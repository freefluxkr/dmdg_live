19.1 데이터베이스의 개념과 종류

데이터베이스(Database, DB)란 데이터를 구조화하여 저장하고, 효율적으로 검색·수정·삭제할 수 있도록 관리하는 시스템입니다. 데이터베이스를 관리하는 소프트웨어를 DBMS(Database Management System)라고 합니다.

데이터베이스는 크게 관계형 데이터베이스(RDBMS)와 NoSQL 데이터베이스로 나뉩니다.

관계형 데이터베이스 (RDBMS)

관계형 데이터베이스(Relational Database Management System)는 데이터를 행(row)과 열(column)로 이루어진 테이블 형태로 저장합니다. 테이블 간의 관계를 정의하여 데이터 중복을 줄이고 일관성을 유지합니다. SQL을 사용하여 데이터를 조작합니다.

대표적인 RDBMS로는 MySQL, PostgreSQL, Oracle, SQLite, MariaDB 등이 있습니다.

NoSQL 데이터베이스

NoSQL(Not Only SQL)은 관계형 모델을 따르지 않는 다양한 형태의 데이터베이스를 통칭합니다. 대용량 비정형 데이터 처리에 적합하며 수평 확장이 용이합니다.

구분 관계형 DB (RDBMS) NoSQL
데이터 구조 테이블 (행/열) 문서, 키-값, 그래프 등
스키마 고정 스키마 유연한 스키마
쿼리 언어 SQL 각 DB별 고유 문법
확장성 수직 확장 수평 확장
일관성 강한 일관성 (ACID) 최종 일관성 (BASE)
대표 제품 MySQL, PostgreSQL MongoDB, Redis, Cassandra
적합한 용도 정형 데이터, 복잡한 관계 대용량, 비정형 데이터

이 챕터에서는 가장 널리 사용되는 관계형 데이터베이스인 MySQL을 중심으로 학습합니다.

💡 어떤 DB를 선택해야 할까? 트랜잭션이 중요하고 데이터 관계가 복잡하다면 RDBMS, 빠른 읽기/쓰기와 유연한 구조가 필요하다면 NoSQL을 고려하세요. 실제 프로젝트에서는 두 가지를 혼합하여 사용하기도 합니다.

19.2 관계형 데이터베이스 구조

관계형 데이터베이스의 핵심 구성 요소를 이해하면 SQL을 훨씬 쉽게 배울 수 있습니다.

테이블 (Table)

테이블(Table)은 관계형 데이터베이스의 기본 저장 단위입니다. 스프레드시트의 시트와 유사하게 행과 열로 데이터를 저장합니다. 하나의 데이터베이스는 여러 개의 테이블로 구성됩니다.

예를 들어, 쇼핑몰 데이터베이스에는 users(회원), products(상품), orders(주문) 등의 테이블이 있을 수 있습니다.

행과 열 (Row & Column)

행(Row)은 하나의 데이터 레코드를 의미합니다. users 테이블에서 한 행은 한 명의 회원 정보를 나타냅니다. 열(Column)은 데이터의 속성(필드)을 의미합니다. 이름, 이메일, 가입일 등이 열에 해당합니다.

id name email created_at
1 홍길동 hong@example.com 2024-01-15
2 김철수 kim@example.com 2024-02-20
3 이영희 lee@example.com 2024-03-10

키 (Key)

키(Key)는 테이블에서 행을 식별하거나 테이블 간의 관계를 정의하는 데 사용됩니다.

기본 키(Primary Key, PK)는 테이블에서 각 행을 고유하게 식별하는 열입니다. 중복될 수 없고 NULL 값을 가질 수 없습니다. 위 예시의 id 열이 기본 키입니다.

외래 키(Foreign Key, FK)는 다른 테이블의 기본 키를 참조하는 열입니다. 테이블 간의 관계를 정의합니다. orders 테이블의 user_id가 users 테이블의 id를 참조하는 외래 키가 됩니다.

📌 스키마(Schema)란? 스키마는 데이터베이스의 구조를 정의하는 설계도입니다. 테이블 이름, 각 열의 이름과 데이터 타입, 제약 조건, 테이블 간의 관계 등을 포함합니다.

19.3 MySQL 설치 및 기본 설정

MySQL을 설치하고 기본 환경을 설정하는 방법을 알아봅니다.

MySQL 설치

운영체제별 설치 방법입니다.

Windows: MySQL 공식 사이트에서 MySQL Installer를 다운로드하여 설치합니다. MySQL Server와 MySQL Workbench를 함께 설치하면 편리합니다.

macOS: Homebrew를 사용하는 것이 간편합니다.

brew install mysql
brew services start mysql

Ubuntu/Linux: apt 패키지 관리자를 사용합니다.

sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo mysql_secure_installation

MySQL 접속 및 기본 명령

설치 후 터미널에서 MySQL에 접속합니다.

mysql -u root -p

MySQL에 접속한 후 기본적인 관리 명령어를 익혀 둡니다.

-- 데이터베이스 목록 확인
SHOW DATABASES;

-- 데이터베이스 생성
CREATE DATABASE myshop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 데이터베이스 선택
USE myshop;

-- 테이블 목록 확인
SHOW TABLES;

-- MySQL 종료
EXIT;

테이블 생성

실습에 사용할 users 테이블을 생성합니다.

CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    age INT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

주요 데이터 타입은 다음과 같습니다.

데이터 타입 설명 예시
INT 정수 나이, ID
VARCHAR(n) 가변 길이 문자열 (최대 n자) 이름, 이메일
TEXT 긴 문자열 본문, 댓글
DATETIME 날짜와 시간 생성일, 수정일
DECIMAL(p,s) 소수점 포함 실수 가격, 금액
BOOLEAN 참/거짓 활성화 여부

⚠️ 한글 인코딩 주의 MySQL에서 한글을 올바르게 저장하려면 데이터베이스와 테이블 생성 시 utf8mb4 인코딩을 지정해야 합니다. utf8mb4는 이모지를 포함한 모든 유니코드 문자를 지원합니다.

19.4 SQL 기초 문법 - SELECT, INSERT, UPDATE, DELETE

SQL의 데이터 조작 언어(DML)의 핵심 4가지 명령어를 CRUD라고도 합니다. Create(INSERT), Read(SELECT), Update(UPDATE), Delete(DELETE)를 의미합니다.

실습을 위해 먼저 샘플 데이터를 삽입합니다.

INSERT INTO users (name, email, age) VALUES
('홍길동', 'hong@example.com', 28),
('김철수', 'kim@example.com', 35),
('이영희', 'lee@example.com', 24),
('박민준', 'park@example.com', 42),
('최수진', 'choi@example.com', 31);

SELECT - 데이터 조회

SELECT는 테이블에서 데이터를 조회하는 명령어입니다.

-- 모든 열 조회
SELECT * FROM users;

-- 특정 열만 조회
SELECT name, email FROM users;

-- 열에 별칭(Alias) 지정
SELECT name AS 이름, email AS 이메일 FROM users;

INSERT - 데이터 삽입

INSERT INTO는 테이블에 새로운 행을 추가합니다.

-- 단일 행 삽입
INSERT INTO users (name, email, age)
VALUES ('정다은', 'jung@example.com', 27);

-- AUTO_INCREMENT 열(id)은 생략해도 자동으로 값이 부여됩니다

UPDATE - 데이터 수정

UPDATE는 기존 데이터를 수정합니다.

-- 특정 사용자의 나이 수정
UPDATE users
SET age = 29
WHERE name = '홍길동';

-- 여러 열 동시 수정
UPDATE users
SET age = 36, email = 'kim_new@example.com'
WHERE id = 2;

⚠️ WHERE 절 없이 UPDATE 금지 WHERE 절 없이 UPDATE를 실행하면 테이블의 모든 행이 수정됩니다. 반드시 조건을 지정하는 습관을 들이세요.

DELETE - 데이터 삭제

DELETE는 테이블에서 행을 삭제합니다.

-- 특정 행 삭제
DELETE FROM users WHERE id = 6;

-- 조건에 맞는 여러 행 삭제
DELETE FROM users WHERE age > 40;

⚠️ WHERE 절 없이 DELETE 금지 WHERE 절 없이 DELETE FROM users;를 실행하면 테이블의 모든 데이터가 삭제됩니다. 삭제 전에 SELECT로 먼저 대상 데이터를 확인하는 습관을 들이세요.

19.5 조건절(WHERE), 정렬(ORDER BY), 제한(LIMIT)

실제 데이터 조회에서는 원하는 데이터만 필터링하고 정렬하는 기능이 핵심입니다.

WHERE - 조건 필터링

WHERE 절은 조회할 데이터의 조건을 지정합니다.

-- 나이가 30 이상인 사용자 조회
SELECT * FROM users WHERE age >= 30;

-- 이름이 '홍길동'인 사용자 조회
SELECT * FROM users WHERE name = '홍길동';

-- AND / OR 연산자 사용
SELECT * FROM users WHERE age >= 25 AND age <= 35;
SELECT * FROM users WHERE name = '홍길동' OR name = '김철수';

-- BETWEEN: 범위 조건
SELECT * FROM users WHERE age BETWEEN 25 AND 35;

-- IN: 여러 값 중 하나와 일치
SELECT * FROM users WHERE age IN (24, 28, 31);

-- LIKE: 패턴 매칭 (% = 임의의 문자열, _ = 임의의 한 문자)
SELECT * FROM users WHERE email LIKE '%@example.com';
SELECT * FROM users WHERE name LIKE '김%';

-- IS NULL / IS NOT NULL
SELECT * FROM users WHERE age IS NULL;

ORDER BY - 정렬

ORDER BY는 결과를 특정 열 기준으로 정렬합니다.

-- 나이 오름차순 정렬 (기본값: ASC)
SELECT * FROM users ORDER BY age ASC;

-- 나이 내림차순 정렬
SELECT * FROM users ORDER BY age DESC;

-- 여러 열 기준 정렬 (이름 오름차순, 나이 내림차순)
SELECT * FROM users ORDER BY name ASC, age DESC;

LIMIT - 결과 수 제한

LIMIT은 반환할 행의 수를 제한합니다. 페이지네이션 구현에도 활용됩니다.

-- 상위 3개 행만 조회
SELECT * FROM users LIMIT 3;

-- 나이 높은 순으로 상위 2명 조회
SELECT * FROM users ORDER BY age DESC LIMIT 2;

-- OFFSET: 시작 위치 지정 (페이지네이션)
-- 4번째 행부터 3개 조회 (2페이지, 페이지당 3개)
SELECT * FROM users LIMIT 3 OFFSET 3;

💡 쿼리 실행 순서 SQL 쿼리는 작성 순서와 실행 순서가 다릅니다. FROM → WHERE → SELECT → ORDER BY → LIMIT 순서로 처리됩니다. 이를 이해하면 복잡한 쿼리 작성 시 오류를 예방할 수 있습니다.

19.6 조인(JOIN)과 집계 함수

실제 데이터베이스에서는 여러 테이블을 연결하거나 데이터를 요약할 일이 많습니다.

JOIN - 테이블 연결

실습을 위해 orders 테이블을 생성하고 데이터를 추가합니다.

CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    product_name VARCHAR(100) NOT NULL,
    amount INT NOT NULL,
    ordered_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

INSERT INTO orders (user_id, product_name, amount) VALUES
(1, '노트북', 1200000),
(1, '마우스', 30000),
(2, '키보드', 80000),
(3, '모니터', 350000),
(2, '웹캠', 60000);

INNER JOIN은 두 테이블에서 조건이 일치하는 행만 반환합니다.

-- 주문 정보와 주문자 이름을 함께 조회
SELECT
    orders.id AS 주문번호,
    users.name AS 주문자,
    orders.product_name AS 상품명,
    orders.amount AS 금액
FROM orders
INNER JOIN users ON orders.user_id = users.id;

LEFT JOIN은 왼쪽 테이블의 모든 행을 반환하고, 오른쪽 테이블에 일치하는 행이 없으면 NULL을 반환합니다.

-- 주문이 없는 사용자도 포함하여 조회
SELECT
    users.name AS 이름,
    orders.product_name AS 상품명
FROM users
LEFT JOIN orders ON users.id = orders.user_id;
JOIN 종류 설명
INNER JOIN 양쪽 테이블에 모두 일치하는 행만 반환
LEFT JOIN 왼쪽 테이블 전체 + 오른쪽 일치 행 (없으면 NULL)
RIGHT JOIN 오른쪽 테이블 전체 + 왼쪽 일치 행 (없으면 NULL)
FULL OUTER JOIN 양쪽 테이블 모든 행 (MySQL은 UNION으로 구현)

집계 함수와 GROUP BY

집계 함수(Aggregate Function)는 여러 행의 데이터를 하나의 값으로 요약합니다.

-- COUNT: 행의 수
SELECT COUNT(*) AS 전체회원수 FROM users;
SELECT COUNT(*) AS 주문건수 FROM orders;

-- SUM: 합계
SELECT SUM(amount) AS 총매출 FROM orders;

-- AVG: 평균
SELECT AVG(amount) AS 평균주문금액 FROM orders;

-- MAX / MIN: 최댓값 / 최솟값
SELECT MAX(amount) AS 최고금액, MIN(amount) AS 최저금액 FROM orders;

GROUP BY는 특정 열의 값을 기준으로 행을 그룹화하고, 각 그룹에 집계 함수를 적용합니다.

-- 사용자별 주문 건수와 총 주문 금액
SELECT
    users.name AS 이름,
    COUNT(orders.id) AS 주문건수,
    SUM(orders.amount) AS 총주문금액
FROM users
LEFT JOIN orders ON users.id = orders.user_id
GROUP BY users.id, users.name;

-- HAVING: 그룹화 후 조건 필터링 (WHERE는 그룹화 전)
-- 총 주문금액이 100,000원 이상인 사용자만 조회
SELECT
    users.name AS 이름,
    SUM(orders.amount) AS 총주문금액
FROM users
INNER JOIN orders ON users.id = orders.user_id
GROUP BY users.id, users.name
HAVING SUM(orders.amount) >= 100000;

💡 WHERE vs HAVING WHERE는 그룹화(GROUP BY) 이전에 개별 행을 필터링하고, HAVING은 그룹화 이후 그룹 전체를 필터링합니다. 집계 함수 조건은 반드시 HAVING을 사용해야 합니다.

19.7 Python에서 DB 연결하기

Python에서 MySQL에 연결하는 방법은 크게 두 가지입니다. 저수준 드라이버인 pymysql과 ORM(Object Relational Mapping) 라이브러리인 SQLAlchemy입니다.

pymysql 사용하기

pymysql은 Python에서 MySQL에 직접 연결하여 SQL을 실행할 수 있는 라이브러리입니다.

pip install pymysql

기본 연결 및 쿼리 실행 방법입니다.

import pymysql

# 데이터베이스 연결
conn = pymysql.connect(
    host='localhost',
    user='root',
    password='your_password',
    database='myshop',
    charset='utf8mb4'
)

# 커서 생성
cursor = conn.cursor()

# SELECT 쿼리 실행
cursor.execute("SELECT * FROM users")
rows = cursor.fetchall()  # 모든 결과 가져오기

for row in rows:
    print(row)

# 연결 종료
cursor.close()
conn.close()

fetchall() 외에도 fetchone()(한 행), fetchmany(n)(n개 행)을 사용할 수 있습니다.

SQLAlchemy 사용하기

SQLAlchemy는 Python의 대표적인 ORM 라이브러리입니다. SQL을 직접 작성하지 않고 Python 객체로 데이터베이스를 다룰 수 있습니다. Django, Flask, FastAPI 등 많은 웹 프레임워크와 함께 사용됩니다.

pip install sqlalchemy pymysql

SQLAlchemy를 사용한 연결과 기본 쿼리 방법입니다.

from sqlalchemy import create_engine, text

# 데이터베이스 URL 형식: dialect+driver://user:password@host/dbname
DATABASE_URL = "mysql+pymysql://root:your_password@localhost/myshop?charset=utf8mb4"

# 엔진 생성
engine = create_engine(DATABASE_URL, echo=True)

# SQL 직접 실행 (Core 방식)
with engine.connect() as conn:
    result = conn.execute(text("SELECT * FROM users"))
    for row in result:
        print(row)
구분 pymysql SQLAlchemy
방식 저수준 드라이버 ORM / SQL 표현식
SQL 작성 직접 SQL 문자열 작성 Python 객체 또는 SQL
학습 난이도 낮음 보통
사용 사례 간단한 스크립트 웹 애플리케이션, 대형 프로젝트
DB 교체 용이성 어려움 쉬움 (DB 추상화)

💡 어떤 것을 선택해야 할까? 간단한 스크립트나 데이터 분석 작업에는 pymysql이 편리합니다. 웹 서비스나 규모 있는 애플리케이션을 개발한다면 SQLAlchemy를 배워두는 것을 권장합니다.

실습 준비

먼저 필요한 라이브러리를 설치하고 데이터베이스가 준비되어 있는지 확인합니다.

pip install pymysql

DB 연결 모듈 작성

재사용 가능한 DB 연결 함수를 작성합니다.

# db_config.py
import pymysql

def get_connection():
    """MySQL 데이터베이스 연결을 반환합니다."""
    return pymysql.connect(
        host='localhost',
        user='root',
        password='your_password',  # 실제 비밀번호로 변경
        database='myshop',
        charset='utf8mb4',
        cursorclass=pymysql.cursors.DictCursor  # 결과를 딕셔너리로 반환
    )

DictCursor를 사용하면 결과를 딕셔너리 형태로 받아 row['name']처럼 열 이름으로 접근할 수 있습니다.

Create - 데이터 삽입

# crud_example.py
from db_config import get_connection

def create_user(name: str, email: str, age: int) -> int:
    """새 사용자를 데이터베이스에 삽입하고 생성된 ID를 반환합니다."""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            sql = "INSERT INTO users (name, email, age) VALUES (%s, %s, %s)"
            cursor.execute(sql, (name, email, age))
        conn.commit()  # 변경사항 저장
        return cursor.lastrowid  # 새로 생성된 행의 ID
    except Exception as e:
        conn.rollback()  # 오류 시 롤백
        print(f"오류 발생: {e}")
        raise
    finally:
        conn.close()

# 사용 예시
new_id = create_user('정다은', 'jung@example.com', 27)
print(f"새 사용자 생성 완료. ID: {new_id}")

Read - 데이터 조회

def get_all_users() -> list:
    """모든 사용자를 조회합니다."""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            cursor.execute("SELECT * FROM users ORDER BY id")
            return cursor.fetchall()
    finally:
        conn.close()

def get_user_by_id(user_id: int) -> dict:
    """ID로 특정 사용자를 조회합니다."""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            sql = "SELECT * FROM users WHERE id = %s"
            cursor.execute(sql, (user_id,))
            return cursor.fetchone()  # 단일 행 반환 (없으면 None)
    finally:
        conn.close()

# 사용 예시
users = get_all_users()
for user in users:
    print(f"[{user['id']}] {user['name']} ({user['email']}) - {user['age']}세")

user = get_user_by_id(1)
if user:
    print(f"\n조회된 사용자: {user['name']}")

Update - 데이터 수정

def update_user_age(user_id: int, new_age: int) -> bool:
    """사용자의 나이를 수정합니다. 성공 여부를 반환합니다."""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            sql = "UPDATE users SET age = %s WHERE id = %s"
            cursor.execute(sql, (new_age, user_id))
            affected_rows = cursor.rowcount  # 변경된 행 수
        conn.commit()
        return affected_rows > 0
    except Exception as e:
        conn.rollback()
        print(f"오류 발생: {e}")
        raise
    finally:
        conn.close()

# 사용 예시
success = update_user_age(1, 29)
print(f"수정 {'성공' if success else '실패'} (대상 없음)")

Delete - 데이터 삭제

def delete_user(user_id: int) -> bool:
    """사용자를 삭제합니다. 성공 여부를 반환합니다."""
    conn = get_connection()
    try:
        with conn.cursor() as cursor:
            sql = "DELETE FROM users WHERE id = %s"
            cursor.execute(sql, (user_id,))
            affected_rows = cursor.rowcount
        conn.commit()
        return affected_rows > 0
    except Exception as e:
        conn.rollback()
        print(f"오류 발생: {e}")
        raise
    finally:
        conn.close()

# 사용 예시
success = delete_user(6)
print(f"삭제 {'성공' if success else '실패 (대상 없음)'}")

📌 SQL 인젝션 방지 위 코드처럼 SQL 쿼리에 파라미터를 직접 문자열로 삽입하지 않고 %s 플레이스홀더와 튜플을 사용하면 SQL 인젝션(SQL Injection) 공격을 방어할 수 있습니다. 절대로 f"... WHERE id = {user_id}"와 같이 f-string으로 직접 값을 삽입하지 마세요.

마치며

이번 챕터에서는 데이터베이스의 기초부터 Python과의 연동까지 전체적인 흐름을 학습했습니다.

핵심 요약:

  • 데이터베이스는 관계형(RDBMS)과 NoSQL로 나뉘며, MySQL은 대표적인 관계형 DB입니다.
  • 테이블은 행(row)과 열(column)로 구성되며, 기본 키(PK)로 각 행을 고유하게 식별합니다.
  • SQL의 핵심 4명령어는 SELECT(조회), INSERT(삽입), UPDATE(수정), DELETE(삭제)입니다.
  • WHERE, ORDER BY, LIMIT으로 데이터를 필터링, 정렬, 제한할 수 있습니다.
  • JOIN으로 여러 테이블을 연결하고, 집계 함수와 GROUP BY로 데이터를 요약합니다.
  • Python에서는 pymysql로 직접 SQL을 실행하거나 SQLAlchemy로 ORM 방식으로 데이터베이스를 다룰 수 있습니다.
  • SQL 파라미터는 반드시 플레이스홀더(%s)를 사용하여 SQL 인젝션을 방어해야 합니다.
