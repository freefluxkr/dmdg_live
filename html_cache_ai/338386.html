1.2 Python 설치 및 버전 관리

Python(파이썬)은 현재 AI/머신러닝 분야에서 가장 널리 사용되는 프로그래밍 언어입니다. 문법이 간결하고 풍부한 라이브러리 생태계 덕분에 초보자도 빠르게 생산적인 코드를 작성할 수 있습니다.

Python 버전 선택

AI/데이터 분야에서는 Python 3.10 이상 버전을 권장합니다. Python 2.x는 2020년에 공식 지원이 종료되었으므로 반드시 Python 3.x를 설치해야 합니다.

💡 버전 권장: 2026년 현재 NumPy 2.x · PyTorch 2.5+ · TensorFlow 2.18+ 등 주요 라이브러리가 Python 3.12까지 안정 지원합니다. 본문 실습은 Python 3.11 또는 3.12 환경에서 검증되었으며, 어느 쪽을 사용해도 무방합니다. Python 3.13은 일부 ML 라이브러리(특히 GPU 가속 빌드)가 늦게 지원되는 경우가 있어, 처음이라면 3.11/3.12를 추천합니다.

Windows에서 Python 설치

  1. https://www.python.org/downloads/ 에 접속합니다.
  2. "Download Python 3.11.x" 버튼을 클릭하여 설치 파일을 내려받습니다.
  3. 설치 파일을 실행하고, 반드시 하단의 "Add Python to PATH" 체크박스를 선택합니다.

설치가 완료되면 터미널(명령 프롬프트 또는 PowerShell)을 열고 아래 명령어로 설치를 확인합니다.

python --version

1.4 가상환경(venv) 생성과 관리

가상환경(Virtual Environment)은 프로젝트별로 독립된 Python 실행 환경을 만드는 기술입니다. 프로젝트마다 필요한 라이브러리의 버전이 다를 수 있는데, 가상환경을 사용하면 이런 충돌을 방지할 수 있습니다.

💡 왜 가상환경이 필요한가? 프로젝트 A는 numpy 1.24를, 프로젝트 B는 numpy 1.26을 필요로 한다면, 가상환경 없이는 하나의 버전만 설치할 수 있어 충돌이 발생합니다. 가상환경을 사용하면 각 프로젝트가 자신만의 독립된 패키지 공간을 갖게 됩니다.

가상환경 생성

프로젝트 폴더를 만들고 그 안에서 가상환경을 생성합니다. Python 내장 모듈인 venv를 사용합니다.

# 프로젝트 폴더 생성 및 이동
mkdir my-ai-project
cd my-ai-project

# 가상환경 생성 (.venv 폴더 이름은 자유롭게 지정 가능)
python -m venv .venv

가상환경 활성화

가상환경을 생성했다면 반드시 활성화해야 합니다. 활성화하면 터미널 프롬프트 앞에 (.venv)가 표시됩니다.

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (명령 프롬프트)
.venv\Scripts\activate.bat

# macOS / Linux
source .venv/bin/activate

활성화 후 터미널이 아래처럼 보이면 정상입니다.

(.venv) C:\my-ai-project>

가상환경 비활성화

작업이 끝나면 아래 명령어로 가상환경을 비활성화합니다.

deactivate

VS Code에서 가상환경 연결

VS Code에서 해당 프로젝트 폴더를 열면 자동으로 .venv를 감지합니다. 감지하지 못하는 경우 Ctrl+Shift+P → Python: Select Interpreter에서 .venv/bin/python (또는 .venv\Scripts\python.exe)을 직접 선택합니다.

⚠️ 주의: 터미널에서 가상환경을 활성화한 상태에서 패키지를 설치해야 해당 프로젝트에만 패키지가 설치됩니다. 가상환경을 활성화하지 않으면 시스템 전체에 설치될 수 있습니다.

1.5 필수 라이브러리 설치

AI/데이터 분석을 위한 핵심 라이브러리 4가지를 설치합니다. 가상환경을 활성화한 상태에서 아래 명령어를 실행합니다.

pip install numpy pandas matplotlib scikit-learn

각 라이브러리의 역할을 간단히 살펴보겠습니다.

NumPy (넘파이)

NumPy(Numerical Python)는 수치 계산을 위한 핵심 라이브러리입니다. 다차원 배열(ndarray)을 제공하며, 행렬 연산, 통계 계산 등을 빠르게 처리합니다.

import numpy as np

# 1차원 배열 생성
arr = np.array([1, 2, 3, 4, 5])
print(arr)         # [1 2 3 4 5]
print(arr.mean())  # 3.0 (평균)
print(arr * 2)     # [2 4 6 8 10] (벡터 연산)

Pandas (판다스)

Pandas는 표 형태의 데이터(CSV, Excel 등)를 다루는 라이브러리입니다. DataFrame이라는 자료구조를 통해 데이터를 쉽게 불러오고, 정제하고, 분석할 수 있습니다.

import pandas as pd

# 간단한 데이터프레임 생성
data = {
    "이름": ["Alice", "Bob", "Charlie"],
    "나이": [25, 30, 35],
    "점수": [88, 92, 78]
}
df = pd.DataFrame(data)
print(df)
print(df["점수"].mean())  # 86.0 (점수 평균)

Matplotlib (맷플롯립)

Matplotlib은 데이터를 시각화하는 라이브러리입니다. 선 그래프, 막대 그래프, 산점도 등 다양한 차트를 그릴 수 있습니다.

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]

plt.plot(x, y, marker='o')
plt.title("간단한 선 그래프")
plt.xlabel("X축")
plt.ylabel("Y축")
plt.show()

Scikit-learn (사이킷런)

Scikit-learn(sklearn)은 머신러닝 알고리즘을 쉽게 사용할 수 있도록 모아놓은 라이브러리입니다. 분류, 회귀, 군집화, 전처리 등 다양한 기능을 일관된 API로 제공합니다.

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

# 붓꽃 데이터셋 불러오기
iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.2, random_state=42
)
print(f"훈련 데이터: {X_train.shape}, 테스트 데이터: {X_test.shape}")

설치 확인

아래 코드로 모든 라이브러리가 정상적으로 설치되었는지 확인합니다.

import numpy as np
import pandas as pd
import matplotlib
import sklearn

print(f"NumPy 버전: {np.__version__}")
print(f"Pandas 버전: {pd.__version__}")
print(f"Matplotlib 버전: {matplotlib.__version__}")
print(f"Scikit-learn 버전: {sklearn.__version__}")
print("모든 라이브러리가 정상적으로 설치되었습니다!")

1.6 인공지능의 정의와 분류

인공지능(Artificial Intelligence, AI)은 인간의 지능적 행동(학습, 추론, 문제 해결, 언어 이해 등)을 컴퓨터 프로그램으로 구현하는 기술을 말합니다.

AI는 능력의 범위에 따라 크게 세 가지로 분류됩니다.

약한 AI (Narrow AI / Weak AI)

약한 AI(Narrow AI)는 특정 작업 하나에만 뛰어난 AI를 말합니다. 현재 우리가 실생활에서 사용하는 AI는 거의 모두 약한 AI에 해당합니다.

  • 바둑을 두는 AlphaGo (바둑 외의 다른 게임은 못함)
  • 이미지를 인식하는 AI (이미지 인식 외의 작업은 못함)
  • ChatGPT와 같은 언어 모델 (텍스트 처리 전문)
  • 음성을 인식하는 Siri, Alexa, 클로바

강한 AI (General AI / Strong AI)

강한 AI(AGI, Artificial General Intelligence)는 인간처럼 어떤 지적 과제도 처리할 수 있는 AI를 말합니다. 한 분야를 학습하면 다른 분야에도 그 지식을 활용할 수 있는 범용 지능입니다.

⚠️ 현실: 2026년 현재 강한 AI는 아직 존재하지 않습니다. 이는 AI 연구자들의 궁극적인 목표 중 하나입니다.

초지능 (Superintelligence)

초지능(Superintelligence)은 모든 분야에서 인간의 능력을 월등히 초월하는 가상의 AI를 말합니다. 철학자 닉 보스트롬(Nick Bostrom)이 자신의 저서에서 체계적으로 논의한 개념입니다.

💡 정리: 현재 AI 기술의 수준은 약한 AI 단계에 있습니다. 하지만 약한 AI도 특정 분야에서는 이미 인간을 능가하는 성능을 보여주고 있습니다.

AI, 머신러닝, 딥러닝의 관계

많은 분들이 AI, 머신러닝(Machine Learning, ML), 딥러닝(Deep Learning, DL)을 혼용하는데, 이 셋은 포함 관계에 있습니다.

  • AI: 가장 넓은 개념. 인간의 지능을 흉내 내는 모든 기술
  • 머신러닝: AI의 한 분야. 규칙을 직접 프로그래밍하는 대신 데이터로부터 자동으로 학습
  • 딥러닝: 머신러닝의 한 분야. 인공 신경망을 여러 층 쌓아 복잡한 패턴을 학습

1.7 AI가 할 수 있는 것과 할 수 없는 것

AI 기술에 대한 과도한 기대와 불필요한 두려움을 줄이기 위해, AI가 실제로 무엇을 잘하고 무엇이 어려운지 명확히 이해하는 것이 중요합니다.

AI가 잘하는 것

  • 패턴 인식: 수많은 데이터에서 규칙이나 패턴을 찾아냅니다. 이미지 분류, 스팸 메일 필터링 등이 대표적입니다.

  • 반복 작업 자동화: 동일한 유형의 작업을 빠르고 일관되게 처리합니다. 24시간 쉬지 않고 작동할 수 있습니다.

  • 대용량 데이터 처리: 인간이 평생 읽어도 다 못 읽을 양의 데이터를 짧은 시간에 분석합니다.

  • 특정 게임/최적화: 바둑, 체스, 특정 비디오 게임에서 인간을 압도하는 성능을 보입니다.

  • 언어 생성 및 번역: 자연스러운 텍스트를 생성하고 여러 언어 간 번역을 수행합니다.

AI가 어려워하는 것

  • 상식적 추론: "유리컵을 바닥에 떨어뜨리면 어떻게 될까?"처럼 인간에게는 당연한 상식을 AI는 데이터 없이 추론하기 어렵습니다.

  • 인과관계 이해: 상관관계는 잘 찾아내지만, "왜 그런지"를 진정으로 이해하는 것은 어렵습니다.

  • 적은 데이터로 학습: AI는 일반적으로 대용량 학습 데이터가 필요합니다. 인간 아이는 강아지를 몇 번만 봐도 구분하지만, AI는 수천 장의 사진이 필요할 수 있습니다.

  • 감정과 공감: 텍스트로 감정을 표현할 수 있지만, 실제로 감정을 느끼거나 진정한 공감을 하는 것은 불가능합니다.

  • 완전히 새로운 창의성: 기존 데이터의 패턴을 조합하는 것은 잘하지만, 완전히 새로운 아이디어를 만들어내는 창의성에는 한계가 있습니다.

📌 핵심: AI는 도구입니다. 망치로 나사를 조이려 하면 안 되듯, AI도 잘 맞는 문제에 적용했을 때 최고의 성능을 발휘합니다. AI의 강점과 한계를 정확히 이해하는 것이 좋은 AI 활용자가 되는 첫걸음입니다.

1.8 인공지능의 발전 역사

AI의 역사를 이해하면 현재의 AI 기술이 왜 이런 형태로 발전했는지 맥락을 파악할 수 있습니다.

1950년대: AI의 시작 - 튜링 테스트

앨런 튜링(Alan Turing)은 1950년 "기계가 생각할 수 있는가?"라는 질문을 던지며 튜링 테스트(Turing Test)를 제안했습니다. 이 테스트는 인간이 대화 상대가 사람인지 기계인지 구분하지 못하면 그 기계는 "지능이 있다"고 볼 수 있다는 개념입니다.

같은 시기인 1956년, 존 매카시(John McCarthy)가 "Artificial Intelligence"라는 용어를 처음 사용했으며, 이를 AI 연구의 공식적인 시작으로 봅니다.

1980~90년대: AI의 겨울과 전문가 시스템

AI는 초기의 기대와 달리 한계에 부딪히며 두 차례의 AI 겨울(AI Winter) 시기를 겪었습니다. 연구비 지원이 끊기고 관심이 급감한 기간입니다.

이 시기에 전문가 시스템(Expert System)이 등장했습니다. 전문가의 지식을 규칙으로 프로그래밍하여 특정 분야의 문제를 해결하는 방식이었지만, 새로운 상황에 유연하게 대응하지 못하는 한계가 있었습니다.

1997년: 딥블루 vs 카스파로프

IBM이 개발한 체스 AI 딥블루(Deep Blue)가 당시 세계 체스 챔피언 가리 카스파로프(Garry Kasparov)를 꺾었습니다. AI가 특정 지적 게임에서 인간 최고 전문가를 처음으로 이긴 역사적인 사건입니다.

2012년: 딥러닝의 부활 - ImageNet 대회

알렉스넷(AlexNet)이 ImageNet 이미지 인식 대회에서 기존 방식을 압도하는 성능으로 우승했습니다. 이 사건은 딥러닝 붐의 시작점으로, GPU를 활용한 대규모 신경망 학습의 가능성을 증명했습니다.

2016년: 알파고 vs 이세돌

구글 딥마인드의 알파고(AlphaGo)가 바둑 세계 챔피언 이세돌 9단을 4:1로 꺾었습니다. 바둑은 경우의 수가 우주의 원자 수보다 많아 인간을 절대 이기지 못할 것으로 여겨졌기 때문에, 이 사건은 전 세계에 AI의 가능성을 강렬하게 알렸습니다.

2017년: 트랜스포머 아키텍처 등장

구글의 연구팀이 "Attention Is All You Need" 논문을 통해 트랜스포머(Transformer) 아키텍처를 발표했습니다. 이 구조는 이후 모든 대형 언어 모델(LLM)의 기반이 되었습니다.

2022년: ChatGPT의 등장

OpenAI가 출시한 ChatGPT는 공개 5일 만에 100만 명의 사용자를 확보하며 폭발적인 반응을 불러일으켰습니다. 복잡한 질문에 자연스럽게 대답하고, 코드를 작성하고, 글을 써주는 능력은 AI의 대중화 시대를 열었습니다.

💡 현재: 2026년 현재 생성형 AI(Generative AI)는 텍스트, 이미지, 음악, 영상 생성 등 다양한 분야로 빠르게 확장되고 있으며, 산업 전반에 걸쳐 혁신을 주도하고 있습니다.

AI 발전 역사를 타임라인으로 정리하면 다음과 같습니다.

시기 주요 사건
1950 튜링 테스트 제안 (앨런 튜링)
1956 "Artificial Intelligence" 용어 탄생 (존 매카시)

1980s 전문가 시스템 전성기

# Chapter 1 실습: Python 기본 문법 확인

실습 2: 라이브러리 설치 확인 및 간단한 데이터 시각화

아래 코드로 설치한 라이브러리를 실제로 사용해봅니다.

# ============================================================
# Chapter 1 실습: 라이브러리 활용
# ============================================================
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# --- NumPy: 수치 계산 ---
print("=== NumPy 실습 ===")
scores = np.array([85, 92, 78, 96, 88, 73, 91, 84])
print(f"점수 데이터: {scores}")
print(f"평균: {scores.mean():.1f}")
print(f"최고점: {scores.max()}, 최저점: {scores.min()}")
print(f"표준편차: {scores.std():.2f}")

# --- Pandas: 데이터프레임 ---
print("\n=== Pandas 실습 ===")
data = {
    "학생": ["Alice", "Bob", "Charlie", "Diana", "Eve"],
    "수학": [85, 92, 78, 96, 88],
    "영어": [90, 85, 82, 89, 94],
    "과학": [88, 79, 91, 87, 76]
}
df = pd.DataFrame(data)
df["평균"] = df[["수학", "영어", "과학"]].mean(axis=1).round(1)
print(df.to_string(index=False))
print(f"\n과목별 평균:\n{df[['수학', '영어', '과학']].mean().round(1)}")

# --- Matplotlib: 시각화 ---
print("\n=== Matplotlib 실습 (차트 창이 열립니다) ===")
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 막대 그래프: 학생별 평균 점수
axes[0].bar(df["학생"], df["평균"], color=["#4C72B0", "#55A868", "#C44E52", "#8172B2", "#CCB974"])
axes[0].set_title("학생별 평균 점수")
axes[0].set_xlabel("학생")
axes[0].set_ylabel("점수")
axes[0].set_ylim(0, 100)

# 꺾은선 그래프: 과목별 점수 비교
subjects = ["수학", "영어", "과학"]
for _, row in df.iterrows():
    axes[1].plot(subjects, [row["수학"], row["영어"], row["과학"]], marker='o', label=row["학생"])
axes[1].set_title("과목별 점수 비교")
axes[1].set_xlabel("과목")
axes[1].set_ylabel("점수")
axes[1].legend()
axes[1].set_ylim(60, 100)

plt.tight_layout()
plt.show()
print("실습 완료!")
