우리는 앞선 챕터에서 신경망의 기본 구조와 학습 원리를 배웠습니다. 그런데 신경망이 이미지를 처리할 때는 특별한 문제가 생깁니다. 가령 28×28 픽셀짜리 흑백 이미지를 완전연결층(Fully Connected Layer)으로 처리하려면 784개의 입력 뉴런이 필요하고, 고해상도 컬러 이미지라면 수백만 개의 파라미터가 필요해집니다. 이처럼 기존 방식은 이미지의 공간적 구조를 전혀 활용하지 못하고, 계산 비용도 폭발적으로 증가합니다.

합성곱 신경망(CNN, Convolutional Neural Network)은 이 문제를 해결하기 위해 고안된 구조입니다. CNN은 이미지의 지역적 패턴을 효율적으로 학습하여 이미지 분류, 객체 탐지, 얼굴 인식 등 다양한 시각 지능 과제에서 놀라운 성능을 발휘합니다.

💡 학습 목표

  • 이미지 데이터가 어떻게 표현되는지 이해합니다.
  • 합성곱 연산의 원리를 이해합니다.
  • 필터, 스트라이드, 패딩의 역할을 설명할 수 있습니다.
  • 풀링(Pooling)과 특성맵(Feature Map)의 개념을 이해합니다.
  • CNN의 전체 구조를 파악합니다.
  • LeNet부터 ResNet까지 대표 모델의 발전 흐름을 이해합니다.
  • CNN의 다양한 활용 분야를 파악합니다.
  • 실습을 통해 CNN으로 이미지 분류를 직접 체험합니다.

5.1 이미지 데이터의 특성과 표현

이미지는 숫자의 배열입니다

컴퓨터에서 이미지는 픽셀(Pixel)의 격자로 표현됩니다. 각 픽셀은 밝기나 색상 정보를 담은 숫자입니다.

  • 흑백(Grayscale) 이미지: 각 픽셀이 0(검정)~255(흰색) 사이의 숫자 한 개로 표현됩니다. 28×28 이미지는 2차원 배열 (28, 28)로 나타냅니다.
  • 컬러(RGB) 이미지: 각 픽셀이 빨강(R), 초록(G), 파랑(B) 세 채널의 값으로 구성됩니다. 28×28 컬러 이미지는 3차원 배열 (28, 28, 3)으로 나타냅니다.
import numpy as np
from PIL import Image

# 28x28 흑백 이미지를 numpy 배열로 표현
gray_image = np.random.randint(0, 256, (28, 28), dtype=np.uint8)
print("흑백 이미지 shape:", gray_image.shape)   # (28, 28)

# 32x32 컬러 이미지를 numpy 배열로 표현
color_image = np.random.randint(0, 256, (32, 32, 3), dtype=np.uint8)
print("컬러 이미지 shape:", color_image.shape)  # (32, 32, 3)

딥러닝 프레임워크에서는 보통 배치(Batch) 차원을 포함하여 (배치 크기, 높이, 너비, 채널) 또는 (배치 크기, 채널, 높이, 너비) 형태로 데이터를 다룹니다.

이미지 데이터의 공간적 특성

이미지는 단순한 숫자의 나열이 아닙니다. 이미지에는 다음과 같은 중요한 공간적 특성이 있습니다.

  • 지역 상관성(Local Correlation): 인접한 픽셀들은 서로 연관된 값을 가집니다. 강아지의 눈 주변 픽셀들은 서로 비슷한 패턴을 형성합니다.
  • 계층적 구조(Hierarchical Structure): 낮은 수준에서는 선(edge)이나 색상 같은 단순한 패턴이, 높은 수준에서는 귀, 눈 같은 복잡한 특징이 나타납니다.
  • 위치 불변성(Translation Invariance): 고양이가 사진 왼쪽에 있든 오른쪽에 있든 "고양이"로 인식해야 합니다.

📌 CNN은 바로 이러한 이미지의 공간적 특성을 적극 활용하도록 설계된 구조입니다. 완전연결층은 픽셀을 일렬로 펼쳐서 처리하기 때문에 이 공간 정보를 잃어버리지만, CNN은 공간 구조를 유지한 채로 학습합니다.

5.2 합성곱(Convolution) 연산의 원리

합성곱이란 무엇인가

합성곱(Convolution)은 이미지 위를 작은 창(필터)이 이동하면서 지역적인 특징을 추출하는 연산입니다. 신호 처리나 이미지 처리에서 오래전부터 사용되던 수학적 연산을 딥러닝에 적용한 것입니다.

직관적으로 설명하면 다음과 같습니다.

  1. 작은 창(필터 또는 커널)을 이미지 위에 올려놓습니다.
  2. 창이 덮는 영역의 픽셀값과 필터값을 각각 곱한 뒤 모두 더합니다.
  3. 그 결과값 하나를 새로운 위치에 기록합니다.
  4. 창을 옆으로 이동하면서 이 과정을 반복합니다.

합성곱 연산 예시

예를 들어, 5×5 이미지에 3×3 필터를 적용하는 경우를 살펴봅시다.

이렇게 필터를 이미지 전체에 걸쳐 슬라이딩하면 특성맵(Feature Map)이 생성됩니다.

import numpy as np

def simple_convolution(image, kernel):
    """간단한 2D 합성곱 연산 구현"""
    i_h, i_w = image.shape
    k_h, k_w = kernel.shape
    out_h = i_h - k_h + 1
    out_w = i_w - k_w + 1
    output = np.zeros((out_h, out_w))

    for i in range(out_h):
        for j in range(out_w):
            output[i, j] = np.sum(image[i:i+k_h, j:j+k_w] * kernel)

    return output

# 예시
image = np.array([
    [1, 2, 3, 0, 1],
    [4, 5, 6, 1, 0],
    [7, 8, 9, 2, 1],
    [0, 1, 2, 3, 4],
    [2, 3, 4, 5, 6]
], dtype=float)

# 세로 엣지를 감지하는 필터
kernel = np.array([
    [ 1,  0, -1],
    [ 1,  0, -1],
    [ 1,  0, -1]
], dtype=float)

result = simple_convolution(image, kernel)
print("특성맵:")
print(result)

필터가 학습하는 것

CNN에서 필터의 값들은 사람이 직접 정하지 않고, 역전파(Backpropagation)를 통해 자동으로 학습됩니다. 학습 과정에서 CNN은 스스로 유용한 특징을 추출하는 필터를 찾아냅니다.

초기 층에서는 단순한 엣지나 색상을 감지하는 필터가 학습되고, 깊은 층으로 갈수록 눈, 코, 귀처럼 복잡한 패턴을 감지하는 필터가 학습됩니다.

💡 완전연결층은 각 뉴런이 모든 입력과 연결되므로 파라미터 수가 매우 많습니다. 반면 합성곱층은 필터의 가중치만 학습하면 되므로 파라미터 수가 훨씬 적고, 같은 필터를 이미지 전체에 재사용하는 가중치 공유(Weight Sharing) 덕분에 효율적입니다.

5.3 필터, 스트라이드, 패딩

필터(Filter) / 커널(Kernel)

필터(Filter)는 합성곱 연산에서 이미지를 슬라이딩하는 작은 행렬입니다. 커널(Kernel)이라고도 부릅니다.

  • 필터의 크기는 보통 3×3, 5×5, 7×7 등 홀수를 사용합니다.
  • 하나의 합성곱층은 여러 개의 필터를 사용하여 다양한 특징을 동시에 추출합니다.
  • 필터 수가 많을수록 더 다양한 특성맵이 생성되어 표현력이 높아집니다.

스트라이드(Stride)

스트라이드(Stride)는 필터가 한 번에 이동하는 칸 수입니다.

  • 스트라이드 1: 필터를 한 칸씩 이동 → 출력 크기가 입력과 비슷하게 유지됩니다.
  • 스트라이드 2: 필터를 두 칸씩 이동 → 출력 크기가 절반으로 줄어듭니다.

출력 크기를 계산하는 공식은 다음과 같습니다.

출력 크기 = (입력 크기 - 필터 크기) / 스트라이드 + 1

예시: 입력 7×7, 필터 3×3, 스트라이드 1 → (7-3)/1 + 1 = 5 → 출력 5×5

입력 크기 필터 크기 스트라이드 출력 크기
7×7 3×3 1 5×5
7×7 3×3 2 3×3
28×28 5×5 1 24×24
32×32 3×3 1 30×30

패딩(Padding)

합성곱 연산을 반복하면 출력 크기가 점점 작아집니다. 패딩(Padding)은 이를 방지하기 위해 입력 이미지 가장자리에 0 값을 채워 넣는 기법입니다.

  • 제로 패딩(Zero Padding): 가장자리에 0을 채워 넣습니다.
  • 'valid' 패딩: 패딩 없이 연산 → 출력 크기가 줄어듭니다.
  • 'same' 패딩: 출력 크기를 입력과 같게 유지하도록 패딩을 자동 추가합니다.
import tensorflow as tf
from tensorflow.keras import layers

# 패딩 비교 예시
model_valid = layers.Conv2D(32, (3, 3), padding='valid', input_shape=(28, 28, 1))
model_same  = layers.Conv2D(32, (3, 3), padding='same',  input_shape=(28, 28, 1))

# valid: 입력 28x28 → 출력 26x26
# same:  입력 28x28 → 출력 28x28 (크기 유지)

패딩을 사용하면 이미지 가장자리 픽셀도 충분히 합성곱에 참여할 수 있어 정보 손실을 줄일 수 있습니다.

⚠️ 스트라이드와 패딩은 출력 크기와 계산량에 직접 영향을 줍니다. 모델 설계 시 이 두 값을 적절히 조합하여 원하는 출력 크기를 맞추는 것이 중요합니다.

5.4 풀링(Pooling)과 특성맵(Feature Map)

특성맵(Feature Map)

특성맵(Feature Map)은 합성곱 연산의 결과로 생성되는 2차원 배열입니다. 하나의 필터를 적용하면 하나의 특성맵이 만들어집니다. 여러 개의 필터를 사용하면 그 수만큼 특성맵이 쌓입니다.

특성맵의 각 값은 해당 위치에서 필터가 감지하는 특징이 얼마나 강하게 나타났는지를 의미합니다. 값이 클수록 그 위치에서 해당 패턴이 강하게 검출된 것입니다.

풀링(Pooling)이란

풀링(Pooling)은 특성맵의 크기를 줄이면서 중요한 정보를 유지하는 연산입니다. 다운샘플링(Downsampling)이라고도 합니다.

풀링의 주요 역할은 다음과 같습니다.

  • 특성맵의 크기를 줄여 계산량을 감소시킵니다.
  • 위치의 소소한 변화에 강건하게(robust) 만들어 줍니다.
  • 과적합(Overfitting)을 억제하는 데 도움이 됩니다.

최대 풀링(Max Pooling)

가장 많이 사용되는 풀링 방식입니다. 풀링 창 내에서 가장 큰 값을 선택합니다.

각 사분면의 최댓값만 선택되어 출력 2×2가 만들어집니다. 좌상 6, 우상 4, 좌하 3, 우하 4.

평균 풀링(Average Pooling)

창 내 값들의 평균을 계산합니다. 최대 풀링보다 부드러운 특성맵을 생성하지만, 일반적으로 이미지 분류에서는 최대 풀링이 더 좋은 성능을 보입니다.

구분 최대 풀링 (Max Pooling) 평균 풀링 (Average Pooling)
연산 창 내 최댓값 선택 창 내 평균값 계산
특징 가장 두드러진 특징 추출 전체적인 특징 반영
사용 이미지 분류에 주로 사용 GAP 등 특수 목적에 활용 
import tensorflow as tf
from tensorflow.keras import layers

# 최대 풀링: 2x2 창, 스트라이드 2
max_pool = layers.MaxPooling2D(pool_size=(2, 2), strides=2)

# 평균 풀링: 2x2 창, 스트라이드 2
avg_pool = layers.AveragePooling2D(pool_size=(2, 2), strides=2)

📌 최대 풀링은 가장 강하게 반응한 특징만 남기기 때문에, 이미지의 작은 이동이나 왜곡에도 안정적인 결과를 만들어 냅니다. 이를 위치 불변성(Translation Invariance)이라고 합니다.

5.5 CNN의 전체 구조

CNN은 크게 특징 추출부와 분류부로 나뉩니다.

각 층의 역할

합성곱층(Convolutional Layer)은 필터를 사용해 입력에서 지역적인 특징을 추출합니다. 층이 깊어질수록 더 복잡하고 추상적인 특징을 학습합니다.

활성화 함수(Activation Function)는 보통 ReLU(Rectified Linear Unit)를 사용합니다. 음수를 0으로 만들어 비선형성을 부여합니다.

풀링층(Pooling Layer)은 특성맵의 크기를 줄여 계산 효율을 높이고 과적합을 억제합니다.

플래튼(Flatten)은 2D 특성맵을 1D 벡터로 변환하여 완전연결층에 전달합니다.

완전연결층(Fully Connected Layer)은 추출된 특징들을 종합하여 최종 분류를 수행합니다.

간단한 CNN 예시 코드

import tensorflow as tf
from tensorflow.keras import layers, models

def build_simple_cnn(input_shape=(28, 28, 1), num_classes=10):
    model = models.Sequential([
        # 첫 번째 합성곱 블록
        layers.Conv2D(32, (3, 3), activation='relu', padding='same',
                      input_shape=input_shape),
        layers.MaxPooling2D((2, 2)),

        # 두 번째 합성곱 블록
        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2)),

        # 분류부
        layers.Flatten(),
        layers.Dense(128, activation='relu'),
        layers.Dense(num_classes, activation='softmax')
    ])
    return model

model = build_simple_cnn()
model.summary()

이 모델에서 데이터 흐름을 따라가 보면 다음과 같습니다.

층 출력 Shape 파라미터 수
Conv2D (32필터, 3×3) (26, 26, 32) 320
MaxPooling2D (2×2) (13, 13, 32) 0
Conv2D (64필터, 3×3) (11, 11, 64) 18,496
MaxPooling2D (2×2) (5, 5, 64) 0
Flatten (1600,) 0
Dense (128) (128,) 204,928
Dense (10) (10,) 1,290

💡 합성곱층은 파라미터 수가 매우 적지만, 그 뒤의 완전연결층에서 파라미터가 급격히 늘어납니다. 현대 CNN은 완전연결층 이전에 전역 평균 풀링(Global Average Pooling)을 사용하여 파라미터 수를 줄이는 경향이 있습니다.

5.6 대표 모델의 발전 - LeNet → AlexNet → VGG → ResNet

CNN은 수십 년에 걸쳐 꾸준히 발전해왔습니다. 핵심 모델들의 등장과 의의를 살펴봅시다.

LeNet-5 (1998) — CNN의 원조

얀 르쿤(Yann LeCun)이 설계한 LeNet-5는 최초의 실용적인 CNN 모델입니다. 손으로 쓴 숫자(MNIST)를 인식하는 데 사용되었습니다.

  • 구조: Conv → Pool → Conv → Pool → FC → FC → 출력
  • 의의: 합성곱과 풀링을 결합하는 CNN의 기본 패턴을 확립하였습니다.
  • 한계: 당시 컴퓨팅 파워 부족으로 더 깊은 모델을 만들기 어려웠습니다.

AlexNet (2012) — 딥러닝 혁명의 시작

2012년 ImageNet 대회에서 AlexNet은 기존 방법보다 오류율을 10% 이상 낮추며 딥러닝 시대를 열었습니다.

  • 구조: 5개의 합성곱층 + 3개의 완전연결층, 총 8층
  • 혁신 포인트:
  • ReLU 활성화 함수 사용 (Sigmoid 대비 학습 속도 대폭 향상)
  • 드롭아웃(Dropout) 도입으로 과적합 방지
  • GPU 2개를 병렬로 사용하는 학습
  • 데이터 증강(Data Augmentation) 적용
  • 의의: CNN이 실제로 깊고 강력한 모델이 될 수 있음을 증명하였습니다.

VGGNet (2014) — 단순함의 미학

옥스퍼드 대학팀이 개발한 VGGNet은 단순하지만 매우 깊은 구조로 높은 성능을 달성하였습니다.

  • 구조: 3×3 작은 필터만 일관되게 사용, 16~19층
  • 혁신 포인트:
  • 3×3 필터 두 번 = 5×5 필터 한 번과 같은 수용 영역(receptive field)이지만 파라미터 수가 적음
  • 단순하고 균일한 구조로 재현성이 높음
  • 한계: 파라미터 수가 약 1억 4천만 개로 매우 많아 메모리 부담이 큽니다.

ResNet (2015) — 깊이의 한계를 극복

마이크로소프트 리서치의 허카이밍(Kaiming He) 팀이 개발한 ResNet은 잔차 연결(Residual Connection) 또는 스킵 연결(Skip Connection)을 도입하였습니다.

  • 구조: 152층(ResNet-152)까지 구현
  • 핵심 아이디어: 잔차 블록(Residual Block)

입력 x가 출력에 그대로 더해지므로, 층이 깊어져도 기울기 소실(Gradient Vanishing) 문제 없이 학습이 가능합니다.

  • 의의: 매우 깊은 네트워크를 안정적으로 학습할 수 있게 되어, 층 수와 성능이 비례하는 시대를 열었습니다.

모델 비교 요약

모델 연도 층 수 특징 Top-5 오류율
LeNet-5 1998 7층 CNN의 기반 확립 (MNIST 기준)
AlexNet 2012 8층 ReLU, Dropout, GPU 학습 15.3%
VGGNet-16 2014 16층 3×3 필터 일관 사용 7.3%
ResNet-50 2015 50층 잔차 연결, 초심층 학습 5.25%

📌 ResNet 이후에도 DenseNet, EfficientNet, Vision Transformer(ViT) 등 다양한 모델이 등장하였습니다. 그러나 이 모델들 모두 CNN의 핵심 원리를 바탕으로 발전한 것입니다.

5.7 CNN의 활용

CNN은 이미지와 관련된 거의 모든 분야에서 활용됩니다.

이미지 분류(Image Classification)

입력 이미지가 어떤 클래스에 속하는지 판단합니다.

  • 의료 진단: X-ray, MRI 이미지에서 폐암, 당뇨망막병증 등을 감지합니다.
  • 제품 품질 검사: 공장 생산라인에서 불량품을 자동 감지합니다.
  • 식물 병해 감지: 농작물 잎 사진으로 병충해를 진단합니다.

객체 탐지(Object Detection)

이미지에서 여러 객체의 위치(Bounding Box)와 종류를 동시에 찾아냅니다.

  • 자율주행: 도로 위 차량, 보행자, 신호등을 실시간 감지합니다.
  • CCTV 분석: 특정 인물이나 물체를 자동으로 추적합니다.
  • 대표 모델: YOLO, Faster R-CNN, SSD 등

얼굴 인식(Face Recognition)

얼굴을 감지하고, 누구인지 식별하거나 감정을 분석합니다.

  • 스마트폰 잠금 해제: Face ID 같은 생체 인증 시스템
  • 출입 통제 시스템: 등록된 직원 얼굴을 인식하여 출입 허용
  • 감정 분석: 표정에서 기쁨, 슬픔, 분노 등 감정 파악

이미지 생성 및 변환

  • 스타일 트랜스퍼(Style Transfer): 사진을 특정 화풍의 그림처럼 변환합니다.
  • 이미지 초해상도(Super-Resolution): 저화질 이미지를 고화질로 변환합니다.
  • 의료 이미지 분할(Segmentation): 종양의 경계를 픽셀 단위로 정확히 구분합니다.

💡 CNN은 이미지 처리를 넘어 동영상 분석, 자연어 처리, 음성 인식 등 다양한 분야에도 응용되고 있습니다.

[실습] CNN으로 이미지 분류 체험

MNIST 손글씨 숫자 데이터셋을 이용해 CNN 모델을 만들고 학습시켜 봅시다.

1단계: 데이터 준비

import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt

# MNIST 데이터셋 불러오기
(x_train, y_train), (x_test, y_test) = tf.keras.datasets.mnist.load_data()

# 전처리: 0~1 범위로 정규화 및 채널 차원 추가
x_train = x_train.astype('float32') / 255.0
x_test  = x_test.astype('float32') / 255.0
x_train = x_train[..., np.newaxis]  # (60000, 28, 28, 1)
x_test  = x_test[..., np.newaxis]   # (10000, 28, 28, 1)

print("훈련 데이터:", x_train.shape)
print("테스트 데이터:", x_test.shape)

# 샘플 이미지 확인
fig, axes = plt.subplots(1, 10, figsize=(15, 2))
for i in range(10):
    axes[i].imshow(x_train[i, :, :, 0], cmap='gray')
    axes[i].set_title(str(y_train[i]))
    axes[i].axis('off')
plt.suptitle("MNIST 샘플 이미지")
plt.tight_layout()
plt.show()

2단계: CNN 모델 구축

from tensorflow.keras import layers, models

def build_cnn_model():
    model = models.Sequential([
        # 합성곱 블록 1
        layers.Conv2D(32, (3, 3), activation='relu', padding='same',
                      input_shape=(28, 28, 1)),
        layers.Conv2D(32, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),

        # 합성곱 블록 2
        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
        layers.Conv2D(64, (3, 3), activation='relu', padding='same'),
        layers.MaxPooling2D((2, 2)),
        layers.Dropout(0.25),

        # 분류부
        layers.Flatten(),
        layers.Dense(256, activation='relu'),
        layers.Dropout(0.5),
        layers.Dense(10, activation='softmax')  # 10개 숫자 분류
    ])
    return model

model = build_cnn_model()
model.summary()

3단계: 모델 컴파일 및 학습

# 모델 컴파일
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# 학습 (약 5분 소요)
history = model.fit(
    x_train, y_train,
    epochs=10,
    batch_size=128,
    validation_split=0.1,
    verbose=1
)

4단계: 결과 평가 및 시각화

# 테스트 정확도 평가
test_loss, test_acc = model.evaluate(x_test, y_test, verbose=0)
print(f"\n테스트 정확도: {test_acc:.4f} ({test_acc*100:.2f}%)")

# 학습 곡선 시각화
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# 정확도 곡선
axes[0].plot(history.history['accuracy'],     label='훈련 정확도')
axes[0].plot(history.history['val_accuracy'], label='검증 정확도')
axes[0].set_title('모델 정확도')
axes[0].set_xlabel('에포크')
axes[0].set_ylabel('정확도')
axes[0].legend()

# 손실 곡선
axes[1].plot(history.history['loss'],     label='훈련 손실')
axes[1].plot(history.history['val_loss'], label='검증 손실')
axes[1].set_title('모델 손실')
axes[1].set_xlabel('에포크')
axes[1].set_ylabel('손실')
axes[1].legend()

plt.tight_layout()
plt.show()

5단계: 예측 결과 확인

import numpy as np

# 테스트 이미지 예측
predictions = model.predict(x_test[:20])
predicted_labels = np.argmax(predictions, axis=1)

# 시각화
fig, axes = plt.subplots(2, 10, figsize=(20, 4))
for i in range(20):
    row, col = divmod(i, 10)
    axes[row, col].imshow(x_test[i, :, :, 0], cmap='gray')
    color = 'green' if predicted_labels[i] == y_test[i] else 'red'
    axes[row, col].set_title(
        f"예측:{predicted_labels[i]}\n정답:{y_test[i]}",
        color=color, fontsize=8
    )
    axes[row, col].axis('off')

plt.suptitle("CNN 예측 결과 (초록=정답, 빨강=오답)")
plt.tight_layout()
plt.show()

💡 이 실습에서 잘 구성된 CNN 모델은 MNIST에서 99% 이상의 정확도를 달성할 수 있습니다. 에포크 수나 필터 수를 바꿔가며 정확도 변화를 직접 실험해 보세요.

CIFAR-10으로 확장 실습 (심화)

# CIFAR-10: 10종류 컬러 이미지 (비행기, 자동차, 새, 고양이 등)
(x_train, y_train), (x_test, y_test) = tf.keras.datasets.cifar10.load_data()

x_train = x_train.astype('float32') / 255.0
x_test  = x_test.astype('float32') / 255.0

class_names = ['비행기','자동차','새','고양이','사슴',
               '개','개구리','말','배','트럭']

plt.figure(figsize=(10, 2))
for i in range(10):

print("CIFAR-10 훈련 데이터 shape:", x_train.shape)  # (50000, 32, 32, 3)

⚠️ CIFAR-10은 MNIST보다 훨씬 복잡한 데이터셋으로, 단순한 CNN으로는 70~80% 정도의 정확도를 달성합니다. 더 높은 성능을 원한다면 ResNet 같은 깊은 모델이나 데이터 증강 기법을 사용해보세요.

마치며

이번 챕터에서는 이미지 처리에 특화된 딥러닝 구조인 CNN을 배웠습니다.

CNN은 합성곱 연산을 통해 이미지의 공간적 특성을 효율적으로 학습하고, 필터, 스트라이드, 패딩, 풀링이라는 핵심 구성 요소를 결합하여 강력한 시각 지능을 구현합니다. LeNet에서 시작된 CNN은 AlexNet의 딥러닝 혁명, VGG의 깊이 탐구, ResNet의 잔차 연결 혁신을 거쳐 현재도 이미지 분류, 객체 탐지, 얼굴 인식 등 수많은 분야의 핵심 기술로 활용되고 있습니다.

📌 Chapter 5 핵심 요약

  • 이미지는 픽셀값의 2D(흑백) 또는 3D(컬러) 배열로 표현됩니다.
  • 합성곱 연산은 필터를 슬라이딩하면서 지역적 특징을 추출합니다.
  • 필터는 특징 추출기, 스트라이드는 이동 간격, 패딩은 크기 유지 기법입니다.
  • 특성맵은 합성곱 결과, 풀링은 크기를 줄이고 불변성을 높이는 연산입니다.
  • CNN은 합성곱층 → 활성화 → 풀링층을 반복한 후 완전연결층으로 분류합니다.
  • CNN은 LeNet(1998) → AlexNet(2012) → VGG(2014) → ResNet(2015) 순으로 발전하였습니다.
  • CNN은 이미지 분류, 객체 탐지, 얼굴 인식 등 시각 지능의 핵심 기술입니다.
