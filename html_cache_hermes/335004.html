03-2. 실습: 첫 대화

  • 실습 1: 말 걸어 보기
  • 실습 2: 정보 조사
  • 실습 3: 작업 맡기기
  • 관찰 포인트

이 절에서는 Hermes Agent와 직접 대화하며 기본적인 작동 방식을 체험합니다. 사람에게 부탁하듯 자연스럽게 말하면 됩니다.

실습 환경

이 실습은 「클라우드 API 연동」 절에서 골라 둔 OpenRouter의 무료 모델 nvidia/nemotron-3-super-120b-a12b:free를 사용합니다. 새로 가입했고 크레딧이 0인 상태에서도 그대로 따라 할 수 있도록 한 선택입니다. 다른 모델을 사용 중이라면 /model로 전환할 수 있고, 실습 결과는 모델에 따라 달라질 수 있습니다. 한국어 품질이 더 좋은 옵션은 부록 「로컬 LLM 가이드」를 참고하세요.

⚠️ 무료 모델은 입출력이 모델 학습에 사용됩니다: OpenRouter :free 엔드포인트는 "모든 프롬프트와 응답이 프로바이더의 모델·제품·서비스 개선 목적으로 로깅된다"고 공식 고지합니다. 시험·학습 용도로만 사용하고, 개인정보·기밀 정보·업무 데이터는 입력하지 마세요. 실제 업무에는 유료 모델이나 로컬 LLM(부록 「로컬 LLM 가이드」)을 사용합니다.

실습 1: 말 걸어 보기

Hermes Agent를 시작하고, 편하게 말을 걸어 봅니다.

$ hermes

> 안녕, 너는 뭘 할 수 있어?

에이전트가 잠시 생각한 뒤, 자신이 할 수 있는 일을 자연스럽게 설명합니다. 파일 작업·터미널·웹 검색 같은 기본 도구와 설치 직후 활성화된 번들 스킬이 함께 소개됩니다. 사용자가 MCP 서버를 등록하거나 새 스킬을 추가하면 이 목록은 그만큼 풍성해지고, 같은 질문에도 답의 모양이 달라집니다(7장 스킬·8장 MCP 참고). 단순한 챗봇이 아니라 실제로 행동하는 에이전트라는 것을 첫 대화에서 바로 느낄 수 있습니다.

실습 2: 정보 조사

에이전트에게 무언가를 조사해 달라고 부탁해 봅니다.

> NousResearch가 어떤 회사인지 간단히 알려줘

에이전트가 웹 검색 도구를 사용하여 정보를 찾고, 요약해 줍니다. 직접 검색해서 여러 페이지를 읽는 대신, 에이전트에게 맡기면 한 번에 정리된 답을 받을 수 있습니다.

웹 검색이 안 된다면

모델에 따라 웹 검색 결과를 도구 호출로 깔끔히 처리하지 못하는 경우가 있습니다. 무료 모델이나 14B 이하의 로컬 LLM에서 자주 나타납니다. 이때는 "검색하지 말고 네가 아는 대로 알려줘"라고 하면 학습 데이터 기반으로 답합니다. 웹 검색 기능은 모델의 도구 호출 능력에 크게 의존하며, 14B 이상 모델이나 프론티어 클라우드 모델에서 더 안정적입니다.

실습 3: 작업 맡기기

이번에는 단순한 질문이 아니라, 결과물을 만들어 달라고 부탁합니다. 이 실습부터는 /verbose를 켜두면 에이전트가 어떤 도구를 골라 쓰는지 직접 볼 수 있습니다.

> /verbose
> 러닝 초보자를 위한 4주 훈련 계획을 짜서 파일로 저장해줘.

/verbose는 한 번 입력할 때마다 표시 수준이 순환합니다(off → new → all → verbose). 처음 누르면 new 모드(새로 호출된 도구 표시)가 되고, 끄려면 off가 될 때까지 세 번 더 입력합니다.

에이전트가 스스로 판단해서 필요한 도구를 고르고, 계획을 세우고, 파일로 저장합니다. 웹 검색이 필요하다고 판단하면 알아서 검색하고, 아니면 바로 작성에 들어갑니다. /verbose를 켜두었으므로 이 과정이 화면에 표시됩니다. 일반 챗봇은 텍스트를 화면에 보여주기만 하지만, Hermes Agent는 도구를 조합해서 실제로 파일을 생성합니다.

이어서 수정을 요청해 봅니다.

> 주 3회로 줄이고 스트레칭 루틴도 넣어줘

에이전트가 직전에 만든 파일을 기억하고 있어서, 어떤 파일이라고 말하지 않아도 그 파일을 고칩니다.

같은 질문을 다른 모델로 던져 보고 싶다면 /model로 전환할 수 있습니다. 모델 라우팅과 피커 사용법은 다음 절(3-3 모델 라우팅)에서 자세히 다룹니다.

관찰 포인트

첫 대화에서 주목할 점들:

  • 자연어 이해: 딱딱한 명령어가 아니라 일상적인 말로 지시해도 의도를 파악합니다.
  • 도구 선택: 실습 3에서 /verbose로 관찰한 것처럼, 에이전트가 어떤 도구를 어떤 순서로 쓸지 스스로 판단합니다. 검색이 필요하면 검색하고, 파일을 써야 하면 파일을 씁니다.
  • 컨텍스트 유지: "주 3회로 줄여줘"처럼, 앞선 대화를 기억하고 있는지 확인하세요.
  • 챗봇과의 차이: 단순히 텍스트를 생성하는 것이 아니라, 도구를 조합해서 파일을 저장하고 명령을 실행하는 등 실제로 행동한다는 점을 체감하세요.
