11. 보안

AI 에이전트에게 터미널 접근 권한을 주는 것은 강력하지만, 그만큼 위험할 수 있습니다. 잘못된 명령 하나가 파일을 삭제하거나, API 키를 노출하거나, 시스템을 손상시킬 수 있습니다. 특히 메시징 게이트웨이를 통해 외부에서 접근하거나, 크론으로 무인 실행하는 경우에는 보안이 더욱 중요합니다. 이 장에서는 Hermes Agent의 보안 모델을 다룹니다. Hermes Agent는 심층 방어(defense-in-depth) 원칙에 따라 5개 계층의 보안 장치를 제공합니다.

이 장에서 다루는 내용

  • 5계층 보안 모델
  • 컨테이너 격리
  • 운영 환경 보안 체크리스트
