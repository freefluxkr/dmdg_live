21.1 웹의 기본 구조

클라이언트-서버 모델

웹은 클라이언트-서버(Client-Server) 모델을 기반으로 동작합니다. 사용자의 브라우저가 클라이언트(Client)가 되어 서버에 요청을 보내면, 서버(Server)는 그 요청을 처리하고 응답을 반환합니다.

HTTP 프로토콜

HTTP(HyperText Transfer Protocol)는 클라이언트와 서버가 데이터를 주고받는 규칙(프로토콜)입니다. 현재는 보안이 강화된 HTTPS(HTTP Secure)가 표준으로 사용됩니다.

HTTP 통신에서 자주 사용되는 메서드(Method)는 다음과 같습니다.

메서드 역할 사용 예시
GET 데이터 조회 웹 페이지 열기, 검색
POST 데이터 전송/생성 로그인, 폼 제출
PUT 데이터 수정(전체) 회원 정보 수정
DELETE 데이터 삭제 게시글 삭제

HTTP 응답에는 결과를 나타내는 상태 코드(Status Code)가 포함됩니다.

코드 의미
200 OK (성공)
301/302 Redirect (리다이렉트)
404 Not Found (페이지 없음)
500 Internal Server Error (서버 오류)

프론트엔드와 백엔드

웹 개발은 역할에 따라 두 영역으로 나뉩니다.

구분 프론트엔드(Frontend) 백엔드(Backend)
역할 사용자가 보는 화면 담당 데이터 처리 및 로직 담당
위치 브라우저(클라이언트) 서버
주요 기술 HTML, CSS, JavaScript Python, Flask, DB

AI 모델은 대부분 백엔드 영역에서 실행되며, 프론트엔드는 사용자 입력을 받아 백엔드로 전달하고 결과를 화면에 표시하는 역할을 합니다.

21.2 Flask 프레임워크 소개 및 설치

Flask란?

Flask는 Python으로 웹 애플리케이션을 만들 수 있는 경량 마이크로 웹 프레임워크(Micro Web Framework)입니다. 핵심 기능만 제공하고 나머지는 필요에 따라 확장하는 방식으로, 빠른 프로토타이핑과 AI 모델 서빙에 매우 적합합니다.

Django와 달리 Flask는 최소한의 구성으로 시작할 수 있어, AI/ML 실험을 빠르게 웹으로 전환할 때 특히 유용합니다.

Flask vs Django 비교

항목 Flask Django
철학 마이크로프레임워크, 자유도 높음 풀스택, 배터리 포함
학습 곡선 낮음 상대적으로 높음
적합한 규모 소-중형, API 서버, AI 서빙 중-대형 웹 서비스
ORM 기본 제공 없음 (Flask-SQLAlchemy 확장) 있음

설치

가상환경을 활성화한 상태에서 pip으로 설치합니다.

pip install flask

설치 확인은 다음 명령어로 합니다.

python -c "import flask; print(flask.__version__)"

최소 Flask 앱

Flask 앱의 가장 기본적인 형태는 다음과 같습니다.

from flask import Flask

app = Flask(__name__)   # Flask 앱 인스턴스 생성

@app.route("/")         # 루트 URL에 대한 라우트 등록
def index():
    return "Hello, Flask!"

if __name__ == "__main__":
    app.run(debug=True) # 개발 서버 실행 (debug 모드)

app.run(debug=True)를 실행하면 기본적으로 http://127.0.0.1:5000에서 개발 서버가 시작됩니다.

debug=True는 코드 변경 시 서버가 자동으로 재시작되고 오류 정보를 브라우저에 표시해 주므로, 개발 중에는 편리하지만 운영 환경에서는 반드시 False로 설정해야 합니다.

21.3 라우팅(Routing)과 URL 매핑

라우팅이란?

라우팅(Routing)은 특정 URL로 들어온 요청을 어떤 함수(뷰 함수)가 처리할지 연결하는 것을 말합니다. Flask에서는 @app.route() 데코레이터로 라우트를 등록합니다.

from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "홈 페이지입니다."

@app.route("/about")
def about():
    return "소개 페이지입니다."

@app.route("/hello/<name>")   # URL 변수 사용
def hello(name):
    return f"안녕하세요, {name}님!"

<name>처럼 꺾쇠 괄호를 사용하면 URL의 일부를 변수(Variable Rule)로 받을 수 있습니다.

HTTP 메서드 지정

기본적으로 @app.route()는 GET 메서드만 허용합니다. 여러 메서드를 허용하려면 methods 인자를 지정합니다.

from flask import Flask, request

app = Flask(__name__)

@app.route("/submit", methods=["GET", "POST"])
def submit():
    if request.method == "POST":
        return "POST 요청을 받았습니다."
    return "GET 요청을 받았습니다."

URL 빌드: url_for()

하드코딩된 URL 대신 url_for() 함수를 사용하면 함수 이름으로 URL을 동적으로 생성할 수 있어 유지보수가 편리합니다.

from flask import Flask, url_for

app = Flask(__name__)

@app.route("/user/<username>")
def profile(username):
    return f"{username}의 프로필 페이지"

with app.test_request_context():
    # '/user/alice' 를 반환
    print(url_for("profile", username="alice"))

21.4 템플릿 엔진 (Jinja2)과 HTML 기초

템플릿 엔진이란?

백엔드에서 동적으로 생성된 데이터를 HTML에 삽입하려면 템플릿 엔진(Template Engine)이 필요합니다. Flask는 Jinja2를 기본 템플릿 엔진으로 사용합니다.

Jinja2의 핵심 문법은 다음과 같습니다.

구문 용도 예시
{{ }} 변수 출력 {{ username }}
{% %} 제어문 (if, for) {% if user %}
{# #} 주석 {# 이건 주석 #}

디렉토리 구조

Flask는 기본적으로 templates/ 폴더에서 HTML 파일을 찾습니다.

기본 템플릿 작성

templates/base.html (레이아웃 기반 템플릿)

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}My App{% endblock %}</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">
</head>
<body>
    <header>
        <h1>My Flask App</h1>
        <nav>
            <a href="{{ url_for('index') }}">홈</a> |
            <a href="{{ url_for('about') }}">소개</a>
        </nav>
    </header>
    <main>
        {% block content %}{% endblock %}
    </main>
</body>
</html>

templates/index.html (자식 템플릿)

{% extends "base.html" %}

{% block title %}홈 - My App{% endblock %}

{% block content %}
  <h2>환영합니다!</h2>
  <p>안녕하세요, <strong>{{ username }}</strong>님.</p>

  <h3>메뉴 목록</h3>
  <ul>

      <li>{{ item }}</li>
    {% endfor %}

Python에서 템플릿 렌더링

render_template() 함수로 HTML 파일을 렌더링하고 변수를 전달합니다.

from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def index():
    menu = ["스테이크", "파스타", "샐러드"]
    return render_template("index.html", username="홍길동", menu_list=menu)

HTML 폼과 Flask

사용자로부터 입력을 받는 가장 기본적인 방법은 HTML 폼(Form)입니다. Flask에서는 request 객체를 통해 폼 데이터에 접근합니다.

from flask import Flask, render_template, request

app = Flask(__name__)

@app.route("/form")
def form():
    return render_template("form.html")

@app.route("/result", methods=["POST"])
def result():
    message = request.form.get("message", "")   # POST 데이터에서 'message' 키 추출
    return render_template("result.html", user_message=message)

from flask import Flask, render_template, request, redirect, url_for

app = Flask(__name__)

@app.route("/", methods=["GET"])
def index():
    """메인 페이지: 이름 입력 폼을 표시합니다."""
    return render_template("index.html")

@app.route("/greet", methods=["POST"])
def greet():
    """폼 데이터를 받아 인사 메시지를 생성합니다."""
    name = request.form.get("name", "").strip()
    if not name:
        return redirect(url_for("index"))   # 이름이 없으면 홈으로 리다이렉트
    message = f"안녕하세요, {name}님! 저는 AI 어시스턴트입니다. 무엇을 도와드릴까요?"
    return render_template("greet.html", name=name, message=message)

if __name__ == "__main__":
    app.run(debug=True)

# services/llm_service.py
from openai import OpenAI
from config import Config

client = OpenAI(api_key=Config.OPENAI_API_KEY)

def ask_llm(system_prompt: str, user_message: str, history: list = None) -> str:
    """LLM에 질문하고 응답 텍스트를 반환합니다."""
    messages = [{"role": "system", "content": system_prompt}]

    if history:
        # 최근 10턴만 컨텍스트로 전달 (토큰 절약)
        for turn in history[-10:]:
            messages.append({"role": turn["role"], "content": turn["content"]})

    messages.append({"role": "user", "content": user_message})

    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages,
        max_tokens=1024,
        temperature=0.7,
    )
    return response.choices[0].message.content

# services/excel_service.py
import pandas as pd
import io
from services.llm_service import ask_llm

EXCEL_SYSTEM_PROMPT = """당신은 데이터 분석 전문가입니다.
주어진 데이터 요약을 바탕으로 핵심 트렌드, 이상값, 비즈니스 인사이트를 제공합니다."""

def analyze_excel(file_bytes: bytes, filename: str, user_question: str) -> dict:
    """엑셀 파일을 분석하고 AI 인사이트를 반환합니다."""
    try:
        df = pd.read_excel(io.BytesIO(file_bytes))
    except Exception:
        df = pd.read_csv(io.BytesIO(file_bytes))

    # 데이터 요약 생성
    summary = _build_summary(df)

    prompt = f"""다음 데이터를 분석해 주세요.

[데이터 개요]
{summary}

[사용자 질문]
{user_question}
"""
    answer = ask_llm(EXCEL_SYSTEM_PROMPT, prompt)
    return {
        "answer": answer,
        "rows": len(df),
        "columns": list(df.columns),
        "summary": summary,
    }

def _build_summary(df: pd.DataFrame) -> str:
    """데이터프레임 요약 문자열을 생성합니다."""
    lines = [
        f"행 수: {len(df)}, 열 수: {len(df.columns)}",
        f"컬럼: {', '.join(df.columns.astype(str))}",
        "",
        "수치형 통계:",
        df.describe().to_string(),
        "",
        "결측값:",
        df.isnull().sum().to_string(),
        "",
        "처음 3행 미리보기:",
        df.head(3).to_string(),
    ]
    return "\n".join(lines)

22.5 검색 기능 통합 (웹검색 + DB검색)

하이브리드 검색 전략

하이브리드 검색(Hybrid Search)은 실시간 웹 검색 결과와 내부 DB 검색 결과를 합쳐 LLM에게 컨텍스트로 제공하는 RAG(Retrieval-Augmented Generation) 패턴입니다.

검색 유형 도구 특징
웹 검색 SerpAPI / Tavily 최신 정보, 실시간
DB 검색 SQLite FTS5 내부 문서, 빠른 속도
결합 LLM 요약 두 결과를 통합 답변

hybrid_search()는 사용자 쿼리를 받아 web_search()(SerpAPI/Tavily)와 db_search()(SQLite FTS5)를 병렬로 호출하고, 두 결과를 묶어 LLM에게 컨텍스트로 전달합니다. 최신성(웹)과 정확성·속도(DB)를 동시에 확보해 환각을 줄이는 것이 핵심입니다.

검색 서비스 구현

# services/search_service.py
import requests
import sqlite3
from services.llm_service import ask_llm
from config import Config

SEARCH_SYSTEM_PROMPT = """당신은 검색 결과를 분석하는 전문가입니다.
웹 검색 결과와 내부 문서를 종합하여 정확하고 신뢰할 수 있는 답변을 제공합니다.
출처를 명시하고, 최신 정보를 우선합니다."""

def web_search(query: str, num_results: int = 5) -> list[dict]:
    """SerpAPI를 사용한 웹 검색입니다."""
    params = {
        "q": query,
        "api_key": Config.SERPAPI_KEY,
        "num": num_results,
        "hl": "ko",
    }
    resp = requests.get("https://serpapi.com/search", params=params, timeout=10)
    resp.raise_for_status()
    data = resp.json()

    results = []
    for item in data.get("organic_results", []):
        results.append({
            "title": item.get("title", ""),
            "snippet": item.get("snippet", ""),
            "link": item.get("link", ""),
            "source": "web",
        })
    return results

def db_search(query: str, db_path: str = "app.db") -> list[dict]:
    """SQLite FTS5 전문 검색입니다."""
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    try:
        rows = conn.execute(
            "SELECT title, content, created_at FROM documents_fts WHERE documents_fts MATCH ? LIMIT 5",
            (query,),
        ).fetchall()
        return [
            {"title": r["title"], "snippet": r["content"][:300], "source": "db"}
            for r in rows
        ]
    except sqlite3.OperationalError:
        # FTS 테이블이 없는 경우 빈 결과 반환
        return []
    finally:
        conn.close()

def hybrid_search(query: str) -> dict:
    """웹 검색 + DB 검색 결과를 LLM으로 통합합니다."""
    web_results = web_search(query)
    db_results = db_search(query)
    all_results = web_results + db_results

    if not all_results:
        return {"answer": "검색 결과를 찾을 수 없습니다.", "sources": []}

    context = "\n\n".join(
        f"[{r['source'].upper()}] {r['title']}\n{r['snippet']}"
        for r in all_results
    )
    prompt = f"""다음 검색 결과를 바탕으로 질문에 답변해 주세요.

[검색 결과]
{context}

[질문]
{query}
"""
    answer = ask_llm(SEARCH_SYSTEM_PROMPT, prompt)
    return {
        "answer": answer,
        "sources": [{"title": r["title"], "link": r.get("link", ""), "source": r["source"]} for r in all_results],
    }

# app.py 추가 — 요청 전 공통 검증
import re
from functools import wraps
from markupsafe import escape

# 허용되지 않는 패턴 (프롬프트 인젝션 시도)
INJECTION_PATTERNS = [
    r"ignore previous instructions",
    r"system prompt",
    r"act as",
    r"jailbreak",
]

def validate_input(text: str, max_length: int = 2000) -> tuple[bool, str]:
    """입력 텍스트를 검증하고 (유효여부, 오류메시지)를 반환합니다."""
    if not text or not text.strip():
        return False, "입력값이 비어 있습니다."
    if len(text) > max_length:
        return False, f"입력값은 {max_length}자 이하여야 합니다."

    lower = text.lower()
    for pattern in INJECTION_PATTERNS:
        if re.search(pattern, lower):
            return False, "허용되지 않는 표현이 포함되어 있습니다."

    return True, ""

def require_json(f):

            return jsonify({"error": "Content-Type은 application/json이어야 합니다."}), 415
        return f(*args, **kwargs)
    return decorated

23.1 배포 개요 — 로컬 vs 클라우드

로컬 환경의 한계

지금까지 python app.py를 실행하면 http://127.0.0.1:5000처럼 로컬호스트(localhost)에서만 앱이 동작했습니다. 이 주소는 내 컴퓨터 안에서만 유효하며, 다른 사람은 접근할 수 없습니다.

배포(Deployment)란 애플리케이션을 외부 서버에 올려서 인터넷을 통해 누구나 접근할 수 있도록 하는 작업입니다.

배포 방식 비교

구분 로컬 실행 ngrok 터널링 클라우드 배포
접근 범위 내 컴퓨터만 임시 공개 URL 전 세계
지속성 프로세스 종료 시 중단 터널 세션 동안만 24시간 상시 운영
비용 무료 무료(기본) 무료 플랜 있음
난이도 매우 쉬움 쉬움 보통
사용 목적 개발·테스트 데모·테스트 공유 실제 서비스 운영

배포 흐름 개요

일반적인 웹 애플리케이션 배포 흐름은 다음과 같습니다.

WSGI(Web Server Gateway Interface)는 Python 웹 프레임워크(Flask, Django 등)와 웹 서버 사이를 연결하는 표준 인터페이스입니다. 클라우드 배포 시 Flask 내장 서버 대신 Gunicorn 같은 WSGI 서버를 사용하는 이유가 여기 있습니다.

23.2 ngrok을 이용한 터널링과 임시 공개

ngrok이란?

ngrok(엔그록)은 로컬에서 실행 중인 서버를 외부 인터넷에 임시로 공개할 수 있게 해주는 터널링(Tunneling) 도구입니다. 별도 서버 없이도 https://xxxx.ngrok-free.app 같은 URL을 즉시 받을 수 있습니다.

데모 발표, 팀원 테스트, 웹훅(Webhook) 개발 시 매우 유용합니다.

23.5 로깅과 모니터링 기초

로깅이 중요한 이유

로깅(Logging)은 애플리케이션의 동작 기록을 파일이나 콘솔에 남기는 것입니다. 배포 후 오류가 발생했을 때 원인을 추적하는 핵심 수단입니다.

print()는 개발 중 디버깅에는 편리하지만, 프로덕션에서는 Python 표준 logging 모듈을 사용하는 것이 권장됩니다.

Python logging 모듈 기본 사용법

로그 레벨(Log Level) 은 중요도에 따라 5단계로 구분됩니다.

레벨 숫자 용도
DEBUG 10 상세 디버깅 정보
INFO 20 정상 동작 확인
WARNING 30 주의가 필요한 상황
ERROR 40 기능 오류 발생
CRITICAL 50 심각한 시스템 오류 
import logging
import os

# 로깅 설정
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    handlers=[
        logging.StreamHandler(),           # 콘솔 출력
        logging.FileHandler("app.log"),    # 파일 저장
    ]
)

logger = logging.getLogger(__name__)

Flask 앱에 로깅 통합

from flask import Flask, request, jsonify
import logging
import time

app = Flask(__name__)

@app.before_request
def log_request_info():
    """모든 요청을 로그에 기록"""
    logger.info(f"요청: {request.method} {request.path} | IP: {request.remote_addr}")

@app.after_request
def log_response_info(response):
    """모든 응답을 로그에 기록"""
    logger.info(f"응답: {response.status_code}")
    return response

@app.errorhandler(Exception)
def handle_exception(e):
    """처리되지 않은 예외를 로그에 기록"""
    logger.error(f"처리되지 않은 오류: {str(e)}", exc_info=True)
    return jsonify({"error": "서버 내부 오류가 발생했습니다."}), 500

AI API 호출 로깅

AI 기능이 포함된 앱에서는 API 호출 현황을 추적하는 것이 중요합니다.

import time
import logging
from openai import OpenAI

logger = logging.getLogger(__name__)
client = OpenAI()

def call_openai_with_logging(prompt: str, model: str = "gpt-4o-mini") -> str:
    """로깅이 포함된 OpenAI API 호출 함수"""
    start_time = time.time()

    try:
        logger.info(f"OpenAI 호출 시작 | 모델: {model} | 프롬프트 길이: {len(prompt)}")

        response = client.chat.completions.create(
            model=model,
            messages=[{"role": "user", "content": prompt}]
        )

        elapsed = time.time() - start_time
        usage = response.usage

        logger.info(
            f"OpenAI 호출 완료 | 소요시간: {elapsed:.2f}s | "
            f"입력토큰: {usage.prompt_tokens} | 출력토큰: {usage.completion_tokens}"
        )

        return response.choices[0].message.content

    except Exception as e:
        elapsed = time.time() - start_time
        logger.error(f"OpenAI 호출 실패 | 소요시간: {elapsed:.2f}s | 오류: {str(e)}")
        raise

import os
import logging
from flask import Flask, render_template, request, jsonify
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s"
)
logger = logging.getLogger(__name__)

app = Flask(__name__)
client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/chat", methods=["POST"])
def chat():
    data = request.get_json()
    user_message = data.get("message", "")

    if not user_message:
        return jsonify({"error": "메시지를 입력하세요."}), 400

    logger.info(f"사용자 메시지: {user_message[:50]}")

    try:
        response = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": user_message}]
        )
        reply = response.choices[0].message.content
        logger.info("응답 생성 완료")
        return jsonify({"reply": reply})
    except Exception as e:
        logger.error(f"API 오류: {str(e)}")
        return jsonify({"error": "AI 응답 생성 중 오류가 발생했습니다."}), 500

@app.route("/health")
def health():
    return jsonify({"status": "ok"}), 200

if __name__ == "__main__":
    app.run(debug=True)
