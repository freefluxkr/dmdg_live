01-6 파이썬과 에디터

파이썬 대화형 인터프리터는 간단한 예제를 풀 때는 편리하지만, 여러 줄의 복잡한 코드를 작성할 때는 불편하다. 또한 인터프리터를 종료하면 작성한 프로그램이 사라져 다시 사용할 수 없다. 따라서 반복 사용할 프로그램을 만들 때는 에디터가 필요하다.

에디터(editor)란 소스 코드를 편집하는 프로그래밍 도구이다. 에디터에는 여러 종류가 있는데, 이 책에서는 파이썬 설치 시 기본으로 포함되는 파이썬 IDLE(Integrated Development and Learning Environment)의 에디터를 사용한다.

IDLE은 '아이들'이라고 읽는다.

IDLE 에디터로 파이썬 프로그램 작성하기

파이썬 IDLE은 파이썬 프로그램 작성을 도와주는 통합 개발 환경이다. [시작] 메뉴에서 'idle'을 검색한 후 파이썬 IDLE을 실행해 보자.

맥 사용자는 터미널(Spotlight에서 "터미널" 검색)을 열고 idle3 명령을 입력하자.

그러면 다음과 같은 IDLE 셸(shell) 창이 나타난다.

IDLE 셸은 IDLE 에디터에서 실행한 프로그램의 결과를 표시하는 창이다. 파이썬 코드를 직접 입력하고 실행할 수 있다는 점에서는 앞에서 살펴본 파이썬 셸과 같지만, 자동 완성이나 색상 표시 등의 기능이 추가되어 있어 동작이 조금 다를 수 있다. 이 책에서는 혼란을 방지하기 위해 IDLE 셸은 IDLE 에디터로 작성한 프로그램의 실행 결과를 표시하는 용도로만 사용한다. 즉, 프롬프트(>>>)로 시작하는 예제는 IDLE 셸이 아닌 명령 프롬프트(또는 터미널)의 파이썬 셸에서 실행해야 한다.

이제 IDLE 에디터를 실행해 보자.

IDLE 셸 창 메뉴에서 [File → New File]을 선택한다.

그러면 다음과 같이 빈 창이 나타나는데, 이것이 IDLE 에디터이다.

이제 IDLE 에디터에서 다음과 같이 파이썬 프로그램을 작성해 보자.

# hello.py
print("Hello World")

첫 줄의 # hello.py는 주석이다. 파이썬에서 #으로 시작하는 문장은 주석으로 처리되어 프로그램 수행에 영향을 미치지 않는다. 주석은 소스 코드를 읽을 미래의 나 또는 다른 프로그래머를 위해 설명을 달 때 사용한다.

점프 투 파이썬

여러 줄짜리 주석을 작성하는 방법

주석을 여러 줄 달고 싶다면 다음과 같이 작성하자.

"""
Author: EungYong Park
Date: 2023-05-01
이 프로그램은 Hello World를 출력하는 프로그램이다.
"""

여러 줄 주석은 큰따옴표 3개를 연속으로 사용한 """ 사이에 작성하면 된다. 큰따옴표 대신 작은따옴표 3개(''')를 사용해도 된다.

이제 작성한 프로그램을 실행해 보자.

IDLE 에디터 창 메뉴에서 [Run → Run Module]을 선택한다(단축키: F5).

프로그램을 실행하면 파일을 먼저 저장하라는 대화 상자가 나타난다.

[확인]을 선택하면 [다른 이름으로 저장] 창이 나타난다. 로컬 디스크(C:)로 이동한 후 'doit'이라는 이름으로 디렉터리(폴더)를 생성하고 그 안에 hello.py라는 이름으로 파일을 저장하자. 에디터로 파이썬 프로그램을 작성한 후 저장할 때는 파일 이름의 확장자를 항상 .py로 해야 한다. .py는 파이썬 파일을 나타내는 확장자이다.

실습 경로를 간단히 하기 위해 C:\doit 디렉터리를 생성한 후 파일을 저장했다. C:\에 파일을 바로 저장하면 오류가 발생할 수 있으므로 반드시 C:\ 하위에 디렉터리를 생성한 후 그 안에 파일을 저장하자. 맥 사용자는 홈 디렉터리 아래에 ~/doit 디렉터리를 생성하고 그 안에 파일을 저장하자.

파일을 저장하면 hello.py 프로그램이 실행된다. 실행 결과는 다음과 같이 IDLE 셸 창에 표시된다.

앞으로 간단한 예제는 파이썬 셸에 입력해 결과를 바로 확인하고, 여러 줄을 한꺼번에 작성하거나 저장 후 재사용할 프로그램은 IDLE 에디터에서 작성한다.

점프 투 파이썬

파이썬 셸과 IDLE 에디터의 차이점

이 책은 파이썬 셸과 IDLE 에디터를 번갈아 사용하여 예제를 작성한다. 이때 주의할 점이 1가지 있다. 다음 예제를 살펴보자.

>>> a = "python"
>>> print(a)
python
>>> print(1 + 1)
2

파이썬 셸에서는 위와 같이 변수 a와 표현식 1+1의 값을 확인하기 위해 print 함수를 사용해도 되지만, 다음처럼 print 함수 없이도 그 값을 확인할 수 있다.

>>> a = "python"
>>> a
'python'
>>> 1 + 1
2

이것은 표현식의 실행 결과를 출력하는 파이썬 셸 본래의 기능이기 때문이다. 하지만 IDLE 에디터를 사용할 때는 다음처럼 print 함수를 반드시 사용해야 한다.

# editor.py
a = "python"
print(a)
print(1 + 1)  # print 함수를 사용해야 결괏값을 출력할 수 있다.

실행 결과:

python
2

명령 프롬프트 창에서 파이썬 프로그램 실행하기

이번에는 앞에서 IDLE 에디터로 작성한 hello.py 파일을 명령 프롬프트(command prompt) 창에서 실행해 보자. IDLE 에디터에서 F5를 눌러 실행할 수도 있지만, 실제 업무에서는 주로 명령 프롬프트 창에서 파이썬 프로그램을 실행한다.

우리는 이미 다음 프로그램을 C:\doit 디렉터리에 'hello.py'라는 이름으로 저장했다.

# hello.py
print("Hello World")

hello.py 프로그램을 실행하기 위해 먼저 명령 프롬프트 창을 열어 보자. [윈도우 키 + R]을 누르면 다음과 같은 실행 창이 나타난다. 빈칸에 'cmd'를 입력하고 [확인]을 클릭하면 명령 프롬프트 창이 열린다.

첫 번째 줄에는 다음과 같은 프롬프트가 나타날 것이다. C:\Users\박응용에서 박응용은 필자의 컴퓨터 이름이다(여러분의 명령 프롬프트는 여러분의 컴퓨터 이름으로 표시될 것이다).

C:\Users\박응용>

맥 사용자는 명령 프롬프트 창 대신 터미널을 사용하자.

이제 다음과 같이 프롬프트에서 cd c:\doit이라고 입력한다. cd(change directory) 명령어는 프롬프트를 다음에 나오는 디렉터리로 이동시킨다.

C:\Users\박응용> cd c:\doit

c:\doit>

c:\doit에서 역슬래시(\)는 [Enter] 바로 위에 있는 키로 입력한다. 한글 키보드에서는 원화 표시(₩)로 표시되어 있지만 같은 키이다.

프롬프트가 c:\doit>으로 바뀐 것을 확인할 수 있다. 이제 명령어 python과 실행할 프로그램 이름을 입력하면 파이썬 프로그램을 실행할 수 있다. 다음과 같이 입력해 hello.py 프로그램을 실행해 보자.

c:\doit> python hello.py
Hello World

맥 사용자는 터미널에서 다음처럼 실행하면 된다.

$ cd ~/doit
$ python3 hello.py
Hello World

hello.py 프로그램이 실행되는 것을 확인할 수 있다. 만약 결괏값이 위와 같지 않다면 hello.py 파일이 C:\doit 디렉터리에 있는지 다시 한번 확인하자.

명령 프롬프트 창에서 예제를 실행한 화면은 다음과 같다.

추천하는 에디터

파이썬으로 실무 프로그램을 작성할 때는 앞에서 소개한 IDLE보다 더 많은 기능을 갖춘 에디터를 사용하는 것이 좋다. 추천할 만한 에디터를 소개한다.

이 책의 예제를 풀 때는 파이썬 공부에 최적화된 IDLE을 사용하자. 여기서 소개하는 에디터는 파이썬 공부를 마친 후에 사용해 보기를 권장한다.

파이참

파이썬에 어느 정도 익숙해졌다면 파이참을 사용해 보기를 적극 추천한다. 파이참은 가장 유명한 파이썬 에디터 중 하나로, 코드 작성 시 자동 완성, 문법 체크 등 편리한 기능을 많이 제공한다. 공식 다운로드 사이트(www.jetbrains.com/pycharm/download)에서 내려받을 수 있다.

파이참은 파이썬 전용 에디터이므로 별도의 extension이나 플러그인을 설치할 필요가 없다.

비주얼 스튜디오 코드

비주얼 스튜디오 코드(Visual Studio Code)는 파이참(PyCharm)과 더불어 프로그래머에게 가장 많은 사랑을 받는 파이썬 대표 에디터이다. 공식 다운로드 사이트(code.visualstudio.com)에서 내려받을 수 있다.

비주얼 스튜디오 코드는 파이썬 전용 에디터가 아니므로 파이썬 외에도 여러 언어를 지원한다. 따라서 비주얼 스튜디오 코드를 설치한 후 파이썬을 사용하려면 가장 먼저 파이썬 extension을 설치해야 한다. 파이썬 extension은 비주얼 스튜디오 코드의 [Extensions] 메뉴에서 설치할 수 있다.

여기서는 비주얼 스튜디오 코드(이하 VS Code)로 파이썬 프로그램을 작성하고 실행하는 방법을 간단히 알아보자.

1. VS Code 설치하기

공식 다운로드 사이트(code.visualstudio.com)에서 VS Code를 내려받아 설치한다.

2. 파이썬 extension 설치하기

VS Code를 실행한 후 왼쪽 사이드바에서 Extensions 아이콘(블록 모양)을 클릭한다. 검색창에 'python'을 입력하면 Microsoft에서 제공하는 Python extension이 나타난다. [설치]를 클릭하여 설치하자.

이 extension을 설치하면 코드 자동 완성, 문법 강조, 오류 표시 등 파이썬 개발에 필요한 기능을 사용할 수 있다.

3. 작업 폴더 열기

VS Code 메뉴에서 [File → Open Folder]를 선택하고, 앞에서 만든 C:\doit 폴더를 선택한다.

4. 파이썬 파일 작성하기

왼쪽 탐색기(Explorer)에서 새 파일 아이콘을 클릭하고 hello_vscode.py라는 이름으로 파일을 만든다. 그리고 다음과 같이 코드를 작성한 후 [Ctrl+S](맥: [Cmd+S])를 눌러 저장하자.

# hello_vscode.py
print("Hello VS Code!")

5. 프로그램 실행하기

에디터 오른쪽 상단의 실행 버튼(▷)을 클릭하면 하단의 터미널 창에서 프로그램이 실행된다.

터미널 창에 다음과 같이 출력되면 성공이다.

Hello VS Code!

또는 VS Code 하단의 터미널 창에서 python hello_vscode.py를 직접 입력해도 같은 결과를 얻을 수 있다.
