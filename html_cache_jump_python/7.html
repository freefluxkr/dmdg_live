01-3 파이썬으로 무엇을 할 수 있을까?

프로그래밍 언어를 좋은 언어와 나쁜 언어로 구별할 수 있을까? 사실 이런 구별은 무의미하다. 어떤 언어든 강점과 약점이 있기 때문이다. 따라서 각 언어가 어떤 일에 효율적인지 아는 것이 프로그래머의 생산성을 크게 높인다.

그렇다면 파이썬으로 하기에 적합한 일과 그렇지 않은 일은 무엇일까? 파이썬을 배우기 전에 간단히 알아보자.

파이썬으로 할 수 있는 일

파이썬으로 할 수 있는 일은 매우 많다. 대부분의 프로그래밍 언어가 하는 일을 더 쉽고 깔끔하게 처리한다. 대표적인 몇 가지만 소개한다.

웹 프로그래밍

누구나 한 번쯤 구글 크롬이나 마이크로소프트 엣지 같은 웹 브라우저로 웹 서핑을 하면서 게시판이나 방명록에 글을 남겨 본 적이 있을 것이다. 이런 게시판이나 방명록을 '웹 프로그램'이라고 한다. 파이썬은 웹 프로그램을 만들기에 매우 적합하며, 실제로 파이썬으로 만든 웹 사이트는 셀 수 없이 많다.

인공지능과 머신러닝

인공지능(Artificial Intelligence) 분야의 발전으로 파이썬이 인기 언어로 떠올랐다. 인공지능은 기계가 인간처럼 생각하고 행동하게 하는 기술이다. 파이썬으로 자연어 처리, 음성 인식, 이미지 인식, 챗봇 개발 같은 인공지능 기술을 구현할 수 있다. 머신러닝(Machine Learning)은 인공지능의 한 분야로, 경험을 통해 자동으로 발전하는 컴퓨터 알고리즘을 연구한다. 파이썬에는 인공지능과 머신러닝을 쉽게 구현할 수 있는 다양한 라이브러리가 있으며, 대표적으로 사이킷런(scikit-learn), 텐서플로(TensorFlow), 파이토치(PyTorch), 케라스(Keras) 등이 있다. 이런 이름을 지금 외울 필요는 없고, 파이썬이 인공지능 분야에서 가장 널리 사용되는 언어라는 점만 기억하자.

수치 연산 프로그래밍

파이썬 자체는 C 같은 언어보다 수치 연산 속도가 느리다. 하지만 넘파이(NumPy)라는 수치 연산 모듈을 사용하면 이 문제를 해결할 수 있다. NumPy는 내부적으로 C로 작성되어 빠른 속도를 제공하면서도, 파이썬의 간결한 문법으로 사용할 수 있어 실무에서 널리 활용된다.

데이터 분석

파이썬은 데이터 분석에 이상적인 언어다. 넘파이(NumPy), 판다스(Pandas), 맷플롯립(Matplotlib) 등의 라이브러리로 데이터 처리, 통계 분석, 시각화를 손쉽게 할 수 있다. 데이터 분석에 특화된 R이라는 언어도 많이 사용되지만, 판다스가 등장한 이후 파이썬을 사용하는 경우가 점점 늘고 있다.

데이터베이스 프로그래밍

파이썬은 사이베이스(Sybase), 인포믹스(Informix), 오라클(Oracle), 마이에스큐엘(MySQL), 포스트그레스큐엘(PostgreSQL) 등의 데이터베이스에 접근하기 위한 도구를 제공한다.

이런 데이터베이스를 직접 사용하는 것 외에, 데이터베이스 없이도 간단하게 데이터를 저장하는 방법이 있다. 바로 피클(pickle)이라는 모듈이다. 피클은 파이썬 자료를 변형 없이 파일에 저장하거나 불러올 수 있다.

피클 사용법과 활용 방법은 '05-6 표준 라이브러리'를 참고하자.

시스템 유틸리티 제작

파이썬은 운영체제(윈도우, 리눅스 등)의 시스템 명령어를 사용할 수 있는 각종 도구를 갖추고 있다. 이를 바탕으로 파일 관리, 로그 분석, 시스템 모니터링 등 여러 가지 시스템 유틸리티를 만들 수 있다. 실제로 시스템에서 사용 중인 서로 다른 유틸리티 프로그램을 하나로 합쳐 더 유용한 프로그램을 만들 수 있다.

유틸리티란 컴퓨터 사용에 도움을 주는 소프트웨어를 말한다.

GUI 프로그래밍

GUI(graphic user interface) 프로그래밍이란 화면에 윈도우 창을 만들고 그 창에 프로그램을 동작시킬 수 있는 메뉴나 버튼 등을 추가하는 것을 말한다. 파이썬은 GUI 프로그래밍을 위한 도구가 잘 갖춰져 있어 GUI 프로그램을 쉽게 만들 수 있다. 대표적인 예로 파이썬과 함께 설치되는 Tkinter(티케이인터)가 있다. Tkinter를 사용하면 단 5줄의 코드만으로 윈도우 창을 띄울 수 있다.

C/C++와 결합

파이썬은 접착(glue) 언어라고도 부른다. 다른 언어와 결합해서 사용할 수 있기 때문이다. C나 C++로 만든 프로그램을 파이썬에서 사용할 수 있고, 파이썬으로 만든 프로그램도 C나 C++에서 사용할 수 있다. 예를 들어 속도가 중요한 핵심 부분은 C로 작성하고, 나머지 부분은 파이썬으로 편리하게 작성하는 식으로 두 언어의 장점을 결합할 수 있다.

사물 인터넷

파이썬은 사물 인터넷(Internet of Things) 분야에서도 활용도가 높다. 예를 들어 라즈베리파이(Raspberry Pi)는 리눅스 기반의 매우 작은 컴퓨터다. 라즈베리파이로 홈시어터나 작은 게임기 등 여러 가지 재미있는 것을 만들 수 있는데, 이때 파이썬으로 라즈베리파이를 제어한다. 라즈베리파이에 연결된 모터를 작동시키거나 LED에 불을 켜는 일을 파이썬으로 할 수 있다.

파이썬으로 할 수 없는 일

시스템과 밀접한 프로그래밍 영역

파이썬으로 리눅스 같은 운영체제, 장치 드라이버, 또는 엄청난 횟수의 반복과 연산이 필요한 프로그램을 만드는 것은 어렵다. 즉, 매우 빠른 속도가 필요하거나 하드웨어를 직접 제어해야 하는 프로그램에는 적합하지 않다. 이런 분야에서는 주로 C나 C++ 같은 언어를 사용한다.

모바일 프로그래밍

파이썬은 구글이 가장 많이 사용하는 언어지만, 파이썬으로 안드로이드 네이티브 앱(android native app)을 개발하는 것은 여전히 제한적이다. 네이티브 앱이란 특정 운영체제(안드로이드, iOS)에 맞춰 전용 언어로 만든 앱을 말한다. Kivy나 BeeWare 같은 프레임워크로 모바일 앱 개발이 가능하지만, 성능이나 네이티브 기능 활용 면에서는 한계가 있다. 아이폰 앱도 마찬가지로 직접적인 네이티브 개발보다는 하나의 코드로 여러 운영체제에서 동작하는 크로스 플랫폼 도구를 활용한 개발이 주를 이룬다.
