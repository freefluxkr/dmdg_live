구분 구버전 레거시 방식 (thebook.io 원문) 2026년 최신 표준 처방 (본 도서 적용)
1. GitHub 인증 터미널 ID/비밀번호 입력 ➔ fatal: Auth failed 에러 발생 gh auth login 원클릭 OAuth 승인 & Fine-grained PAT / SSH 3중 처방
2. 기본 브랜치 master 브랜치 기준 설명 (GitHub과 불일치) git config --global init.defaultBranch main 전면 표준 적용
3. 브랜치 전환 git checkout -b feature (다목적 혼란) 최신 표준 git switch -c feature 전면 사용
4. 파일 복원 git checkout -- file.txt 최신 표준 git restore file.txt (언스테이징은 --staged)
5. Pull 경고 차단 단순 git pull 시 불필요한 전략 경고 출력 git config --global pull.rebase false 사전 세팅
6. 서브모듈 복제 clone 후 submodule init, update 수동 분리 실행 git clone --recurse-submodules 모던 원라이너 명령 전수
7. GUI 클라이언트 무겁고 로그인 까다로운 구버전 소스트리 의존 VS Code 내장 소스제어 + GitLens 확장 + 모던 GUI(Fork / GitHub Desktop)
