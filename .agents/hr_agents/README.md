## 🛠️ 커스터마이징 방법
각 JSON 파일의 필드를 수정하여 평가 기준 및 리포트 디자인 테마를 바꿀 수 있습니다:
1. `portrait_image`: 담당자의 고유 프로필 사진 경로를 지정합니다.
2. `color_primary` 및 `color_secondary`: PDF 출력 시 사용되는 기업 시그니처 색상을 변경합니다.
3. `quote`: 담당자 한 줄 명언/좌우명을 설정합니다.
4. `system_instruction`: 실시간 분석 구동 시 에이전트에게 내릴 구체적인 채용 가이드 및 성격 필터 조건을 명시합니다.
