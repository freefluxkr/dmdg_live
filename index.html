구직자의 4대 역량 점수를 6대 축 레이더로 정량화하여 최적의 직무를 찾아드립니다.

📋 응시 요건 및 프로세스 안내

  • 응시 대상: DMDG 7대 공인 평가(기초 4대 + 심화 3대, 총 490문항) 또는 자가 진단 평가를 응시할 누구나
  • 진단 방식 및 예상 소요시간:
    ⚡ 쾌속 직무 매칭 진단 (자가진단): 약 5~8분 소요 (4대 기둥 12개 핵심 역량 지표 슬라이더 진단)
    ※ 공인 인증 성적표가 필요한 경우 [실무 역량 평가 센터] 7대 공인 시험(기초 400문항 + 심화 90문항 = 총 490문항) 완료 후 자동 검증 연동됩니다. (개인 점수 임의 수정 불가)
  • 진단 영역 (4대 핵심 축):
    1. Analytical (데이터·수학·통계)
    2. Coding (Python·알고리즘)
    3. GenAI (LLM·프롬프트·RAG)
    4. Solution (아키텍처·비즈니스)
  • 제공 혜택: 6대 IT/AI 직무 추천 순위 + 6각 네온 레이더 차트 + SHAP XAI 정량 기여도 분석 + 1-Click PDF 성적표 다운로드
