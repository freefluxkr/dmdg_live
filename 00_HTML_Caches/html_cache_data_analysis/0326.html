■ print( ) 함수로 출력하기

여러분은 아마 print라는 단어가 친숙할 겁니다. 흔히 ‘프린트 했어?’ 이런 표현들을 일상 생활에서도 많이 사용하는데요.

파이썬에서 print라는 이름의 함수는 괄호 안의 어떤 값을 모니터에 출력할 때 사용합니다. 백문이 불여일타(百聞而 不如一打)라고 했으니 먼저 코드를 작성해 보겠습니다. 자, print는 괄호 안의 어떤 값을 모니터에 출력해줄 때 사용한다고 했는데요, 파이썬을 처음 배우더라도 이 코드가 무엇을 의미하는지 짐작해 보세요.

print(34759**24341)
