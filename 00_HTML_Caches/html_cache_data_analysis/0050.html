2 기본 그래프 그리기

먼저 간단한 그래프를 그리는 코드와 실행 결과를 살펴보겠습니다.

첫 번째 그래프입니다. 여기에서는 plot() 함수에 한 개의 리스트가 입력되었습니다. plot() 함수는 직선 또는 꺾은선 형태의 그래프를 그릴 때 사용할 수 있는 명령어입니다.

import matplotlib.pyplot as plt
plt.plot([10, 20, 30, 40])
plt.show()

TIP

plt.plot()은 matplotlib.pyplot.plot()와 같은 명령입니다.
