6 제주도의 연령대별 성별 비율을 산점도로 표현하기

다시 성별 인구 데이터로 돌아오겠습니다. 다음 코드는 앞에서 꺾은선 그래프로 남녀 인구를 표현할 때 사용했던 코드와 같은 코드입니다.

import csv
f = open('gender.csv')
data = csv.reader(f)
m = []
f = []
name = input('궁금한 동네를 입력해주세요:')
for row in data :
    if name in row[0] :
        for i in range(3,104) :
            m.append(int(row[i]))
            f.append(int(row[i+103]))
        break
