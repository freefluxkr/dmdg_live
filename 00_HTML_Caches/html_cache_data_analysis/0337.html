■ 비교 연산자(comparison operator)

두 번째 만날 연산자는 비교 연산자입니다. 이것도 코드를 보면 직관적으로 쉽게 이해가 갈 겁니다. 그리고 비교 연산자를 활용한 식이 참이면 True, 거짓이면 False라는 값을 갖는다는 것을 기억하세요.

# 다양한 값을 넣어보며 연습해보세요.
print(10 >= 3)
print(10 <= 3)
print(10 == 3)   # == : 같다
print(10 != 3)   # != : 같지 않다
print(3 % 2 == 1)
