1 클라이언트-서버 모델

요청을 보내는 클라이언트와 요청을 처리해 응답하는 서버가 역할을 분리하여 통신하는 구조입니다.

 

2 UI와 API

① UI는 버튼, 입력창, 아이콘처럼 사용자가 직접 보고 조작하는 화면 요소로, 클라이언트는 사용자와 가까운 위치에서 실행되며 UI를 통해 상호작용합니다.

② API는 두 프로그램이 상호작용하기 위해 정해 둔 규칙으로, 클라이언트 프로그램과 서버 프로그램 사이 통신은 API를 통해 이루어집니다.

 

3 FastAPI 소개

파이썬 3.10 이상에서 동작하는 웹 프레임워크로, 빠른 개발 속도와 높은 실행 성능을 갖췄습니다.
