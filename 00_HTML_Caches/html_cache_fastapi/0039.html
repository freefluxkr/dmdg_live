1.4.2 파이참 설치하기

파이참(PyCharm)은 젯브레인스(JetBrains)에서 개발한 파이썬 전용 IDE로, 코드 작성, 실행, 디버깅, 테스트, 패키지 관리, 버전 관리 등을 한곳에서 수행할 수 있습니다. 파이참은 개발 생산성을 높이는 다음 기능을 제공합니다.

• 코드 자동 완성과 문법 검사로 작성 중인 코드의 오류를 실시간으로 확인할 수 있습니다.

• 프로젝트별 독립된 가상환경을 설정하여 손쉽게 패키지를 관리할 수 있습니다.

• 코드 실행을 멈추고 변수 값을 직접 확인할 수 있는 디버깅 기능을 제공합니다.

• 깃, 깃허브 같은 버전 관리 도구와 연동할 수 있어 개발 생산성을 높여 줍니다.
