10.9.1 원격 저장소 생성

태그 정보를 공유하는 데는 원격 저장소가 필요합니다. 깃허브 같은 호스팅 서비스를 이용하여 공개 저장소를 생성합니다. 책에서는 5장에서 생성한 깃허브 저장소를 사용하겠습니다. 먼저 깃허브에 로그인한 후 New 버튼 또는 + > New repository를 클릭합니다.

▼ 그림 10-12 깃허브에서 새 저장소 메뉴 선택

다음 화면에서 원하는 저장소 이름을 입력하고 Create repository를 누릅니다. 필자는 gitstudy10으로 정했는데, 로컬 저장소 이름과 동일하지 않아도 됩니다.
