10.9.2 태그 동기화

생성된 원격 저장소로 로컬 저장소의 태그 정보를 공유할 수 있습니다. 태그 정보는 원격 저장소로 자동 전송되지 않으므로 직접 동기화 명령을 수행해야 합니다.

로컬 저장소의 커밋을 원격 저장소로 전송할 때는 push 명령어를 사용합니다. 원격 저장소로 로컬 저장소의 브랜치는 다음과 같이 전송할 수 있습니다.

$ git push 브랜치이름

직접 실습해 봅시다. 로컬 저장소의 master 브랜치를 원격 저장소로 전송해 보겠습니다.

infoh@DESKTOP MINGW64 /e/gitstudy10 (master)


$ git push origin master 커밋 전송
