8.3.2 마스터 변경

이번에는 브랜치 모양을 변경해 보겠습니다. master 브랜치에도 새로운 커밋을 추가하여 실습을 진행하겠습니다. 먼저 hotfix 브랜치에서 master 브랜치로 이동합니다.

Switched to branch 'master'


 


infoh@DESKTOP MINGW64 /e/gitstudy08 (master) 원본 브랜치로 이동
