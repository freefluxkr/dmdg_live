12.4.2 저장소 분리

준비한 저장소에는 커밋이 4개 있습니다. 이 저장소를 2개로 분리해 보겠습니다.

1단계. 저장소를 분리할 수 있게 새로운 브랜치를 하나 생성합니다. 작업3을 기준으로 브랜치를 만듭니다.

infoh@DESKTOP MINGW64 /e/git-replace (master)


$ git branch worked 8681d97 work3 해시 값 입력
