지금까지 머신러닝의 기본 개념과 다양한 알고리즘을 살펴보았습니다. 이번 챕터에서는 현대 인공지능의 핵심인 신경망(Neural Network)에 대해 깊이 있게 다룹니다. 신경망은 인간의 뇌 구조에서 영감을 받아 설계된 모델로, 이미지 인식, 자연어 처리, 게임 플레이 등 수많은 분야에서 놀라운 성과를 거두고 있습니다.

이 챕터를 마치면 신경망이 어떻게 학습하는지 그 전체 흐름을 이해하고, 직접 간단한 신경망을 구현해 손글씨 숫자를 분류할 수 있게 됩니다.

💡 학습 목표 - 생물학적 뉴런에서 인공 뉴런의 개념이 어떻게 유래했는지 설명할 수 있습니다. - 퍼셉트론과 다층 퍼셉트론(MLP)의 구조를 이해합니다. - 주요 활성화 함수의 특징과 용도를 구분합니다. - 순전파, 손실함수, 역전파, 경사하강법으로 이어지는 학습 파이프라인을 이해합니다. - 최적화 기법과 과적합 방지 기법을 적용할 수 있습니다. - PyTorch로 MNIST 손글씨 분류 신경망을 구현합니다.

4.1 생물학적 뉴런에서 인공 뉴런으로

생물학적 뉴런의 구조

우리 뇌에는 약 860억 개의 뉴런(Neuron)이 있습니다. 각 뉴런은 다른 뉴런으로부터 신호를 받아 처리하고, 그 결과를 다음 뉴런으로 전달하는 역할을 합니다.

생물학적 뉴런의 주요 구성 요소는 다음과 같습니다.

  • 수상돌기(Dendrite): 다른 뉴런으로부터 신호를 수신합니다.
  • 세포체(Cell Body): 수신한 신호를 합산하고 처리합니다.
  • 축삭돌기(Axon): 처리된 신호를 다음 뉴런으로 전달합니다.
  • 시냅스(Synapse): 뉴런 간의 연결 부위로, 신호의 강도를 조절합니다.

뉴런은 입력 신호의 합계가 일정 임계값(Threshold)을 넘을 때만 활성화(발화)하여 다음 뉴런으로 신호를 전달합니다.

인공 뉴런의 탄생

1943년 워런 맥컬럭(Warren McCulloch)과 월터 피츠(Walter Pitts)는 생물학적 뉴런을 수학적으로 모델링한 인공 뉴런(Artificial Neuron)을 제안했습니다.

인공 뉴런의 동작 원리는 다음과 같습니다.

  1. 여러 입력값 $x_1, x_2, \ldots, x_n$을 받습니다.
  2. 각 입력에 가중치(Weight) $w_1, w_2, \ldots, w_n$를 곱합니다.
  3. 가중합(Weighted Sum)에 편향(Bias) $b$를 더합니다.
  4. 활성화 함수(Activation Function)를 통과시켜 최종 출력을 냅니다.

수식으로 표현하면 다음과 같습니다.

$$z = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b$$

$$\text{output} = f(z)$$

여기서 $f$는 활성화 함수입니다.

📌 생물학적 뉴런 vs 인공 뉴런 | 생물학적 뉴런 | 인공 뉴런 | |---|---| | 수상돌기 | 입력값 $x_i$ | | 시냅스 연결 강도 | 가중치 $w_i$ | | 세포체 신호 합산 | 가중합 계산 | | 임계값 초과 시 발화 | 활성화 함수 | | 축삭돌기 신호 전달 | 출력값 |

4.2 퍼셉트론과 다층 퍼셉트론(MLP)

퍼셉트론 (Perceptron)

1957년 프랑크 로젠블라트(Frank Rosenblatt)가 제안한 퍼셉트론(Perceptron)은 최초의 학습 가능한 인공 신경망입니다. 퍼셉트론은 입력층과 출력층 단 두 개의 층으로 구성됩니다.

퍼셉트론의 출력은 다음과 같습니다.

$$\hat{y} = \begin{cases} 1 & \text{if } \mathbf{w}^T \mathbf{x} + b \geq 0 \\ 0 & \text{otherwise} \end{cases}$$

퍼셉트론은 AND, OR 같은 선형 분리 가능한 문제는 풀 수 있지만, XOR 문제처럼 선형으로 분리되지 않는 문제는 풀 수 없다는 한계가 있습니다.

⚠️ 퍼셉트론의 한계 1969년 마빈 민스키(Marvin Minsky)와 시모어 페이퍼트(Seymour Papert)는 단층 퍼셉트론이 XOR 문제를 해결할 수 없음을 수학적으로 증명했습니다. 이 발견은 한동안 인공지능 연구를 침체시켰지만, 다층 구조를 통해 극복할 수 있었습니다.

다층 퍼셉트론 (MLP, Multi-Layer Perceptron)

퍼셉트론의 한계를 극복하기 위해 은닉층(Hidden Layer)을 추가한 다층 퍼셉트론(MLP)이 등장했습니다.

MLP는 다음 세 가지 층으로 구성됩니다.

  • 입력층(Input Layer): 데이터의 특성(Feature)을 받아들이는 층입니다.
  • 은닉층(Hidden Layer): 입력층과 출력층 사이에서 데이터를 변환합니다. 여러 개를 쌓을 수 있습니다.
  • 출력층(Output Layer): 최종 예측값을 출력하는 층입니다.

각 층의 뉴런은 이전 층의 모든 뉴런과 연결되어 있으며, 이를 완전 연결층(Fully Connected Layer) 또는 Dense 층이라고 합니다.

은닉층을 여러 겹 쌓은 신경망을 심층 신경망(Deep Neural Network, DNN)이라고 하며, 이것이 딥러닝(Deep Learning)의 어원입니다.

💡 왜 은닉층이 필요한가? 은닉층은 데이터에서 점점 더 추상적인 특징을 학습합니다. 예를 들어 이미지 인식에서 첫 번째 은닉층은 선과 모서리를, 두 번째는 도형을, 세 번째는 얼굴의 부위를 학습하는 식으로 계층적 특징 추출이 이루어집니다.

4.3 활성화 함수 (Sigmoid, ReLU, Softmax)

활성화 함수는 신경망에 비선형성(Non-linearity)을 부여합니다. 활성화 함수 없이 가중합만 계산하면, 아무리 층을 깊게 쌓아도 결국 하나의 선형 변환과 동일해집니다.

Sigmoid 함수

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Sigmoid 함수는 출력값을 0과 1 사이로 압축합니다. 이진 분류의 출력층에서 주로 사용됩니다.

특징 내용
출력 범위 (0, 1)
주요 용도 이진 분류 출력층
장점 확률 해석 가능
단점 기울기 소실(Vanishing Gradient) 문제 발생

⚠️ 기울기 소실 문제 Sigmoid는 입력값이 매우 크거나 작을 때 기울기가 거의 0이 됩니다. 역전파 시 기울기가 점점 작아져 초기 층의 학습이 매우 느려지는 기울기 소실(Vanishing Gradient) 문제가 발생합니다.

ReLU 함수 (Rectified Linear Unit)

$$\text{ReLU}(z) = \max(0, z)$$

ReLU는 현재 가장 널리 사용되는 활성화 함수입니다. 입력이 0보다 크면 그대로 출력하고, 0 이하면 0을 출력합니다.

특징 내용
출력 범위 $[0, +\infty)$
주요 용도 은닉층
장점 계산이 빠르고, 기울기 소실 문제 완화
단점 음수 입력에서 뉴런이 죽는 Dying ReLU 문제

ReLU의 변형으로는 음수 영역에 작은 기울기를 주는 Leaky ReLU, 부드러운 곡선 형태의 ELU, GELU 등이 있습니다.

Softmax 함수

$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

Softmax는 다중 분류 문제의 출력층에서 사용됩니다. 각 클래스의 출력값을 확률로 변환하며, 모든 출력의 합은 1이 됩니다.

예를 들어 숫자 0~9를 분류하는 경우, Softmax는 10개 클래스 각각의 확률을 반환합니다.

📌 활성화 함수 선택 가이드 | 위치 | 권장 함수 | |---|---| | 은닉층 (일반) | ReLU 또는 Leaky ReLU | | 이진 분류 출력층 | Sigmoid | | 다중 분류 출력층 | Softmax | | 회귀 출력층 | 없음 (Linear) |

활성화 함수 시각화 코드

import numpy as np
import matplotlib.pyplot as plt

z = np.linspace(-5, 5, 200)

# Sigmoid
sigmoid = 1 / (1 + np.exp(-z))

# ReLU
relu = np.maximum(0, z)

# Softmax는 벡터 입력이므로 간단한 예시
z_vec = np.array([2.0, 1.0, 0.5])
softmax = np.exp(z_vec) / np.sum(np.exp(z_vec))
print("Softmax 출력:", softmax)  # [0.659, 0.242, 0.099]

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].plot(z, sigmoid, label='Sigmoid', color='blue')
axes[0].set_title('Sigmoid')
axes[0].grid(True)
axes[0].axhline(0, color='k', linewidth=0.5)
axes[0].axvline(0, color='k', linewidth=0.5)

axes[1].plot(z, relu, label='ReLU', color='red')
axes[1].set_title('ReLU')
axes[1].grid(True)
axes[1].axhline(0, color='k', linewidth=0.5)
axes[1].axvline(0, color='k', linewidth=0.5)

plt.tight_layout()
plt.show()

위 코드를 실행하면 두 활성화 함수의 형태를 비교할 수 있습니다.

4.4 순전파 (Forward Propagation)

순전파(Forward Propagation)는 입력 데이터가 신경망의 입력층에서 출력층까지 차례로 계산되어 예측값을 만들어내는 과정입니다.

순전파 계산 과정

2개의 은닉층을 가진 신경망을 예로 들어봅니다.

층별 계산:

$$\mathbf{z}^{(1)} = \mathbf{W}^{(1)} \mathbf{x} + \mathbf{b}^{(1)}$$ $$\mathbf{a}^{(1)} = f(\mathbf{z}^{(1)})$$

$$\mathbf{z}^{(2)} = \mathbf{W}^{(2)} \mathbf{a}^{(1)} + \mathbf{b}^{(2)}$$ $$\mathbf{a}^{(2)} = f(\mathbf{z}^{(2)})$$

$$\hat{\mathbf{y}} = \text{Softmax}(\mathbf{W}^{(3)} \mathbf{a}^{(2)} + \mathbf{b}^{(3)})$$

여기서 $\mathbf{W}^{(l)}$는 $l$번째 층의 가중치 행렬, $\mathbf{b}^{(l)}$는 편향 벡터입니다.

NumPy로 구현하는 순전파

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def relu(z):
    return np.maximum(0, z)

def softmax(z):
    exp_z = np.exp(z - np.max(z))  # 수치 안정성을 위해 최댓값을 뺌
    return exp_z / np.sum(exp_z)

# 간단한 신경망 파라미터 초기화 (입력 2, 은닉 3, 출력 2)
np.random.seed(42)
W1 = np.random.randn(3, 2) * 0.1  # (은닉 뉴런 수, 입력 크기)
b1 = np.zeros(3)
W2 = np.random.randn(2, 3) * 0.1  # (출력 크기, 은닉 뉴런 수)
b2 = np.zeros(2)

# 입력 데이터
x = np.array([1.0, 2.0])

# 순전파
z1 = W1 @ x + b1          # 은닉층 가중합
a1 = relu(z1)              # 은닉층 활성화

z2 = W2 @ a1 + b2          # 출력층 가중합
y_hat = softmax(z2)        # 출력층 활성화 (확률)

print("예측 확률:", y_hat)

순전파는 계산 방향이 입력 → 출력으로 한 방향이기 때문에 매우 빠릅니다. 학습이 끝난 후 새로운 데이터에 대한 예측도 순전파만으로 수행합니다.

4.5 손실함수 (MSE, Cross-Entropy)

손실함수(Loss Function)는 모델의 예측값과 실제 정답 사이의 차이를 수치로 나타냅니다. 신경망의 목표는 이 손실값을 최소화하는 것입니다.

평균 제곱 오차 (MSE, Mean Squared Error)

$$\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

MSE는 주로 회귀(Regression) 문제에 사용됩니다. 예측값과 실제값의 차이를 제곱하여 평균을 냅니다. 제곱을 취하기 때문에 큰 오차에 더 큰 패널티를 부여합니다.

import numpy as np

def mse_loss(y_true, y_pred):
    return np.mean((y_true - y_pred) ** 2)

y_true = np.array([3.0, 5.0, 2.5])
y_pred = np.array([2.8, 4.5, 2.7])

loss = mse_loss(y_true, y_pred)
print(f"MSE 손실: {loss:.4f}")  # MSE 손실: 0.0933

교차 엔트로피 손실 (Cross-Entropy Loss)

$$\text{Cross-Entropy} = -\sum_{c=1}^{K} y_c \log(\hat{y}_c)$$

교차 엔트로피(Cross-Entropy)는 분류(Classification) 문제에 사용됩니다. 정답 클래스의 예측 확률이 낮을수록 손실이 크게 증가합니다.

이진 분류의 경우 이진 교차 엔트로피(Binary Cross-Entropy)를 사용합니다.

$$\text{BCE} = -[y \log(\hat{y}) + (1-y) \log(1-\hat{y})]$$

import numpy as np

def cross_entropy_loss(y_true, y_pred):
    # 수치 안정성을 위해 클리핑
    y_pred = np.clip(y_pred, 1e-12, 1 - 1e-12)
    return -np.sum(y_true * np.log(y_pred))

# 정답: 클래스 1 (원-핫 인코딩)
y_true = np.array([0, 1, 0])

# 좋은 예측 (정답 클래스 확률이 높음)
y_pred_good = np.array([0.1, 0.8, 0.1])
# 나쁜 예측 (정답 클래스 확률이 낮음)
y_pred_bad  = np.array([0.4, 0.2, 0.4])

print(f"좋은 예측의 손실: {cross_entropy_loss(y_true, y_pred_good):.4f}")  # 0.2231
print(f"나쁜 예측의 손실: {cross_entropy_loss(y_true, y_pred_bad):.4f}")   # 1.6094

📌 손실함수 선택 기준 | 문제 유형 | 권장 손실함수 | |---|---| | 회귀 | MSE (Mean Squared Error) | | 이진 분류 | Binary Cross-Entropy | | 다중 클래스 분류 | Categorical Cross-Entropy |

4.6 역전파 (Backpropagation)와 경사하강법

경사하강법 (Gradient Descent)

신경망의 학습은 손실함수를 최소화하는 가중치를 찾는 과정입니다. 경사하강법(Gradient Descent)은 손실함수의 기울기(Gradient)를 따라 파라미터를 조금씩 업데이트하는 최적화 알고리즘입니다.

$$W \leftarrow W - \eta \frac{\partial L}{\partial W}$$

여기서 $\eta$는 학습률(Learning Rate)으로, 한 번에 얼마나 이동할지를 결정합니다.

⚠️ 학습률의 중요성 - 학습률이 너무 크면: 손실값이 발산하거나 진동할 수 있습니다. - 학습률이 너무 작으면: 학습이 매우 느리고 지역 최솟값(Local Minimum)에 갇힐 수 있습니다. 일반적으로 0.001 ~ 0.01 사이의 값을 초기 학습률로 사용합니다.

역전파 (Backpropagation)

역전파(Backpropagation)는 손실함수에 대한 각 파라미터의 기울기를 효율적으로 계산하는 알고리즘입니다. 연쇄 법칙(Chain Rule)을 이용하여 출력층에서 입력층 방향으로 기울기를 전파합니다.

연쇄 법칙:

$$\frac{\partial L}{\partial W^{(1)}} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial a^{(2)}} \cdot \frac{\partial a^{(2)}}{\partial z^{(2)}} \cdot \frac{\partial z^{(2)}}{\partial a^{(1)}} \cdot \frac{\partial a^{(1)}}{\partial z^{(1)}} \cdot \frac{\partial z^{(1)}}{\partial W^{(1)}}$$

계산 과정을 단계별로 정리하면 다음과 같습니다.

  1. 순전파: 입력 데이터를 통해 예측값 $\hat{y}$를 계산합니다.
  2. 손실 계산: $L = \text{Loss}(y, \hat{y})$를 구합니다.
  3. 역전파: 연쇄 법칙으로 각 파라미터의 기울기 $\frac{\partial L}{\partial W}$를 계산합니다.
  4. 파라미터 업데이트: $W \leftarrow W - \eta \frac{\partial L}{\partial W}$
import numpy as np

# 간단한 1층 신경망의 역전파 예시 (MSE 손실, Sigmoid 활성화)
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    return a * (1 - a)

# 데이터
x = np.array([[1.0, 2.0]])  # 1개 샘플, 2개 특성
y = np.array([[1.0]])        # 정답

# 파라미터 초기화
np.random.seed(42)
W = np.random.randn(1, 2) * 0.1
b = np.zeros((1, 1))
lr = 0.1

# 학습 루프
for epoch in range(5):
    # 순전파
    z = x @ W.T + b
    a = sigmoid(z)

    # 손실 (MSE)
    loss = np.mean((y - a) ** 2)

    # 역전파
    dL_da = -2 * (y - a)           # 손실의 a에 대한 기울기
    da_dz = sigmoid_derivative(a)  # 활성화 함수의 기울기
    dL_dz = dL_da * da_dz

    dL_dW = dL_dz.T @ x           # W에 대한 기울기
    dL_db = np.sum(dL_dz, axis=0, keepdims=True)

    # 파라미터 업데이트
    W -= lr * dL_dW
    b -= lr * dL_db

    print(f"Epoch {epoch+1}, Loss: {loss:.6f}")

실제 딥러닝 프레임워크(PyTorch, TensorFlow)는 이 역전파 과정을 자동 미분(Automatic Differentiation) 기능으로 자동화합니다.

4.7 최적화 기법 (SGD, Adam)

확률적 경사하강법 (SGD, Stochastic Gradient Descent)

전체 데이터셋을 한 번에 사용하는 배치 경사하강법(Batch GD)은 데이터가 많을 때 매우 느립니다. SGD는 매 업데이트마다 무작위로 선택한 하나의 샘플만 사용하여 기울기를 계산합니다.

현실에서는 여러 샘플을 묶은 미니배치(Mini-batch)를 사용하는 미니배치 SGD가 표준입니다.

방법 업데이트에 사용하는 데이터 장점 단점
Batch GD 전체 데이터 안정적인 수렴 메모리 많이 사용, 느림
SGD 1개 샘플 빠른 업데이트 수렴이 불안정
Mini-batch SGD N개 샘플(배치) 속도와 안정성의 균형 배치 크기 튜닝 필요

모멘텀 (Momentum)

모멘텀(Momentum)은 이전 업데이트 방향을 일부 유지하여 진동을 줄이고 수렴 속도를 높이는 기법입니다.

$$v_t = \beta v_{t-1} + (1-\beta) \nabla L$$ $$W \leftarrow W - \eta v_t$$

Adam 최적화기 (Adaptive Moment Estimation)

Adam은 현재 가장 널리 사용되는 최적화 알고리즘입니다. 모멘텀과 RMSProp의 장점을 결합하여 각 파라미터마다 학습률을 개별적으로 조정합니다.

$$m_t = \beta_1 m_{t-1} + (1 - \beta_1) \nabla L \quad \text{(1차 모멘트, 기울기 평균)}$$ $$v_t = \beta_2 v_{t-1} + (1 - \beta_2) (\nabla L)^2 \quad \text{(2차 모멘트, 기울기 분산)}$$

$$\hat{m}_t = \frac{m_t}{1 - \beta_1^t}, \quad \hat{v}_t = \frac{v_t}{1 - \beta_2^t} \quad \text{(편향 보정)}$$

$$W \leftarrow W - \eta \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon}$$

기본 하이퍼파라미터는 $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\epsilon = 10^{-8}$을 사용합니다.

import torch
import torch.nn as nn

model = nn.Linear(10, 1)

# SGD 옵티마이저
optimizer_sgd = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# Adam 옵티마이저
optimizer_adam = torch.optim.Adam(model.parameters(), lr=0.001)

# RMSProp 옵티마이저
optimizer_rmsprop = torch.optim.RMSprop(model.parameters(), lr=0.001)

💡 어떤 옵티마이저를 선택해야 할까? 초보자라면 Adam을 기본값으로 사용하는 것을 권장합니다. Adam은 대부분의 경우에 잘 동작하며, 학습률에 비교적 덜 민감합니다. 학습률 $10^{-3}$ (0.001)이 좋은 출발점입니다.

4.8 과적합 방지 (드롭아웃, 배치 정규화, 조기 종료)

신경망은 학습 데이터에 지나치게 맞춰지는 과적합(Overfitting) 문제가 발생할 수 있습니다. 과적합이 발생하면 학습 데이터에서는 성능이 좋지만, 새로운 데이터(테스트 데이터)에서는 성능이 크게 떨어집니다.

드롭아웃 (Dropout)

드롭아웃(Dropout)은 학습 시 각 에포크마다 무작위로 일부 뉴런을 비활성화하는 기법입니다. 특정 뉴런에 대한 의존도를 줄여 모델이 더 강건(Robust)한 표현을 학습하도록 유도합니다.

드롭아웃 비율 $p$를 0.5로 설정하면 학습 시 절반의 뉴런이 무작위로 꺼집니다. 테스트 시에는 모든 뉴런을 활성화하고 출력에 $(1-p)$를 곱하여 스케일을 조정합니다.

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),     # 50% 뉴런 비활성화
    nn.Linear(256, 128),
    nn.ReLU(),
    nn.Dropout(p=0.3),     # 30% 뉴런 비활성화
    nn.Linear(128, 10),
    nn.Softmax(dim=1)
)

배치 정규화 (Batch Normalization)

배치 정규화(Batch Normalization)는 각 층의 입력을 미니배치 단위로 정규화(평균 0, 분산 1)하는 기법입니다. 학습을 안정시키고, 학습 속도를 높이며, 과적합도 줄이는 효과가 있습니다.

$$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$ $$y_i = \gamma \hat{x}_i + \beta$$

여기서 $\mu_B$와 $\sigma_B^2$는 미니배치의 평균과 분산, $\gamma$와 $\beta$는 학습 가능한 스케일·시프트 파라미터입니다.

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.BatchNorm1d(256),   # 배치 정규화
    nn.ReLU(),
    nn.Linear(256, 128),
    nn.BatchNorm1d(128),
    nn.ReLU(),
    nn.Linear(128, 10)
)

조기 종료 (Early Stopping)

조기 종료(Early Stopping)는 학습 과정에서 검증 손실(Validation Loss)이 더 이상 줄어들지 않으면 학습을 멈추는 기법입니다.

# 조기 종료 구현 예시
best_val_loss = float('inf')
patience = 5      # 개선 없이 허용하는 에포크 수
counter = 0

for epoch in range(100):
    train_loss = train_one_epoch(model, train_loader)
    val_loss = evaluate(model, val_loader)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        torch.save(model.state_dict(), 'best_model.pth')
        counter = 0
    else:
        counter += 1
        if counter >= patience:
            print(f"Early Stopping at epoch {epoch+1}")
            break

# 최적 모델 복원
model.load_state_dict(torch.load('best_model.pth'))

📌 정규화 기법 요약 | 기법 | 원리 | 효과 | |---|---|---| | 드롭아웃 | 뉴런 무작위 비활성화 | 과적합 방지 | | 배치 정규화 | 층 입력 정규화 | 학습 안정화, 속도 향상 | | 조기 종료 | 검증 손실 모니터링 | 과적합 방지 | | L1/L2 정규화 | 손실함수에 가중치 패널티 추가 | 가중치 희소화/축소 |

[실습] 간단한 신경망으로 손글씨 숫자 분류 (MNIST)

이제 지금까지 배운 개념을 모두 활용하여 MNIST 데이터셋으로 손글씨 숫자(0~9)를 분류하는 신경망을 구현해보겠습니다.

💡 MNIST 데이터셋 MNIST(Modified National Institute of Standards and Technology)는 0~9 손글씨 숫자 이미지 70,000장(훈련 60,000장 + 테스트 10,000장)으로 구성된 데이터셋입니다. 각 이미지는 28×28 픽셀의 흑백 이미지입니다. 딥러닝의 "Hello World"로 불릴 만큼 입문용으로 널리 사용됩니다.

전체 구현 코드

import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

# ─────────────────────────────────────────
# 1. 하이퍼파라미터 설정
# ─────────────────────────────────────────
BATCH_SIZE = 64
LEARNING_RATE = 0.001
EPOCHS = 10
DEVICE = 'cuda' if torch.cuda.is_available() else 'cpu'

print(f"사용 디바이스: {DEVICE}")

# ─────────────────────────────────────────
# 2. 데이터 로드 및 전처리
# ─────────────────────────────────────────
transform = transforms.Compose([
    transforms.ToTensor(),                  # PIL 이미지 → Tensor [0,1]
    transforms.Normalize((0.1307,), (0.3081,))  # MNIST 평균/표준편차로 정규화
])

train_dataset = datasets.MNIST(
    root='./data', train=True, download=True, transform=transform
)
test_dataset = datasets.MNIST(
    root='./data', train=False, download=True, transform=transform
)

train_loader = DataLoader(train_dataset, batch_size=BATCH_SIZE, shuffle=True)
test_loader  = DataLoader(test_dataset, batch_size=BATCH_SIZE, shuffle=False)

print(f"훈련 샘플 수: {len(train_dataset)}, 테스트 샘플 수: {len(test_dataset)}")

# ─────────────────────────────────────────
# 3. 데이터 시각화
# ─────────────────────────────────────────
examples = iter(train_loader)
images, labels = next(examples)

fig, axes = plt.subplots(2, 5, figsize=(10, 4))
for i, ax in enumerate(axes.flat):
    ax.imshow(images[i].squeeze(), cmap='gray')
    ax.set_title(f'Label: {labels[i].item()}')
    ax.axis('off')
plt.suptitle('MNIST 샘플 이미지')
plt.tight_layout()
plt.show()

# ─────────────────────────────────────────
# 4. 신경망 모델 정의
# ─────────────────────────────────────────
class MLP(nn.Module):
    def __init__(self):
        super(MLP, self).__init__()
        self.network = nn.Sequential(
            nn.Flatten(),                   # (B, 1, 28, 28) → (B, 784)

            nn.Linear(784, 256),            # 입력층 → 은닉층 1
            nn.BatchNorm1d(256),            # 배치 정규화
            nn.ReLU(),
            nn.Dropout(p=0.3),             # 드롭아웃

            nn.Linear(256, 128),            # 은닉층 1 → 은닉층 2
            nn.BatchNorm1d(128),
            nn.ReLU(),
            nn.Dropout(p=0.3),

            nn.Linear(128, 10)              # 은닉층 2 → 출력층 (10 클래스)
            # CrossEntropyLoss에 Softmax가 내장되어 있으므로 별도 Softmax 불필요
        )

    def forward(self, x):
        return self.network(x)

model = MLP().to(DEVICE)
print(model)
print(f"\n총 파라미터 수: {sum(p.numel() for p in model.parameters()):,}")

# ─────────────────────────────────────────
# 5. 손실함수와 옵티마이저 정의
# ─────────────────────────────────────────
criterion = nn.CrossEntropyLoss()          # 다중 분류 → 교차 엔트로피
optimizer = optim.Adam(model.parameters(), lr=LEARNING_RATE)

# ─────────────────────────────────────────
# 6. 학습 함수
# ─────────────────────────────────────────
def train(model, loader, criterion, optimizer, device):
    model.train()   # 학습 모드 (Dropout, BN 활성화)
    total_loss, correct = 0, 0

    for images, labels in loader:
        images, labels = images.to(device), labels.to(device)

        optimizer.zero_grad()           # 기울기 초기화
        outputs = model(images)         # 순전파
        loss = criterion(outputs, labels)  # 손실 계산
        loss.backward()                 # 역전파
        optimizer.step()                # 파라미터 업데이트

        total_loss += loss.item()
        _, predicted = outputs.max(1)
        correct += predicted.eq(labels).sum().item()

    avg_loss = total_loss / len(loader)
    accuracy = 100. * correct / len(loader.dataset)
    return avg_loss, accuracy

# ─────────────────────────────────────────
# 7. 평가 함수
# ─────────────────────────────────────────
def evaluate(model, loader, criterion, device):
    model.eval()    # 평가 모드 (Dropout 비활성화, BN 추론 통계 사용)
    total_loss, correct = 0, 0

    with torch.no_grad():               # 기울기 계산 비활성화
        for images, labels in loader:
            images, labels = images.to(device), labels.to(device)
            outputs = model(images)
            loss = criterion(outputs, labels)

            total_loss += loss.item()
            _, predicted = outputs.max(1)
            correct += predicted.eq(labels).sum().item()

    avg_loss = total_loss / len(loader)
    accuracy = 100. * correct / len(loader.dataset)
    return avg_loss, accuracy

# ─────────────────────────────────────────
# 8. 학습 실행 (조기 종료 포함)
# ─────────────────────────────────────────
train_losses, val_losses = [], []
train_accs, val_accs = [], []

best_val_loss = float('inf')
patience, counter = 5, 0

for epoch in range(1, EPOCHS + 1):
    train_loss, train_acc = train(model, train_loader, criterion, optimizer, DEVICE)
    val_loss, val_acc = evaluate(model, test_loader, criterion, DEVICE)

    train_losses.append(train_loss)
    val_losses.append(val_loss)
    train_accs.append(train_acc)
    val_accs.append(val_acc)

    print(f"Epoch [{epoch:2d}/{EPOCHS}] "
          f"Train Loss: {train_loss:.4f}, Train Acc: {train_acc:.2f}% | "
          f"Val Loss: {val_loss:.4f}, Val Acc: {val_acc:.2f}%")

    # 조기 종료
    if val_loss < best_val_loss:
        best_val_loss = val_loss
        torch.save(model.state_dict(), 'best_mnist_model.pth')
        counter = 0
    else:
        counter += 1
        if counter >= patience:
            print(f"\n조기 종료: {epoch}번째 에포크에서 종료합니다.")
            break

# 최적 모델 복원
model.load_state_dict(torch.load('best_mnist_model.pth'))
print(f"\n최적 모델 검증 손실: {best_val_loss:.4f}")

# ─────────────────────────────────────────
# 9. 학습 결과 시각화
# ─────────────────────────────────────────
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].plot(train_losses, label='Train Loss')
axes[0].plot(val_losses, label='Validation Loss')
axes[0].set_xlabel('Epoch')
axes[0].set_ylabel('Loss')
axes[0].set_title('학습 손실 곡선')
axes[0].legend()
axes[0].grid(True)

axes[1].plot(train_accs, label='Train Accuracy')
axes[1].plot(val_accs, label='Validation Accuracy')
axes[1].set_xlabel('Epoch')
axes[1].set_ylabel('Accuracy (%)')
axes[1].set_title('정확도 곡선')
axes[1].legend()
axes[1].grid(True)

plt.tight_layout()
plt.show()

# ─────────────────────────────────────────
# 10. 예측 결과 시각화
# ─────────────────────────────────────────
model.eval()
test_images, test_labels = next(iter(test_loader))
test_images = test_images.to(DEVICE)

with torch.no_grad():
    outputs = model(test_images)
    _, predictions = outputs.max(1)

test_images = test_images.cpu()
predictions = predictions.cpu()

fig, axes = plt.subplots(2, 5, figsize=(10, 4))
for i, ax in enumerate(axes.flat):
    ax.imshow(test_images[i].squeeze(), cmap='gray')
    color = 'green' if predictions[i] == test_labels[i] else 'red'
    ax.set_title(f'예측: {predictions[i].item()} / 정답: {test_labels[i].item()}',
                 color=color)
    ax.axis('off')
plt.suptitle('예측 결과 (초록: 정답, 빨강: 오답)')
plt.tight_layout()
plt.show()
