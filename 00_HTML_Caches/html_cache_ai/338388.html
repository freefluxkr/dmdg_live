지금까지 우리는 정답(레이블)이 있는 데이터로 모델을 학습시키는 지도학습을 살펴보았습니다. 하지만 현실 세계의 데이터 대부분은 레이블이 없습니다. 이 챕터에서는 레이블 없이도 데이터 속 패턴을 스스로 찾아내는 비지도학습(Unsupervised Learning)과, 시행착오를 통해 스스로 최선의 행동을 학습하는 강화학습(Reinforcement Learning)을 소개합니다.

학습 목표

  • 비지도학습의 개념과 지도학습과의 차이를 설명할 수 있다.
  • K-Means, DBSCAN, 계층적 클러스터링의 원리와 차이를 이해한다.
  • PCA를 통한 차원 축소의 개념을 이해한다.
  • 이상탐지와 연관규칙의 실제 활용 사례를 설명할 수 있다.
  • 강화학습의 핵심 구성요소(에이전트, 환경, 상태, 행동, 보상)를 설명할 수 있다.
  • Q-Learning의 기초 원리를 이해한다.
  • 강화학습이 실제로 적용되는 분야를 열거할 수 있다.

3.1 비지도학습의 개요 — 레이블 없는 학습

비지도학습(Unsupervised Learning)이란 정답(레이블)이 없는 데이터에서 숨겨진 구조나 패턴을 스스로 찾아내는 기계학습 방식입니다.

예를 들어, 수천 명의 고객 구매 데이터가 있을 때 "이 고객은 VIP다", "이 고객은 일반 고객이다"라는 레이블 없이도, 구매 패턴이 비슷한 고객끼리 자동으로 묶어주는 것이 비지도학습입니다.

구분 지도학습 비지도학습
레이블 필요 불필요
목표 정답 예측 패턴·구조 발견
대표 알고리즘 회귀, 분류 클러스터링, 차원축소
예시 스팸 메일 분류 고객 군집화

비지도학습의 주요 분야는 다음과 같습니다.

  • 클러스터링(Clustering): 비슷한 데이터끼리 그룹으로 묶기
  • 차원 축소(Dimensionality Reduction): 데이터의 특징을 줄여 핵심만 남기기
  • 이상 탐지(Anomaly Detection): 정상 패턴에서 벗어난 데이터 찾기
  • 연관 규칙(Association Rule): 함께 발생하는 패턴 찾기

💡 비지도학습은 레이블 작업 비용이 없어 실무에서 매우 광범위하게 사용됩니다. 인터넷에 쌓이는 방대한 비레이블 데이터를 활용할 수 있다는 점이 큰 장점입니다.

3.2 클러스터링 — K-Means, DBSCAN, 계층적 클러스터링

클러스터링(Clustering)은 데이터를 비슷한 것끼리 묶어 군집(Cluster)을 형성하는 기법입니다. 사람이 직접 분류 기준을 정하지 않아도, 알고리즘이 데이터의 유사성을 기반으로 자동으로 그룹을 나눕니다.

K-Means 클러스터링

K-Means는 가장 널리 쓰이는 클러스터링 알고리즘입니다. 사용자가 군집 수 K를 미리 지정하면, 알고리즘이 데이터를 K개의 군집으로 나눕니다.

작동 원리:

  1. K개의 중심점(센트로이드, Centroid)을 임의로 초기화합니다.
  2. 각 데이터를 가장 가까운 센트로이드에 할당합니다.
  3. 각 군집의 평균값으로 센트로이드를 재계산합니다.
  4. 센트로이드가 더 이상 변하지 않을 때까지 2~3을 반복합니다.

⚠️ K-Means는 K를 미리 정해야 하고, 원형 군집에 적합합니다. 불규칙한 형태의 군집이나 이상치가 많은 데이터에는 성능이 떨어질 수 있습니다.

DBSCAN

DBSCAN(Density-Based Spatial Clustering of Applications with Noise)은 밀도 기반 클러스터링 알고리즘입니다. K처럼 군집 수를 미리 정하지 않아도 되며, 불규칙한 모양의 군집도 잘 찾아냅니다.

핵심 개념은 "가까운 데이터가 충분히 많이 모여 있으면 하나의 군집"이라는 것입니다. 밀도가 낮은 곳에 홀로 있는 데이터는 노이즈(Noise)로 처리합니다.

구분 K-Means DBSCAN
군집 수 사전 지정 필요 자동 결정
군집 형태 원형에 적합 임의 형태 가능
이상치 처리 취약 노이즈로 처리
속도 빠름 데이터 크기에 따라 느려질 수 있음

계층적 클러스터링

계층적 클러스터링(Hierarchical Clustering)은 데이터를 계층 구조로 묶어가는 방식입니다. 결과를 덴드로그램(Dendrogram)이라는 나무 형태의 그림으로 표현하여 어떤 데이터가 먼저 묶이는지 한눈에 볼 수 있습니다.

  • 병합(Agglomerative) 방식: 각 데이터를 개별 군집으로 시작해 점점 합쳐나감 (아래에서 위로)
  • 분할(Divisive) 방식: 전체를 하나의 군집으로 시작해 점점 나눠나감 (위에서 아래로)

📌 계층적 클러스터링은 K를 미리 정하지 않아도 되고, 덴드로그램으로 군집 구조를 시각적으로 파악할 수 있다는 장점이 있습니다. 다만 데이터가 많아질수록 계산 비용이 급격히 증가합니다.

3.3 차원 축소 — PCA(주성분 분석)

데이터의 특징(Feature) 수가 너무 많으면 학습이 느려지고, 시각화도 어려워집니다. 이를 해결하기 위해 차원 축소(Dimensionality Reduction) 기법을 사용합니다.

PCA(Principal Component Analysis, 주성분 분석)는 대표적인 차원 축소 알고리즘입니다. 데이터의 분산(정보)을 최대한 보존하면서 새로운 축(주성분, Principal Component)으로 데이터를 변환하여 차원을 줄입니다.

💡 예를 들어 키와 몸무게, 허리둘레 3가지 특징이 있을 때, PCA는 이 3가지 정보를 최대한 담는 2개(또는 1개)의 새로운 축을 만들어 냅니다.

PCA의 주요 활용:

  • 고차원 데이터를 2D/3D로 줄여 시각화
  • 머신러닝 모델 학습 속도 향상
  • 중복되거나 불필요한 특징 제거 (노이즈 감소)

PCA 핵심 파라미터:

  • n_components: 축소할 차원 수 (예: 2이면 2차원으로 축소)
  • explained_variance_ratio_: 각 주성분이 전체 분산 중 몇 %를 설명하는지 나타냄

⚠️ PCA로 축소된 축은 원래 특징의 의미를 잃어버리므로, "첫 번째 주성분이 무엇을 의미하는지" 직관적으로 해석하기 어렵습니다.

3.4 이상탐지와 연관규칙

이상탐지

이상탐지(Anomaly Detection)는 정상 패턴에서 크게 벗어난 데이터(이상치, Anomaly)를 찾아내는 기법입니다. 대부분의 데이터가 정상이고 이상치는 매우 드물기 때문에 레이블 없이 학습하는 비지도학습 방식이 많이 사용됩니다.

실제 활용 사례:

  • 금융: 신용카드 부정 사용(사기) 탐지
  • 제조: 공장 설비의 이상 징후 감지
  • 네트워크: 사이버 침입 탐지
  • 의료: 비정상적인 진단 수치 감지

대표 알고리즘으로는 Isolation Forest, One-Class SVM, Autoencoder 등이 있습니다.

연관규칙

연관규칙(Association Rule)은 대량의 거래 데이터에서 "함께 자주 등장하는 항목들의 규칙"을 찾는 기법입니다. 대형마트의 장바구니 분석이 가장 유명한 예시입니다.

💡 "기저귀를 산 고객은 맥주도 함께 산다"는 실제 마트 데이터 분석에서 발견된 유명한 연관규칙 사례입니다.

주요 지표:

  • 지지도(Support): 전체 거래 중 해당 조합이 등장하는 비율
  • 신뢰도(Confidence): A를 샀을 때 B도 살 확률
  • 향상도(Lift): 연관규칙이 우연보다 얼마나 강한지 나타내는 값 (1보다 크면 양의 연관)

대표 알고리즘: Apriori, FP-Growth

3.5 강화학습의 개요 — 에이전트, 환경, 상태, 행동, 보상

강화학습(Reinforcement Learning, RL)은 에이전트(Agent)가 환경(Environment)과 상호작용하면서 시행착오를 통해 최대 보상(Reward)을 얻는 방법을 스스로 학습하는 방식입니다.

게임을 처음 배우는 아이를 떠올려보세요. 규칙을 누가 알려주지 않아도, 여러 번 플레이하면서 어떤 행동이 점수를 올리는지 스스로 터득하는 것과 같은 원리입니다.

강화학습의 핵심 구성요소:

구성요소 설명 예시 (체스 게임)
에이전트(Agent) 학습하고 행동하는 주체 AI 체스 플레이어
환경(Environment) 에이전트가 상호작용하는 세계 체스 보드
상태(State) 현재 환경의 상황 현재 말의 위치
행동(Action) 에이전트가 취할 수 있는 선택 말을 어디로 이동할지
보상(Reward) 행동의 결과로 받는 피드백 상대 말을 잡으면 +1, 지면 -1
정책(Policy) 상태에서 행동을 선택하는 전략 "이 상황에서는 이 말을 움직이자"

강화학습의 학습 흐름:

  1. 에이전트가 현재 상태(State)를 관찰합니다.
  2. 정책(Policy)에 따라 행동(Action)을 선택합니다.
  3. 환경이 보상(Reward)과 다음 상태(Next State)를 반환합니다.
  4. 에이전트는 누적 보상이 최대가 되도록 정책을 업데이트합니다.
  5. 1~4를 반복합니다.

📌 강화학습은 지도학습처럼 정답을 알려주지 않습니다. 오직 보상 신호만으로 좋은 행동과 나쁜 행동을 스스로 구분하며 학습합니다.

3.6 Q-Learning 기초 개념

Q-Learning은 강화학습의 가장 기초적인 알고리즘 중 하나입니다. 각 (상태, 행동) 쌍에 대해 Q값(Q-value)이라는 "기대 누적 보상"을 계산하고, 이 Q값을 기반으로 행동을 선택합니다.

Q값을 저장하는 표를 Q-테이블(Q-Table)이라고 합니다. 행은 상태(State), 열은 행동(Action)을 나타내며, 학습이 진행될수록 Q값이 점점 정확해집니다.

Q값 업데이트 공식 (벨만 방정식):

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

  • s: 현재 상태, a: 선택한 행동
  • r: 받은 보상
  • s': 다음 상태
  • α (알파): 학습률 — 새 정보를 얼마나 빠르게 반영할지
  • γ (감마): 할인율 — 미래 보상을 현재 가치로 얼마나 환산할지

💡 할인율 γ가 1에 가까울수록 먼 미래의 보상도 중요하게 여기고, 0에 가까울수록 당장의 보상만 중요하게 여깁니다.

Q-Learning의 한계와 발전:

Q-테이블은 상태와 행동의 수가 적을 때는 잘 동작하지만, 체스나 바둑처럼 상태 공간이 거대할 때는 테이블 자체를 만들 수 없습니다. 이 한계를 극복하기 위해 딥러닝을 결합한 DQN(Deep Q-Network)이 등장했습니다.

3.7 강화학습의 실제 적용 사례

강화학습은 다양한 분야에서 놀라운 성과를 거두고 있습니다.

게임

  • AlphaGo / AlphaZero (DeepMind): 바둑 세계 챔피언을 이긴 AI. 강화학습으로 자기 자신과 대국하며 스스로 실력을 키웠습니다.
  • OpenAI Five: 팀 협동 게임 Dota 2에서 프로 팀을 이긴 AI.
  • Atari 게임: DQN이 픽셀만 보고 수십 가지 아타리 게임을 사람 수준 이상으로 플레이했습니다.

로봇공학

로봇 팔이 물체를 집는 방법, 두발로 걷는 방법 등을 사람이 일일이 코딩하지 않고 강화학습으로 스스로 터득합니다. Boston Dynamics의 로봇 등이 대표적인 연구 사례입니다.

자율주행

차선 변경, 교차로 통과 등 복잡한 교통 상황에서의 의사결정에 강화학습이 활용됩니다. 시뮬레이터 환경에서 수백만 번의 가상 주행을 통해 안전한 주행 정책을 학습합니다.

RLHF — 대형 언어 모델의 핵심 기술

RLHF(Reinforcement Learning from Human Feedback, 인간 피드백 강화학습)는 ChatGPT, Claude와 같은 대형 언어 모델(LLM)을 사람의 선호에 맞게 정렬(Alignment)하는 핵심 기술입니다.

RLHF 학습 과정:

  1. 사전 학습된 언어 모델이 여러 응답을 생성합니다.
  2. 사람이 응답의 품질을 평가하고 순위를 매깁니다.
  3. 이 데이터로 보상 모델(Reward Model)을 학습합니다.
  4. 보상 모델을 환경으로 삼아 언어 모델을 강화학습으로 미세조정합니다.

📌 RLHF 덕분에 AI가 단순히 다음 단어를 예측하는 것을 넘어, 사람이 원하는 유용하고 안전한 응답을 생성하도록 발전할 수 있었습니다.

[실습] K-Means 클러스터링으로 데이터 군집화하기

이제 Python으로 K-Means 클러스터링을 직접 실습해 보겠습니다. scikit-learn의 내장 데이터셋을 활용하여 데이터를 군집화하고 시각화합니다.

환경 준비

다음 라이브러리가 필요합니다. 설치되어 있지 않다면 아래 명령어로 설치하세요.

pip install scikit-learn matplotlib numpy

실습 1: 기본 K-Means 클러스터링

먼저 샘플 데이터를 생성하고 K-Means로 군집화합니다.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

# 1. 샘플 데이터 생성 (300개 데이터, 4개 군집)
X, y_true = make_blobs(n_samples=300, centers=4,
                        cluster_std=0.60, random_state=42)

# 2. K-Means 모델 생성 및 학습
kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
kmeans.fit(X)

# 3. 군집 레이블과 중심점 확인
labels = kmeans.labels_
centers = kmeans.cluster_centers_

print("군집 레이블 (처음 10개):", labels[:10])
print("군집 중심점:\n", centers)

# 4. 결과 시각화
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=labels, cmap='viridis',
            s=50, alpha=0.8, label='데이터')
plt.scatter(centers[:, 0], centers[:, 1],
            c='red', marker='X', s=200, label='중심점')
plt.title('K-Means 클러스터링 결과')
plt.xlabel('Feature 1')
plt.ylabel('Feature 2')
plt.legend()
plt.tight_layout()
plt.show()

실행하면 4개의 군집이 서로 다른 색으로 표시되고, 빨간 X가 각 군집의 중심점입니다.

실습 2: 최적의 K 찾기 — 엘보우 방법

K-Means에서 가장 중요한 것은 적절한 K를 선택하는 것입니다. 엘보우 방법(Elbow Method)은 K를 바꿔가며 관성(Inertia) — 각 데이터와 소속 중심점 사이의 거리 합 — 을 계산하여 최적의 K를 찾습니다.

# 엘보우 방법으로 최적 K 탐색
inertia_list = []
k_range = range(1, 11)

for k in k_range:
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(X)
    inertia_list.append(km.inertia_)

# 엘보우 그래프 시각화
plt.figure(figsize=(8, 5))
plt.plot(k_range, inertia_list, marker='o', color='steelblue')
plt.axvline(x=4, color='red', linestyle='--', label='최적 K=4')
plt.title('엘보우 방법 — 최적 K 찾기')
plt.xlabel('군집 수 (K)')
plt.ylabel('관성 (Inertia)')
plt.legend()
plt.tight_layout()
plt.show()

그래프에서 기울기가 급격히 완만해지는 "팔꿈치" 지점이 최적의 K입니다.

💡 위 예시에서는 K=4 근방에서 기울기가 꺾이는 것을 확인할 수 있습니다. 실제 데이터에서는 명확한 엘보우가 나타나지 않을 수도 있으며, 이때는 실루엣 계수(Silhouette Score) 등 다른 지표를 함께 사용합니다.

실습 3: 실제 데이터에 적용 — 붓꽃(Iris) 데이터셋

이번에는 유명한 붓꽃 데이터셋에 K-Means를 적용하고 PCA로 시각화합니다.

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. 데이터 로드
iris = load_iris()
X_iris = iris.data          # 4개 특징 (꽃잎 길이/너비 등)
y_iris = iris.target        # 실제 종 (시각화 비교용)

# 2. 데이터 표준화 (K-Means는 거리 기반이므로 스케일링 필수)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_iris)

# 3. K-Means 클러스터링 (K=3, 붓꽃 종류가 3가지)
kmeans_iris = KMeans(n_clusters=3, random_state=42, n_init=10)
kmeans_iris.fit(X_scaled)
labels_iris = kmeans_iris.labels_

# 4. PCA로 2차원 축소 후 시각화
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# K-Means 군집 결과
axes[0].scatter(X_pca[:, 0], X_pca[:, 1],
                c=labels_iris, cmap='Set1', s=60, alpha=0.8)
axes[0].set_title('K-Means 군집화 결과 (PCA 2D)')
axes[0].set_xlabel('PC1')
axes[0].set_ylabel('PC2')

# 실제 정답 레이블
axes[1].scatter(X_pca[:, 0], X_pca[:, 1],
                c=y_iris, cmap='Set1', s=60, alpha=0.8)
axes[1].set_title('실제 붓꽃 종류 (정답)')
axes[1].set_xlabel('PC1')
axes[1].set_ylabel('PC2')

print(f"PCA 설명 분산 비율: {pca.explained_variance_ratio_}")
print(f"PC1+PC2 누적 설명력: {sum(pca.explained_variance_ratio_):.1%}")

plt.tight_layout()
plt.show()

📌 K-Means 결과와 실제 정답을 나란히 비교해보세요. 레이블 없이도 실제 종 분류와 상당히 유사한 군집을 만들어 낸 것을 확인할 수 있습니다.
