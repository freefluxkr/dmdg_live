이 파트에서는 데이터베이스 기초와 RAG(Retrieval-Augmented Generation) 기술을 학습합니다.

SQL 기본 문법부터 시작하여, LLM의 한계(할루시네이션, 지식 컷오프)를 보완하는 RAG 아키텍처를 이해하고, 실제로 사내 문서 기반 QA 시스템을 구축합니다.

학습 목표

  • SQL 기본 문법(CRUD, JOIN, 집계함수)을 사용할 수 있습니다.
  • Python에서 MySQL 데이터베이스에 연결하여 데이터를 처리할 수 있습니다.
  • RAG의 전체 파이프라인(청킹 → 임베딩 → 벡터 저장 → 검색 → 생성)을 이해합니다.
  • ChromaDB와 GPT를 연동하여 문서 기반 QA 시스템을 구축할 수 있습니다.
