13.1 API란 무엇인가 — REST API의 기본 개념

API(Application Programming Interface)는 서로 다른 소프트웨어가 정해진 규칙으로 대화하는 창구입니다. 식당으로 비유하면, 손님(내 코드)이 메뉴를 보고 종업원(API)에게 주문하면 주방(AI 서버)이 요리를 만들어 가져다주는 구조입니다.

REST API(Representational State Transfer API)는 웹에서 가장 널리 쓰이는 API 설계 방식입니다. HTTP 프로토콜을 사용해 요청을 보내고 응답을 받으며, 데이터는 주로 JSON(JavaScript Object Notation) 형식으로 주고받습니다.

REST API의 핵심 요소는 다음과 같습니다.

요소 설명 예시
엔드포인트(Endpoint) API 서버의 주소 https://api.openai.com/v1/chat/completions
HTTP 메서드 요청의 종류 GET(조회), POST(생성), PUT(수정), DELETE(삭제)
헤더(Header) 요청 부가 정보 인증 키, 콘텐츠 타입 등
바디(Body) 요청 본문 데이터 JSON 형식의 메시지, 모델명 등
응답(Response) 서버가 돌려주는 결과 JSON 형식의 AI 답변

AI API를 호출할 때는 항상 POST 메서드를 사용하고, 헤더에 API 키(API Key)를 담아 자신이 정당한 사용자임을 증명합니다.

내 코드(Python 클라이언트)가 헤더에 API 키, 바디에 JSON 메시지를 담아 HTTPS POST 로 AI 서버 엔드포인트를 호출하면, 서버는 모델 응답을 다시 JSON으로 돌려줍니다. 모든 통신은 TLS로 암호화되며 API 키는 헤더의 Authorization 필드를 통해서만 전달됩니다.

💡 API 키는 신분증입니다. 키가 노출되면 다른 사람이 내 이름으로 비용을 발생시킬 수 있으니 절대 공개 저장소에 올리지 않도록 주의합니다.

13.2 OpenAI API Key 발급 및 환경변수 등록

OpenAI API 키는 GPT 모델을 코드로 호출하기 위한 인증 수단입니다.

발급 절차

1단계 — OpenAI 계정 생성 및 로그인

https://platform.openai.com 에 접속합니다. 구글 계정, 마이크로소프트 계정, 또는 이메일로 회원가입합니다. 이미 ChatGPT 계정이 있다면 같은 계정으로 로그인합니다.

2단계 — API Keys 페이지 이동

로그인 후 화면 왼쪽 사이드바에서 API Keys 메뉴를 클릭합니다. 또는 https://platform.openai.com/api-keys 로 직접 접속합니다.

3단계 — 새 키 생성

+ Create new secret key 버튼을 클릭합니다. 키 이름(Name)을 입력합니다(예: my-api-key). Create secret key 버튼을 클릭합니다.

4단계 — 키 복사 및 저장

생성된 키는 sk-proj-... 또는 sk-... 형태입니다. 이 화면을 벗어나면 키를 다시 볼 수 없으니 반드시 복사해 안전한 곳에 저장합니다.

⚠️ 주의: 키를 잃어버렸다면 새로 발급받아야 합니다. 분실이나 노출이 의심될 경우 즉시 Revoke 버튼으로 폐기합니다.

5단계 — 결제 수단 등록

API 사용에는 비용이 발생합니다. Settings > Billing 에서 신용카드를 등록합니다. 소액(예: $5~$10)을 충전하여 시작합니다.

환경변수 등록

발급받은 키를 운영체제 환경변수에 등록합니다.

Windows (PowerShell)

[System.Environment]::SetEnvironmentVariable("OPENAI_API_KEY", "sk-...", "User")

macOS / Linux (bash 또는 zsh)

echo 'export OPENAI_API_KEY="sk-..."' >> ~/.bashrc
source ~/.bashrc

등록 후 터미널을 새로 열어 다음 명령으로 확인합니다.

echo $OPENAI_API_KEY

13.6 토큰(Token)의 개념과 비용 계산

토큰이란

토큰(Token)은 AI 모델이 텍스트를 처리하는 최소 단위입니다. 단어와 비슷하지만 정확히 같지는 않습니다.

  • 영문 기준: 1 토큰 ≈ 0.75 단어 (약 4글자)
  • 한글 기준: 1 글자 ≈ 1~3 토큰 (한글은 영문보다 토큰 소비가 많습니다)

예를 들어 "Hello, world!" 는 약 4 토큰이고, "안녕하세요, 세상아!" 는 약 8~12 토큰입니다.

토큰 계산 예시

파이썬에서 tiktoken 라이브러리로 OpenAI 모델의 토큰 수를 직접 계산할 수 있습니다.

import tiktoken

# GPT-4o 모델의 인코더 불러오기
enc = tiktoken.encoding_for_model("gpt-4o")

text = "안녕하세요. 오늘 날씨가 정말 좋네요!"
tokens = enc.encode(text)

print(f"텍스트: {text}")
print(f"토큰 수: {len(tokens)}")
print(f"토큰 목록: {tokens}")

비용 계산 공식

비용 = (입력 토큰 수 / 1,000,000) × 입력 단가
     + (출력 토큰 수 / 1,000,000) × 출력 단가

예를 들어 GPT-5 mini(입력 $0.25 / 출력 $2.00)로 입력 1,000 토큰, 출력 500 토큰을 사용했을 때의 비용입니다.

입력 비용 = (1,000 / 1,000,000) × $0.25 = $0.00025
출력 비용 = (500  / 1,000,000) × $2.00 = $0.00100
합계      = $0.00125 (약 1.7원, 2026년 환율 기준)

💡 비용 관리 팁: 각 플랫폼 콘솔의 Usage 또는 Billing 페이지에서 누적 사용량과 비용을 실시간으로 확인할 수 있습니다. 월 한도(Spending Limit)를 설정하면 예상치 못한 과금을 방지할 수 있습니다.

13.8 환경변수와 .env 파일로 Key 안전하게 관리하기

API 키는 절대 코드에 직접 입력해서는 안 됩니다. 코드를 깃허브 등에 공개할 경우 키가 노출되어 타인이 내 계정으로 비용을 발생시킬 수 있습니다.

.env 파일 방식

.env 파일은 환경변수를 파일로 관리하는 표준적인 방법입니다. 프로젝트 루트 폴더에 .env 파일을 만들고 키를 저장합니다.

.env 파일 예시입니다.

OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxx
GOOGLE_API_KEY=AIzaxxxxxxxxxxxxxxxxxxxxxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxx

파이썬 코드에서 python-dotenv 라이브러리로 이 파일을 불러옵니다.

from dotenv import load_dotenv
import os

# .env 파일의 환경변수를 불러옵니다
load_dotenv()

openai_key = os.getenv("OPENAI_API_KEY")
google_key = os.getenv("GOOGLE_API_KEY")

[실습] GPT / Gemini / Claude API 각각 첫 호출 테스트

지금까지 설정한 환경을 바탕으로 세 플랫폼 API를 각각 호출해봅니다. 모든 코드는 같은 질문("파이썬이란 무엇인지 한 문장으로 설명해줘")을 각 플랫폼에 보내고 답변을 출력합니다.

프로젝트 폴더 구조를 다음과 같이 준비합니다.

실습 1 — OpenAI GPT API 첫 호출

# ch13_gpt_test.py
from dotenv import load_dotenv
import os
from openai import OpenAI

# 환경변수 로드
load_dotenv()

# 클라이언트 초기화 (API 키는 환경변수에서 자동으로 읽습니다)
client = OpenAI()

# API 호출
response = client.chat.completions.create(
    model="gpt-5-mini",            # 2026년 기준 저비용 일반 모델. 폐기 시 gpt-4.1-mini 등으로 교체
    messages=[
        {
            "role": "user",
            "content": "파이썬이란 무엇인지 한 문장으로 설명해줘"
        }
    ],
    max_tokens=100                 # 최대 응답 토큰 수 제한
)

# 응답 텍스트 추출
answer = response.choices[0].message.content
print("GPT 응답:", answer)

# 토큰 사용량 확인
usage = response.usage
print(f"입력 토큰: {usage.prompt_tokens}, 출력 토큰: {usage.completion_tokens}")

예상 출력

GPT 응답: 파이썬은 간결하고 읽기 쉬운 문법을 가진 범용 프로그래밍 언어로, 데이터 분석, 웹 개발, 인공지능 등 다양한 분야에서 널리 사용됩니다.
입력 토큰: 28, 출력 토큰: 52

실습 2 — Google Gemini API 첫 호출

신규 google-genai SDK 사용 예시입니다(2025년 이후 공식 권장).

# ch13_gemini_test.py
from dotenv import load_dotenv
import os
from google import genai

# 환경변수 로드
load_dotenv()

# 클라이언트 초기화 (GOOGLE_API_KEY 환경변수를 자동으로 사용)
client = genai.Client()

# API 호출
response = client.models.generate_content(
    model="gemini-2.5-flash",      # 2026년 기준 무료 티어 가능 빠른 모델. 폐기 시 최신 Flash 계열로 교체
    contents="파이썬이란 무엇인지 한 문장으로 설명해줘",
)

# 응답 텍스트 추출
print("Gemini 응답:", response.text)

# 토큰 사용량 확인
usage = response.usage_metadata
print(f"입력 토큰: {usage.prompt_token_count}, 출력 토큰: {usage.candidates_token_count}")

💡 기존 google-generativeai(구 SDK)를 그대로 쓰는 경우, genai.configure(...) → genai.GenerativeModel("gemini-2.5-flash").generate_content(...) 형태로 호출합니다. 새 코드는 위의 google-genai 신 SDK 패턴을 권장합니다.

예상 출력

Gemini 응답: 파이썬은 가독성 높은 문법과 방대한 라이브러리 생태계를 갖춘 인터프리터 방식의 범용 프로그래밍 언어입니다.
입력 토큰: 22, 출력 토큰: 38
