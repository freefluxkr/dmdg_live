이 챕터에서는 클라우드 API에 의존하지 않고 자신의 컴퓨터에서 직접 LLM(Large Language Model)을 실행하는 방법을 배웁니다. Ollama와 LM Studio 같은 도구를 활용해 로컬 환경에서 강력한 AI 모델을 구동하고, 기존 애플리케이션과 연동하는 실전 기술을 익힙니다.

25.1 로컬 LLM 실행의 의의 — 비용, 프라이버시, 오프라인

로컬 LLM(Local LLM)이란 OpenAI, Anthropic 등 외부 서버를 거치지 않고 자신의 하드웨어에서 직접 실행하는 언어 모델을 말합니다. 클라우드 API가 편리하지만, 로컬 실행이 더 나은 선택인 경우가 분명히 존재합니다.

비용 절감

클라우드 API는 토큰(token) 단위로 과금됩니다. 프로토타이핑 단계나 대용량 텍스트를 반복 처리할 때는 비용이 빠르게 누적됩니다. 로컬 LLM은 초기 하드웨어 비용만 지불하면 이후 사용량에 따른 추가 비용이 없습니다.

프라이버시와 보안

금융 데이터, 의료 기록, 내부 문서 등 민감한 정보를 외부 서버로 전송할 수 없는 경우가 많습니다. 로컬 LLM은 데이터가 자신의 장비를 벗어나지 않으므로 데이터 컴플라이언스(data compliance) 요구사항을 충족하기 훨씬 유리합니다.

오프라인 환경

인터넷이 불안정하거나 차단된 환경(보안 시설, 원격지, 항공기 내 등)에서도 AI 기능을 제공할 수 있습니다. 한 번 모델을 내려받으면 네트워크 없이도 완전하게 동작합니다.

모델 커스터마이징

클라우드 API는 제공자가 정해놓은 모델만 사용할 수 있지만, 로컬 환경에서는 파인튜닝(fine-tuning)된 전용 모델이나 특수 목적 모델을 자유롭게 교체할 수 있습니다.

정리: 로컬 LLM은 비용, 보안, 가용성, 유연성 네 가지 측면에서 클라우드 API와 상호 보완적인 관계입니다. 두 방식을 상황에 맞게 선택하는 것이 핵심입니다.

25.2 하드웨어 요구사항 (GPU, RAM, VRAM)

로컬 LLM의 성능은 하드웨어에 직결됩니다. 모델 크기와 실행 방식에 따라 요구사항이 크게 달라집니다.

모델 크기와 파라미터

파라미터(parameter) 수는 모델 크기를 나타내는 주요 지표입니다. 일반적으로 다음과 같이 분류합니다.

모델 규모 파라미터 수 대표 모델 최소 VRAM
소형 1B ~ 3B Phi-3 Mini, Gemma 2B 4 GB
중형 7B ~ 13B Llama 3.1 8B, Mistral 7B 8 GB
대형 30B ~ 70B Llama 3.1 70B, Qwen 72B 24 GB 이상
초대형 100B 이상 Llama 3.1 405B 80 GB 이상

양자화(Quantization)

양자화(quantization)는 모델의 가중치를 더 낮은 정밀도로 압축해 메모리 사용량을 줄이는 기법입니다. 품질을 약간 희생하는 대신 훨씬 적은 VRAM으로 큰 모델을 실행할 수 있습니다.

양자화 형식 설명 메모리 절감 품질 손실
FP32 32비트 부동소수점 (원본) 기준 없음
FP16 / BF16 16비트 부동소수점 ~50% 거의 없음
GGUF Q8 8비트 양자화 ~75% 매우 낮음
GGUF Q4 4비트 양자화 ~87% 낮음
GGUF Q2 2비트 양자화 ~93% 중간

실용 팁: 일반적으로 Q4_K_M 또는 Q5_K_M 형식이 품질과 메모리 효율의 균형이 가장 좋습니다.

7B 모델을 기준으로 양자화를 적용하면 FP32 대비 메모리를 최대 87% 절감(28GB → 4GB)할 수 있으며, 품질 손실은 약 12%p 수준에 그칩니다. 8GB VRAM에서 7B 모델을 실행하려면 Q4_K_M, 12GB 이상이면 Q5_K_M을 권장합니다.

CPU vs GPU 실행

  • GPU 실행: VRAM(Video RAM)에 모델을 올려 병렬 처리하므로 속도가 빠릅니다. NVIDIA GPU는 CUDA, AMD GPU는 ROCm을 활용합니다.
  • CPU 실행: GPU가 없어도 시스템 RAM을 이용해 실행 가능합니다. 속도는 느리지만 접근성이 높습니다.
  • 하이브리드: 일부 레이어는 GPU VRAM에, 나머지는 RAM에 올리는 혼합 방식도 지원합니다.

권장 최소 사양

목적 RAM GPU VRAM 권장 모델
입문/학습 16 GB 불필요 (CPU) Phi-3 Mini 3.8B Q4
실용적 사용 32 GB 8 GB Llama 3.1 8B Q4
업무급 64 GB 24 GB Mistral 22B Q4

25.3 Ollama 설치 및 모델 다운로드

Ollama는 로컬 LLM을 가장 쉽게 실행할 수 있게 해주는 오픈소스 도구입니다. 복잡한 환경 설정 없이 단 몇 개의 명령어로 다양한 모델을 내려받고 실행할 수 있습니다.

ollama run CLI, OpenAI SDK, LangChain 등 어떤 클라이언트가 호출하든 모두 Ollama 데몬(ollama serve, localhost:11434)으로 들어가고, 데몬은 내부적으로 llama.cpp 추론 엔진과 GGUF 모델 파일을 결합해 응답을 만들어냅니다. /v1 엔드포인트가 OpenAI 호환이라 기존 SDK 코드는 base_url만 바꾸면 그대로 작동합니다.

설치

운영체제별 설치 방법은 다음과 같습니다.

macOS / Linux

curl -fsSL https://ollama.com/install.sh | sh

Windows

Ollama 공식 사이트(https://ollama.com)에서 Windows 설치 파일을 내려받아 실행합니다.

설치 후 버전을 확인합니다.

ollama --version

모델 다운로드 및 실행

ollama run 명령 하나로 모델 다운로드와 실행을 동시에 처리합니다.

REST API 서버

Ollama는 백그라운드에서 REST API 서버를 자동으로 실행합니다. 기본 주소는 http://localhost:11434입니다.

# 서버 상태 확인
curl http://localhost:11434

# 설치된 모델 목록 (API)
curl http://localhost:11434/api/tags

Python으로 API 호출

import requests
import json

def chat_with_ollama(prompt: str, model: str = "llama3.2") -> str:
    """Ollama REST API를 통해 모델과 대화합니다."""
    url = "http://localhost:11434/api/generate"

    payload = {
        "model": model,
        "prompt": prompt,
        "stream": False  # 스트리밍 비활성화로 전체 응답 한 번에 수신
    }

    response = requests.post(url, json=payload)
    response.raise_for_status()

    return response.json()["response"]

# 사용 예시
answer = chat_with_ollama("파이썬 리스트와 튜플의 차이점은?")
print(answer)

스트리밍 응답 처리

import requests
import json

def stream_chat(prompt: str, model: str = "llama3.2"):
    """응답을 실시간으로 스트리밍합니다."""
    url = "http://localhost:11434/api/generate"

    payload = {
        "model": model,
        "prompt": prompt,
        "stream": True  # 스트리밍 활성화
    }

    with requests.post(url, json=payload, stream=True) as response:
        for line in response.iter_lines():
            if line:
                chunk = json.loads(line)
                print(chunk["response"], end="", flush=True)
                if chunk.get("done"):
                    break
    print()  # 줄바꿈

# 실행
stream_chat("머신러닝과 딥러닝의 차이를 설명해주세요.")

OpenAI 호환 API

Ollama는 OpenAI API 형식도 지원합니다. 기존 OpenAI SDK 코드를 거의 수정 없이 재사용할 수 있습니다.

from openai import OpenAI

# OpenAI 클라이언트를 Ollama 서버로 연결
client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama"  # 로컬이므로 임의 값 사용
)

response = client.chat.completions.create(
    model="llama3.2",
    messages=[
        {"role": "system", "content": "당신은 친절한 AI 어시스턴트입니다."},
        {"role": "user", "content": "파이썬으로 피보나치 수열을 구현해주세요."}
    ]
)

print(response.choices[0].message.content)

25.5 LM Studio 소개와 활용

LM Studio는 그래픽 사용자 인터페이스(GUI)를 제공하는 로컬 LLM 실행 도구입니다. 터미널이 익숙하지 않은 사용자나 다양한 모델을 시각적으로 탐색하고 싶을 때 유용합니다.

주요 특징

  • 허깅페이스(Hugging Face) 모델을 GUI 내에서 직접 검색하고 다운로드
  • GGUF 포맷 모델 기본 지원
  • 채팅 인터페이스와 프롬프트 편집기 내장
  • OpenAI 호환 로컬 서버 기능 제공
  • Windows, macOS, Linux 모두 지원

설치 및 시작

  1. LM Studio 공식 사이트(https://lmstudio.ai)에서 설치 파일을 내려받습니다.
  2. 설치 후 실행하면 Discover 탭에서 모델을 검색할 수 있습니다.
  3. 원하는 모델의 양자화 버전을 선택해 다운로드합니다.
  4. Chat 탭에서 다운로드된 모델을 불러와 대화를 시작합니다.

로컬 서버 활성화

LM Studio의 Local Server 탭에서 서버를 시작하면 http://localhost:1234로 API 요청을 받을 수 있습니다.

from openai import OpenAI

# LM Studio 로컬 서버 연결
client = OpenAI(
    base_url="http://localhost:1234/v1",
    api_key="lm-studio"  # 임의 값
)

response = client.chat.completions.create(
    model="lmstudio-community/Meta-Llama-3.1-8B-Instruct-GGUF",
    messages=[
        {"role": "user", "content": "안녕하세요!"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)

25.6 로컬 LLM vs 클라우드 API 비교 (성능, 비용, 속도)

로컬 LLM과 클라우드 API 중 어느 쪽이 더 낫다고 단정하기 어렵습니다. 용도에 따라 최적의 선택이 달라집니다.

종합 비교표

로컬은 저비용·프라이버시·오프라인 축에서 압도적이고, 클라우드는 모델 품질·응답 속도·확장성 축에서 우위입니다. 따라서 두 방식 중 하나를 고르기보다 시나리오별(개발/운영, 민감/비민감, 내부/공개)로 조합하는 것이 실전에서 가장 효과적입니다.

비교 항목 로컬 LLM 클라우드 API
비용 초기 하드웨어 비용, 이후 무료 토큰당 과금, 대용량 시 고비용
프라이버시 데이터 외부 전송 없음 제3자 서버에 데이터 전송
오프라인 사용 가능 불가능
모델 품질 중소형 모델 중심 최신·최대 규모 모델
응답 속도 하드웨어에 따라 천차만별 안정적이고 빠름
확장성 하드웨어 한계 존재 무제한 확장
유지보수 직접 관리 필요 제공자가 관리
커스터마이징 파인튜닝 모델 자유롭게 사용 제한적

  • 특화된 파인튜닝 모델 활용
  • 개발·테스트 단계의 프로토타이핑

클라우드 API가 적합한 경우

  • 최고 수준의 응답 품질이 필요할 때
  • 트래픽이 불규칙하고 확장성이 필요할 때
  • 하드웨어 투자 없이 빠르게 시작할 때
  • 멀티모달(이미지·음성) 기능이 필요할 때

25.7 로컬 모델을 기존 앱에 연결하기

로컬 LLM의 진가는 기존 애플리케이션과 연동할 때 발휘됩니다. OpenAI 호환 API 덕분에 기존 코드를 거의 수정하지 않고도 로컬 모델로 전환할 수 있습니다.

LangChain과 연동

LangChain은 Ollama를 공식 지원합니다.

from langchain_ollama import OllamaLLM
from langchain_core.prompts import ChatPromptTemplate

# Ollama 모델 초기화
llm = OllamaLLM(model="llama3.2")

# 프롬프트 템플릿 정의
prompt = ChatPromptTemplate.from_messages([
    ("system", "당신은 {topic} 전문가입니다."),
    ("human", "{question}")
])

# 체인 구성
chain = prompt | llm

# 실행
response = chain.invoke({
    "topic": "파이썬",
    "question": "데코레이터 패턴을 설명해주세요."
})
print(response)

환경 변수로 API 전환

운영 환경에 따라 클라우드 API와 로컬 LLM을 유연하게 전환하는 패턴입니다.

import os
from openai import OpenAI

# 환경 변수로 백엔드 선택
USE_LOCAL = os.getenv("USE_LOCAL_LLM", "false").lower() == "true"

if USE_LOCAL:
    client = OpenAI(
        base_url="http://localhost:11434/v1",
        api_key="ollama"
    )
    MODEL = "llama3.2"
else:
    client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
    MODEL = "gpt-4o-mini"

def ask(question: str) -> str:
    response = client.chat.completions.create(
        model=MODEL,
        messages=[{"role": "user", "content": question}]
    )
    return response.choices[0].message.content

# USE_LOCAL_LLM=true python app.py 로 로컬 모드 실행
print(ask("파이썬이란 무엇인가요?"))

2단계: Flask 백엔드 작성

app.py 파일을 생성합니다.

from flask import Flask, request, jsonify, render_template_string
import requests
import json

app = Flask(__name__)

# HTML 템플릿 (간결한 인라인 버전)
HTML_TEMPLATE = """
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>로컬 LLM 챗봇</title>
    <style>
        body { font-family: Arial, sans-serif; max-width: 700px; margin: 40px auto; padding: 0 20px; }
        #chat-box { border: 1px solid #ddd; height: 400px; overflow-y: auto; padding: 16px;
                    border-radius: 8px; background: #f9f9f9; margin-bottom: 16px; }
        .user-msg { background: #007bff; color: white; padding: 8px 12px; border-radius: 12px;
                    margin: 4px 0; max-width: 80%; margin-left: auto; display: table; }
        .bot-msg { background: #e9ecef; padding: 8px 12px; border-radius: 12px;
                   margin: 4px 0; max-width: 80%; display: table; white-space: pre-wrap; }
        #input-area { display: flex; gap: 8px; }
        #user-input { flex: 1; padding: 10px; border: 1px solid #ddd; border-radius: 8px; font-size: 16px; }
        button { padding: 10px 20px; background: #007bff; color: white; border: none;
                 border-radius: 8px; cursor: pointer; font-size: 16px; }
        button:hover { background: #0056b3; }
        #status { color: #666; font-size: 14px; margin-top: 8px; }
    </style>
</head>
<body>
    <h2>🤖 로컬 LLM 챗봇 (Ollama)</h2>
    <div id="chat-box"></div>
    <div id="input-area">
        <input type="text" id="user-input" placeholder="메시지를 입력하세요..." />
        <button onclick="sendMessage()">전송</button>
    </div>
    <div id="status"></div>

    <script>
        const chatBox = document.getElementById('chat-box');
        const userInput = document.getElementById('user-input');
        const status = document.getElementById('status');

        userInput.addEventListener('keypress', (e) => {
            if (e.key === 'Enter') sendMessage();
        });

        function addMessage(text, isUser) {
            const div = document.createElement('div');
            div.className = isUser ? 'user-msg' : 'bot-msg';
            div.textContent = text;
            chatBox.appendChild(div);
            chatBox.scrollTop = chatBox.scrollHeight;
        }

        async function sendMessage() {
            const message = userInput.value.trim();
            if (!message) return;

            addMessage(message, true);
            userInput.value = '';
            status.textContent = '응답 생성 중...';

            try {
                const response = await fetch('/chat', {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify({ message })
                });
                const data = await response.json();
                addMessage(data.response, false);
                status.textContent = `모델: ${data.model} | 완료`;
            } catch (err) {
                addMessage('오류: 서버에 연결할 수 없습니다.', false);
                status.textContent = '오류 발생';
            }
        }
    </script>
</body>
</html>
"""

# 대화 이력 저장 (간단한 메모리 기반)
conversation_history = []

@app.route('/')
def index():
    """메인 페이지를 반환합니다."""
    return render_template_string(HTML_TEMPLATE)

@app.route('/chat', methods=['POST'])
def chat():
    """사용자 메시지를 받아 Ollama 모델에 전달하고 응답을 반환합니다."""
    data = request.get_json()
    user_message = data.get('message', '').strip()

    if not user_message:
        return jsonify({"error": "메시지가 없습니다."}), 400

    # 대화 이력에 사용자 메시지 추가
    conversation_history.append({
        "role": "user",
        "content": user_message
    })

    # Ollama API 호출 (대화 이력 포함)
    ollama_url = "http://localhost:11434/api/chat"
    payload = {
        "model": "llama3.2",
        "messages": [
            {"role": "system", "content": "당신은 친절하고 도움이 되는 AI 어시스턴트입니다. 한국어로 답변하세요."}
        ] + conversation_history,
        "stream": False
    }

    try:
        response = requests.post(ollama_url, json=payload, timeout=120)
        response.raise_for_status()

        result = response.json()
        bot_message = result["message"]["content"]

        # 대화 이력에 어시스턴트 응답 추가
        conversation_history.append({
            "role": "assistant",
            "content": bot_message
        })

        return jsonify({
            "response": bot_message,
            "model": result.get("model", "llama3.2")
        })

    except requests.exceptions.ConnectionError:
        return jsonify({"error": "Ollama 서버에 연결할 수 없습니다. 'ollama serve'를 실행하세요."}), 503
    except Exception as e:
        return jsonify({"error": str(e)}), 500

@app.route('/reset', methods=['POST'])
def reset():
    """대화 이력을 초기화합니다."""
    conversation_history.clear()
    return jsonify({"message": "대화 이력이 초기화되었습니다."})

if __name__ == '__main__':
    print("로컬 LLM 챗봇 서버를 시작합니다...")
    print("브라우저에서 http://localhost:5000 을 열어주세요.")
    print("Ollama가 실행 중인지 확인하세요: ollama serve")
    app.run(debug=True, port=5000)
