프로젝트: Mac Mini 홈 인텔리전스 허브

이 프로젝트에서는 Mac Mini(또는 항상 켜 놓는 macOS 기기)에서 Hermes Agent를 실행하여, Apple 생태계와 스마트홈을 통합 관리하는 개인 AI 비서를 구축합니다.

목표

  • Apple 미리알림, 메모, iMessage를 에이전트로 제어
  • HomeAssistant 연동으로 스마트홈 기기 제어
  • 크론으로 모닝 브리핑, 야간 루틴 자동화
  • Telegram으로 외출 중에도 에이전트와 소통

아키텍처

iPhone/iPad ←(iCloud 동기화)→ Mac Mini (Hermes Agent)
                                    ↕
                              Ollama LLM 서버
                                    ↕
Telegram ←(메시징 게이트웨이)→ HomeAssistant

1단계: Apple 스킬 설정

Homebrew와 CLI 도구 설치

Apple 스킬 중 3개는 Homebrew로 설치하는 CLI 도구가 필요합니다(7장 참조). 테스트 Mac에는 Homebrew가 이미 설치되어 있으므로 CLI 도구만 설치하면 됩니다. Homebrew가 없는 환경이라면 brew.sh에서 먼저 설치하세요.

# Apple 스킬 CLI 도구 설치
brew install steipete/tap/remindctl    # 미리알림 (apple-reminders 스킬)
brew install steipete/tap/imsg         # iMessage (imessage 스킬)
brew install antoniorodr/memo/memo     # Apple 메모 (apple-notes 스킬)

미리알림 테스트

> 내일 오전 10시에 "치과 예약" 미리알림을 추가해줘
> 이번 주 미리알림 목록을 보여줘
> "장보기" 리스트에 우유, 빵, 계란을 추가해줘

iCloud를 통해 iPhone의 미리알림 앱에도 즉시 동기화됩니다.

iMessage 테스트

> 최근 iMessage 목록을 보여줘
> 아내에게 "오늘 늦을 것 같아" 메시지 보내줘
전체 디스크 접근 권한

iMessage 스킬을 사용하려면 터미널 앱에 시스템 설정 > 개인정보 보호 및 보안 > 전체 디스크 접근 권한을 부여해야 합니다. findmy 스킬은 별도 CLI 도구 없이 AppleScript로 Find My 앱 화면을 캡처한 뒤 멀티모달 LLM으로 읽는 방식을 사용합니다(7장 참조).

2단계: HomeAssistant 연동

HomeAssistant가 설치되어 있다면, Hermes Agent의 내장 HomeAssistant 도구로 연결할 수 있습니다.

설정

# ~/.hermes/.env에 추가
HASS_TOKEN=your_long_lived_access_token
HASS_URL=http://homeassistant.local:8123

사용 예시

> 거실 조명을 켜줘
> 현재 실내 온도가 몇 도야?
> 현관문 잠금 상태를 확인해줘

3단계: 크론으로 자동화

모닝 브리핑

> 매일 아침 7시에 다음을 실행해줘:
> 1. 오늘 미리알림 목록 확인
> 2. 오늘 날씨 검색
> 3. 요약해서 Telegram으로 보내줘

야간 루틴

> 매일 밤 11시에 다음을 실행해줘:
> 1. 모든 조명 끄기
> 2. 현관문 잠금 확인
> 3. 내일 미리알림 미리 알려주기

4단계: Telegram 원격 제어

외출 중에도 Telegram으로 에이전트와 소통할 수 있습니다 (9장 참조).

> hermes gateway

Telegram에서:

장보기 리스트에 두부 추가해줘
거실 에어컨 25도로 설정해줘
아이 AirTag 위치 확인해줘     # findmy 스킬: AppleScript + 비전 LLM 방식

이 프로젝트의 의미

이 구성은 OpenClaw의 네이티브 iOS 앱이 제공하는 경험과 다른 방식으로 같은 목표를 달성합니다. OpenClaw는 앱으로, Hermes Agent는 시스템 레벨 접근으로 Apple 생태계와 통합합니다. Hermes Agent만의 장점은:

  • FindMy 통합: OpenClaw에 없는 기능 (AppleScript + 비전 LLM 방식)
  • HomeAssistant 내장 도구: 4개의 전용 도구로 스마트홈 직접 제어
  • 자기 개선: 반복 사용 시 자동으로 스킬 생성 (예: "야간 루틴" 스킬)
  • 비용: 로컬 LLM 사용 시 API 비용 없음
