09. 메시징 게이트웨이

이 장에서는 Hermes Agent를 메시징 플랫폼과 연동하여, 터미널 밖에서도 에이전트와 대화하는 방법을 다룹니다. 터미널 앞에 앉아 있지 않아도 스마트폰의 Telegram이나 Discord에서 에이전트에게 작업을 지시하고 결과를 받을 수 있습니다. 크론 작업의 알림을 받거나, 외출 중에 서버 상태를 확인하거나, 팀원들과 하나의 에이전트를 공유하는 것도 가능합니다.

Hermes Agent는 Telegram, Discord, WhatsApp, Slack, Signal 등 22개 플랫폼을 지원합니다. 명령 하나로 설정된 모든 플랫폼에 동시에 연결할 수 있습니다.

이 장에서 다루는 내용

  • 지원 플랫폼 개요 (세션 관리, DM 페어링, PII 보호)
  • 텔레그램 연동 (음성, 스트리밍 응답)
  • 디스코드 연동 (스레드 기반 세션, 팀 활용)
  • Microsoft Teams 연동 (Graph API + 웹훅, v0.14 정식 통합)
