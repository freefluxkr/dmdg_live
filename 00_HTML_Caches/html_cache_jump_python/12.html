02-1 숫자형

숫자형(Number)은 숫자 형태로 이루어진 자료형이다. 정수, 실수, 8진수, 16진수 등이 여기에 해당한다.

다음 표는 파이썬에서 숫자를 사용하는 예이다.

항목 파이썬 사용 예
정수 123, -345, 0
실수 123.45, -1234.5, 3.4e10
8진수 0o34, 0o25
16진수 0x2A, 0xFF

숫자형은 어떻게 만들고 사용할까?

정수형

정수형(integer)은 말 그대로 정수를 뜻하는 자료형이다. 다음은 양의 정수, 음의 정수, 숫자 0을 변수 a에 대입하는 예이다.

>>> a = 123
>>> a = -178
>>> a = 0

실수형

실수형(floating-point)은 소수점이 포함된 숫자를 말한다. 다음은 실수를 변수 a에 대입하는 예이다.

>>> a = 1.2
>>> a = -3.45

정수 1과 실수 1.0은 값은 같지만 자료형이 다르다.

아주 크거나 아주 작은 숫자를 표현할 때는 지수 표현 방식을 사용하면 편리하다. 파이썬에서는 4.24e10 또는 4.24E10처럼 표현할 수 있다(e와 E 둘 중 어느 것을 사용해도 된다).

>>> a = 4.24E10
>>> a = 4.24e-10

여기서 4.24E10은 $4.24 * 10^{10}$, 4.24e-10은 $4.24 * 10^{-10}$을 의미한다.

8진수와 16진수

8진수(octal)는 0o 또는 0O(숫자 0 + 알파벳 소문자 o 또는 대문자 O)로 시작한다.

>>> a = 0o177
>>> print(a)
127

0o177 = $1×8^2+7×8^1+7=127$

16진수(hexadecimal)는 0x로 시작한다.

>>> a = 0x8ff
>>> b = 0xABC
>>> print(b)
2748

0xABC = $10×16^2+11×16^1+12=2748$ (A:10, B:11, C:12)

8진수나 16진수는 파이썬에서 자주 사용하지 않으므로 간단히 눈으로만 익히고 넘어가자. 다만 파일 권한이나 색상 코드 등에서 가끔 볼 수 있으므로 이런 표현이 있다는 정도만 기억해 두자.

숫자형을 활용하기 위한 연산자

사칙 연산

프로그래밍을 처음 접하더라도 사칙 연산(+, -, *, /)은 알고 있을 것이다. 파이썬도 계산기처럼 연산자를 사용해 사칙 연산을 수행한다.

>>> a = 3
>>> b = 4
>>> a + b
7
>>> a - b
-1
>>> a * b
12
>>> a / b
0.75

x의 y제곱을 나타내는 ** 연산자

** 연산자는 x ** y처럼 사용하면 x의 y제곱($x^y$) 값을 반환한다.

>>> a = 3
>>> b = 4
>>> a ** b
81

나눗셈 후 나머지를 반환하는 % 연산자

%는 나눗셈의 나머지 값을 반환하는 연산자이다. 7을 3으로 나누면 나머지는 1, 3을 7로 나누면 나머지는 3이 된다.

>>> 7 % 3
1
>>> 3 % 7
3

3을 7로 나누면 몫이 0이고 나머지가 3이므로 3 % 7의 결과는 3이다.

나눗셈 후 몫을 반환하는 // 연산자

/ 연산자를 사용하여 7 나누기 4를 하면 결과는 1.75가 된다. 반면 // 연산자를 사용하면 나눗셈 후 몫만 반환한다. 두 연산자의 차이를 비교해 보자.

>>> 7 / 4
1.75
>>> 7 // 4
1

/는 소수점까지 포함한 결과를, //는 몫에 해당하는 정수값 1만 반환한다.

복합 연산자

복합 연산자는 산술 연산자(+, - 등)와 대입 연산자(=)를 합친 것이다.

먼저 a에 1을 대입한다.

>>> a = 1

a의 값을 1만큼 증가시키려면 다음과 같이 할 수 있다.

>>> a = a + 1  # a + 1로 계산된 값을 다시 a에 대입한다.
>>> print(a)
2

a = a + 1은 다음과 같이 간략하게 표현할 수 있다.

>>> a += 1

a += 1은 a = a + 1과 동일하다. 이처럼 +=를 복합 연산자라 부른다.

a의 값을 1만큼 감소시키려면 -= 복합 연산자를 사용한다.

>>> a = 1
>>> a -= 1  # a = a - 1과 같음
>>> print(a)
0

복합 연산자에는 다음과 같은 것들이 있다.

+=, -=, *=, /=, //=, %=, **=

예를 들어 *=는 다음과 같이 사용한다.

>>> a = 2
>>> a *= 3  # a = a * 3과 같음
>>> print(a)
6

복합 연산자를 사용하면 코드를 더 간결하게 작성할 수 있다.
