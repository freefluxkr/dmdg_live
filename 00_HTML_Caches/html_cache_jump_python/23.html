04장 파이썬의 입출력

지금까지 공부한 내용을 바탕으로 함수, 입출력, 파일 처리 방법에 대해 알아보자. 입출력은 프로그래밍 설계와 밀접한 관련이 있다. 프로그래머는 프로그램을 만들기 전에 어떻게 동작하게 할 것인지 설계부터 하는데, 이때 가장 중요한 부분이 바로 입출력이다. 특정 프로그램에서만 사용하는 함수를 만들 것인지, 여러 프로그램이 공통으로 사용하는 함수를 만들 것인지, 더 나아가 오픈 API로 공개하여 외부 프로그램도 사용할 수 있게 만들 것인지가 모두 입출력과 관련 있다.
