Label은 많은 요소를 포함하고 있는 클래스입니다. 생성자 __init__ 부분을 봅시다. 생성자 내부에 STANDARD OPTIONS가 있습니다. 이 중에서 주로 사용할 옵션만 굵게 표시했습니다. 모든 것을 다 알 필요는 없으니 부담 갖지 말고 훑어만 보세요. 차차 설명하겠습니다.

 

텍스트 레이블 만들기

텍스트 레이블을 만들어 봅시다. 먼저 Label 클래스의 객체를 만들어야 합니다. 레이블 객체는 Label()로 만들고, 텍스트는 text 옵션으로 나타냅니다.

root = Tk()
root.title('my first tkinter')
root.geometry('400x200+0+300')

label1 = Label(root, text='안녕하세요!')

root.mainloop()
