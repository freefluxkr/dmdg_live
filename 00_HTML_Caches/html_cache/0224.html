2 코드를 보고 다음 중 틀린 것을 고르세요.

for i in range(100):
    if i % 5 == 1:
        print('쿵', end=' ')
    elif i % 5 == 2:
        print('짝', end=' ')
    else:
        print(i, end=' ')

① 반복문 내부에 있는 코드를 100번 반복한다.

② 가장 먼저 ‘쿵’이 출력된다.

③ i가 32일 때 ‘짝’이 출력된다.

④ 마지막으로 99가 출력된다.

⑤ print()에 end 옵션을 추가했으므로 줄바꿈되지 않고, 한 칸 공백 후 다음 글자가 출력된다.
