▼ 표 5-6 반복문의 실행과정

반복 회차

a에 저장된 값

반복문 내부

첫 번째

0

   i에 0이 저장되고

    print(i)          i 값 0 출력
    if i == 2:        조건을 충족하지 않음
        break

두 번째

1

   i에 1이 저장되고

    print(i)          i 값 1 출력
    if i == 2:        조건을 충족하지 않음
        break

세 번째

2

   i에 2이 저장되고

    print(i)          i 값 2 >출력
    if i == 2:        조건을 충족함
        break         break가 실행되어 반복문 종료

반복문과 조건문의 구조를 잘 파악하면 break가 포함된 프로그램도 이해하기 쉽습니다.
