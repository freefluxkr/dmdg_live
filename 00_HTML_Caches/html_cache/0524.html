11.1.1 데이터 선정하기

핫플레이스의 인구 분석이므로 인구 데이터가 필요하겠네요. 그리고 사람이 적은 시간대를 구하니 시간대별 인구 데이터가 있어야 하고요. 그런데 찾는 범위를 전국으로 하면 데이터가 너무 커질 테니 지역을 서울로 한정하겠습니다.

데이터를 찾을 때는 구글을 추천합니다. 찾으려는 키워드 옆에 ‘데이터’를 붙여 구글에서 검색하면 적절한 데이터를 찾을 수 있습니다. 우리에게 필요한 데이터는 서울의 시간대별 인구죠. 그럼 구글에서 ‘서울 시간대별 인구 데이터’를 검색해 봅시다(다른 지역을 알고 싶다면 해당 지역으로 바꿔서 검색하면 됩니다).
