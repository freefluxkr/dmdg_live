한 칸씩 공백을 넣어 출력하는 콤마 때문에 띄어쓰기가 생겼지만, 변수 값만 나오는 것보다는 조금 더 문장이 매끄러워졌네요.

이번에는 앞의 코드를 그대로 넣고 그 아래에 새로운 값을 넣은 후 다시 한번 실행해 봅시다.

name = '유리'
height = 175.5
age = 21
hobby = 'programming'
print(name, '키는', height, ', 나이는', age, ', 취미는', hobby, '입니다!')

name = '제임스'
height = 186
age = 24
hobby = '요리하기'
print(name, '키는', height, ', 나이는', age, ', 취미는', hobby, '입니다!')
실행결과
유리 키는 175.5 , 나이는 21 , 취미는 programming 입니다!
제임스 키는 186 , 나이는 24 , 취미는 요리하기 입니다!
