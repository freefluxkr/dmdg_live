이번에는 Grace가 책을 2권 샀다고 가정하고 코드를 작성해 봅시다.

Grace.buy(books, 2)
books.information()
실행결과
Grace 고객님이 books 2 개 구매!
상품이름 : books
상품가격 : 17500
재고수량 : 13

상품을 구매하면 Grace 객체가 buy() 메서드를 실행하고 다음으로 books 객체가 information() 메서드를 실행합니다. 책 2권을 구매했으므로 재고수량은 13권이 됩니다.

그럼 Grace 객체의 정보를 조회해 봅시다.

Grace.information()
실행결과
고객이름 : Grace
가입날짜 : 20200130
구매내역 : ['books']
누적 구매금액 : 35000
