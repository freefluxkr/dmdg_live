초깃값을 특정하기 어렵다면 None을 사용합니다. None은 값이 비어 있음을 표현하는 파이썬의 데이터 타입입니다.

def hi(name = None):
    print('hi!')
    print('My name is', name, '!')

hi()
실행결과
hi!
My name is None !

None을 넣고 실행하면 결과에는 None이 그대로 출력됩니다. 초깃값을 설정하기 어려울 때 None을 자주 사용합니다.
