입력된 텍스트를 프로그램으로 읽어 들여 봅시다. 엔트리에 입력된 값을 가져올 때는 get() 함수를 사용합니다. 버튼 하나를 추가하고, 버튼이 클릭될 때 엔트리에 입력된 값을 가져와 보겠습니다.

root = Tk()
root.title('entry')
