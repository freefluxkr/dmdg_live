NOTE 주피터 노트북 바로 실행하기

주피터 노트북을 매번 검색해 실행하려면 귀찮죠? 이럴 때 주피터 노트북을 작업 표시줄에 고정하면 매번 검색할 필요 없이 아이콘을 클릭해서 한 번에 주피터 노트북을 실행할 수 있습니다. 주피터 노트북을 실행한 후 화면 하단의 작업 표시줄에서 주피터 노트북 아이콘을 마우스 우클릭합니다. 메뉴에서 [작업 표시줄에 고정]을 클릭하면 작업 표시줄에 주피터 노트북 아이콘이 고정됩니다.
