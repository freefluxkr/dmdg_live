food는 처음에 데이터가 5개인 리스트였습니다. food.append('감자칩')을 실행하고 나면 리스트의 맨 뒤에 감자칩이 추가되어 데이터는 6개가 됩니다. 데이터를 하나 더 추가해 볼까요? ‘카레’를 추가해 봅시다.

food.append('카레')
print(food)
실행결과
['피자', '치킨', '떡볶이', '스테이크', '파스타', '감자칩', '카레']

food 리스트 맨 뒤에 카레가 추가됐습니다. 이처럼 append() 명령어는 리스트의 맨 뒤에 데이터를 추가합니다. append()가 실행될 때 컴퓨터 내부에서는 다음과 같은 일이 일어납니다.
