15.2.4 엔트리

세 번째 위젯으로 화면에서 값을 입력받을 수 있는 엔트리(Entry)를 배워 보겠습니다. entry는 ‘들어옴’, ‘입장’ 등을 의미하죠. 단어의 의미처럼 엔트리를 사용하면 화면을 통해 들어오는 값을 프로그램에서 입력받을 수 있습니다.

 

엔트리 만들기

간단한 엔트리를 하나 만들어 봅시다.

from tkinter import *

root = Tk()
root.title('entry')
root.geometry('400x200')

ent = Entry(root, width=25)
ent.grid(row=0, column=0)

root.mainloop()
