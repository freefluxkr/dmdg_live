함수를 정의할 때 매개변수에 초깃값을 넣을 수도 있습니다. 다음 코드를 실행해 봅시다.

def hi(name = 'A'):
    print('hi!')
    print('My name is', name, '!')

hi()
hi('B')
hi(name = 'C')
실행결과
hi!
My name is A !
hi!
My name is B !
hi!
My name is C !

매개변수 name에 초깃값으로 'A'를 저장했습니다. 초깃값이 저장됐기 때문에 hi()처럼 함수 호출 시 인자가 없어도 오류가 발생하지 않고, name에 저장된 초깃값 'A'를 넣어 실행합니다. 함수 호출 시 인자가 입력되면 해당 인자로 매개변수의 값을 바꿉니다. 따라서 hi('B')처럼 인자를 넣어 실행하면 자동으로 name에 'B'가 저장됩니다.
