각 카드 이용내역에서 이용일시, 가맹점명, 이용금액만 골라서 출력됩니다. 가맹점명과 이용금액을 입력할 때 인덱스를 뒤에서부터 세는 것이 더 편하다면 print(row[0], row[-4], row[-3])처럼 음수 인덱스로 표현해도 됩니다. 실행결과는 같습니다.

이번에는 가맹점명의 데이터 타입을 출력해 봅시다.

for row in data:
    print(row[5], type(row[5]))
실행결과
네이버파이낸셜(주) <class 'str'>
GS샵 <class 'str'>
G마켓 <class 'str'>
...

str, 즉 문자열로 나옵니다. 이용금액의 데이터 타입도 출력해 봅시다. 이용금액은 숫자니까 당연히 int가 나오지 않을까요?

for row in data:
    print(row[6], type(row[6]))
