6) win32com 통해 엑셀 다루기 - 차트

이번 파트는 win32com.client 모듈을 통해 엑셀 차트를 다루는 방법을 소개하겠습니다. win32com.client를 사용하여 차트를 표시하는 코드를 순서대로 설명하겠습니다.

1. 모듈 import

지금까지 계속 반복했던 내용으로 모듈 import는 별도 설명은 하지 않고 코드만 작성하고 넘어가겠습니다.

import win32com.client


2. 엑셀 App 열기(객체 생성)

이 부분도 많이 설명했던 부분이죠? win32com 을 통해 Microsft Office를 제외할 때 관련 Application 객체를 생성하는 과정은 필수이니 이 점 꼭 기억해주세요.

excel = win32com.client.Dispatch("Excel.Application") #엑셀 프로그램을 객체로 생성
excel.Visible = True #실행과정 보이게


3. Workbook 및 Worksheet 객체 생성

이번에는 "chart_data.xlsx"라는 파일명을 가진 엑셀 파일을 가지고 객체를 생성해보겠습니다. 위 이미지가 설정할 파일입니다. 현재 이름별 점수가 기록되어 있는 시트가 선택되어있습니다.

#기존 존재하는 data파일을 Workbook 객체로 생성
wb = excel.Workbooks.Open(r"C:\Users\Desktop\VS CODE\Project\17. win32com\chart_data.xlsx")

#활성화되어잇는 시트를 객체로 생성
ws = wb.ActiveSheet

저희는 위 성적표 양식을 막대 차트로 표현해볼 것입니다.


4. 빈 차트 양식 생성하기

차트를 만드는 과정 중 첫번째는 엑셀에 빈 차트 양식을 생성하는 것입니다. 아래와 같이 코드를 작성해보겠습니다.

#차트를 새로 추가하고 선택하기
ws.Shapes.AddChart().Select()

차트를 생성하는 코드는 Worksheet(=ws)에 Shapes.AddChart( )라는 함수를 사용하면 됩니다. 위 코드를 실행하면 설정한 WorkSheet에 빈 차트 양식이 만들어집니다.(아래 빈 사각형 공간)


5. 차트 Data 영역 설정하기

4번에서 빈 차트 양식을 생성했습니다. 이번에는 빈 차트 양식에 실제 막대 차트를 생성해보겠습니다. 

# 선택 된 차트의 데이터영역을 설정하기
excel.ActiveChart.SetSourceData(Source=ws.Range("A1:B9"))

코드가 길지만 순서대로 설명해볼게요. 처음에 나온 excel은 위 2번 "엑셀 App 열기"에서 다뤘던 excel 변수입니다.

그 다음, ActiveChart는 현재 선택 된 차트를 의미합니다. 위 4번 "빈 차트 양식 생성하기"에서 저희는 아래와 같은 코드를 작성했었습니다.

#차트를 새로 추가하고 선택하기
ws.Shapes.AddChart().Select()

차트를 생성하고 선택을 했으므로 ActiveChart는 위에서 생성했던 차트 빈 양식을 의미합니다.

SetSourceData는 저희가 선택한 빈 차트 양식에 차트를 생성할 데이터 범위를 선택하는 코드입니다. ws.Range("A1:B9")는 많이 보았던 코드죠? "A1:B9" 영역을 차트 데이터 영역으로 선택합니다. win32com 엑셀 파트를 쭉 공부해오신 분이라면 ws.Range("A1:B9") 대신 ws.UsedRange( )를 사용해도 동일한 결과가 나옴을 이해하실겁니다.

해당 내용은 "3-3-2) win32com 엑셀 다루기 - Cell 영역 선택 방법"을 참고해주세요.

위 코드를 순서대로 실행하면 아래와 같은 세로 막대 차트가 생성됩니다.


6. 차트 생성시 옵션

1) 차트 형식 설정하기

위에서는 기본적인 세로 막대 차트를 생성했지만 실제로 엑셀에서는 다양한 형식의 차트를 제공합니다. 사용자가 원하는 차트를 생성하게 하려면 어떻게 해야할까요?

Microsoft에서는 엑셀 차트 번호라는 옵션값을 제공합니다. (구글에 XlChartType Enumeration을 검색해보시기 바랍니다.)

위 이미지가 바로 그 내용인데요. 차트 옵션값을 설정함에 따라 사용자가 원하는 형식의 차트를 선택할 수 있습니다. (모든 내용이 있는 것은 아니므로 자세한 내용은 Microsoft에서 제공하는 문서를 찾아보시기 바랍니다.)

먼저 앞 과정에서 차트를 생성했던 코드를 다시 가져와 보겠습니다.

#꺾은선 차트 생성
chart = ws.Shapes.AddChart(65).Select()
#데이터 범위 설정
excel.ActiveChart.SetSourceData(Source=ws.Range("A1:B9"))

이 전 코드랑 달라진 점은 Shapes.AddChart(65) 부분입니다. 이전에 빈 차트를 생성했을 때는 괄호 안에 아무 값도 입력하지 않았습니다. 이번에는 65라는 숫자 값을 입력하고 코드를 실행시켜보겠습니다.

원래 막대 그래프였던 부분이 숫자 65를 입력함으로써 꺾은선 그래프가 됐네요. 다시 위 XlChartType Enumeration에서 65라는 값에 대한 옵션을 검색해보겠습니다.

숫자 65는 "Line with Markers"를 의미합니다. 즉, 위와 같은 그래프 형태를 사용하려면 숫자 65를 입력하면 되는 것이죠. AddChart( ) 괄호 안의 숫자 값 변경을 통해서 테스트해보시기 바랍니다.

2) Chart 위치 및 크기 설정하기

이번에는 설정한 Chart의 위치 및 크기를 설정하는 코드를 작성해보겠습니다.

chart = ws.Shapes.AddChart(4,100,100,200,200).Select() #막대 차트 200*200 크기 생성
excel.ActiveChart.SetSourceData(Source=ws.Range("A1:B9")) #데이터 범위 설정

이전 코드와 달라진 점이라면 AddChart에 차트 타입을 설정하는 숫자뿐만 아니라 위치, 크기 값이 추가되었다는 것입니다.

괄호 안의 옵션 값 입력 형태는 아래와 같습니다.

"Worksheet 객체명".Shapes.AddChart(차트타입, x축 위치, y축 위치, 가로크기, 세로크기)

-. 차트타입 : 어떤 타입의 차트를 사용할 것인가?(숫자 값)

-. x축위치 : 왼쪽으로부터 시작해서 위치 값

-. y축위치 : 위부터 시작해서 위치 값

-. 가로크기 : 차트의 가로크기

-. 세로크기 : 차트의 세로크기

설명한 내용을 참고하셔서 차트 옵션 값들을 이해해보세요. 코드를 실행시키면 아래와 같은 결과가 나옵니다.

7. 차트 제목 및 범례 설정하기

이번에는 차트의 제목과 범례(label)을 설정하는 방법을 알아보겠습니다. 해당 내용은 어려운 내용은 없어서 주석으로 설명을 대신하겠습니다. 필요하신 코드를 그냥 그대로 써서 사용해주시면 됩니다.

참고로, AcitveChart라는 코드는 위에서도 설명했었지만 현재 선택되어 있는 차트임을 참고해주세요.

1) 차트 제목 설정하기

<코드>

#차트 제목 나오게(False면 안보임)
excel.ActiveChart.HasTitle = True 

#차트 제목 설정
excel.ActiveChart.Charttitle.Text = "국어 과목" 

#차트 제목 글씨 크기
excel.ActiveChart.Charttitle.Characters.Font.Size=14

#차트 제목 색상(파란색)
excel.ActiveChart.Charttitle.Characters.Font.ColorIndex = 5

#제목 굵게 
excel.ActiveChart.Charttitle.Characters.Font.Bold=True

<결과>

2) 차트 범례 설정하기

<코드>

#차트 범례 보이게(Fasle면 안보임)
excel.ActiveChart.HasLegend = True 

#차트 범례 글씨 크기
excel.ActiveChart.Legend.Font.Size = 15 

#차트 범례 굵게
excel.ActiveChart.Legend.Font.Bold = True 

#차트 범례색상 설정(파란색)
excel.ActiveChart.Legend.Font.ColorIndex = 5

<결과>
