2) win32com 통해 엑셀 다루기 - Cell 데이터 읽기/쓰기

win32com에 속한 client라는 모듈을 활용하여 엑셀을 제어할 수 있습니다. 이번 편에서는 win32com.client를 이용해서 엑셀을 제어하는 기본적인 방법에 대해 알아보겠습니다.

1. import

엑셀을 제어하기 위해선 아래와 같이 win32com.client를 import 시켜야 합니다. win32com은 파이썬 내장 모듈이 아니기에 별도 설치가 완료되어 있어야 합니다.

<코드>

import win32com.client


2. 엑셀 Application 열기

win32com.client 모듈을 사용하여 엑셀을 제어할 경우 실제 저희가 엑셀을 사용하는 것처럼 엑셀 프로그램을 여는 과정을 코드로 작성해야 합니다.

<코드>

excel = win32com.client.Dispatch("Excel.Application") #엑셀 프로그램 실행

위와 같이 win32com.client 모듈의 Dispatch 함수를 호출합니다. 괄호 안의 내용은 엑셀 프로그램을 뜻하며, 코드의 전체 의미는 "excel"이라는 변수에 엑셀 프로그램 객체를 설정해주는 것이라고 이해하시면 됩니다.

위 코드는 엑셀을 다루는 방법이므로 "Excel.Applicaton" 을 괄호 안에 입력하였지만 Microsoft에서 제공하는 Internet Explorer, word, PPT 등 을 바인딩할 수 도있습니다. 예를 들어, 인터넷 익스플로러를 객체로 바인딩하고 싶다면 "InternetExplorer.Application"을 괄호 안에 입력해주시면 됩니다.

추가로, win32com의 대표적인 특징 중 하나인 실행과정을 실시간으로 확인하려면 아래와 같이 코드를 추가하여 줍니다. 위에서 설정해준 excel이라는 변수의 Visible 속성을 True로 설정해야 합니다.

<코드>

excel.Visible = True #앞으로 실행과정을 보이게

위 2줄 코드를 실행하면 아래와 같이 빈 엑셀창이 뜬 것을 확인하실 수 있습니다.


3. Workbook 및 Worksheet 객체 생성

OpenPyxl을 설명하는 챕터에서 엑셀에는 Workbook과 Worksheet의 개념이 있다는 것을 설명했습니다. 마찬가지로, win32com.client 모듈을 사용하여 엑셀을 제어할 경우 Workbook 및 Worksheet 객체를 생성해야 합니다.

Workbook 및 Worksheet의 개념을 모르시는 분들은 "3-1-1) 엑셀의 구성요소"와 "3-1-2) Workbook, Worksheet 객체 생성하기" 파트를 참고하시면 되겠습니다.

<코드>

wb = excel.Workbooks.Add() #엑셀 프로그램에 Workbook 추가(객체 설정)
ws = wb.Worksheets("sheet1") #Worksheet 설정

OpenPyxl과 문법은 다르나 Workbook과 Worksheet를 객체로 설정한다는 과정은 같습니다. 위 코드를 실행하면 아래와 같이 엑셀 "통합문서"가 만들어지면서 아래와 같이 "Sheet1"이 생성됩니다.

위 방법은 새로운 엑셀 파일을 생성하는 방법입니다. 만약, 원래 있는 엑셀 파일을 Workbook 객체로 생성하고 싶다면 아래와 같이 작성합니다.

<코드>

wb = excel.Workbooks.Open(r"C:\Users\Desktop\VS CODE\Project\17. win32com\data.xlsx")

Open 함수를 사용하되, 괄호 안의 내용을 엑셀 파일의 전체 경로로 채워주면 됩니다.


4. Cell에 데이터 써보기

특정 Cell에 데이터를 쓰는 방법은 아래와 같습니다. 3가지 방식을 표현해보았습니다. 아래 주석과 코드를 통해 이해해보겠습니다. 참고로 3번째, 4번째 방식은 여러 범위에 한번에 값을 입력하는 방식입니다.


<코드>

#셀 row, col 값 지정하여 값넣기(Range("A1")과 동일 함)
ws.cells(1,1).Value = "win32com excel test1"

#ragne로 값 넣기(Cell(1,2)와 동일함)
ws.Range("A2").Value = "win32com excel test2"

#range로 다중범위 지정해서 값 넣기1
ws.Range("A3:C3").Value = "win32com excel test3"

#range로 다중범위 지정해서 값 넣기2(위 코드와 동일 표현)
ws.Range(ws.Cells(3,1), ws.Cells(3,3)).Value = "win32com excel test3"

만약 엑셀의 자동 채우기 기능을 활용하려면 Autofill( ) 함수를 사용합니다. 사용 방법은 아래와 같습니다.

<코드>

ws.Range('A1:A3').AutoFill(ws.Range("A1:A10"))

코드에서 첫 번째 Range("A1:A3")는 자동 채우기를 할 기준 데이터 범위입니다. 위 이미지에서 A1:A3 데이터를 지정해서 자동 채우기 할 것입니다.

두 번째 AutoFill( ) 괄호 안의 Range("A1:A10")는 자동 채우기를 어디까지 할 것인가 범위를 지정합니다. 주의해야 할 점은 위에 첫 번째에서 기준이 되었던 A1:A3를 포함 시켜야 합니다. 결과는 아래와 같습니다.

5. Cell data 복사/붙여넣기

위 4번의 결과 이미지 중 "A1:A10" 데이터를 복사해서 "B1:B10" 붙여넣기 해보겠습니다. 위에서 생성한 Worksheet 객체를 이용해서 원하는 범위를 복사합니다.(Copy)

그 다음, 복사 시킬 위치를 선택해야 합니다.(Select) 그리고 복사 한 내용을 붙여넣기 합니다.(Paste) 아래 코드는 이 내용을 코드로 구현한 것입니다.

<코드>

ws.Range("A1:A10").Copy() # "A1:A10" 데이터 복사하기
ws.Range("B1").Select() # 붙여넣기 할 위치 선택
ws.Paste() #붙여넣기 실행

6. 파일 저장하기

파일을 저장하는 방법은 Workbook 객체 변수를 통해 Save( ) 함수를 사용하면 됩니다. 이 부분은 OpenPyxl과 비슷합니다.

<코드>

wb.Save()

wb는 위 3번에서 지정했던 Workbook 객체 변수입니다. 위 코드로 저장할 경우 "내 PC-문서" 위치로 지정되며, 파일명은 "통합문서"라는 이름으로 저장됩니다. 만약 "다른 이름으로 저장하기" 기능을 활용하고 싶다면 SaveAs( ) 함수를 사용합니다

<코드>

wb.SaveAs(r"C:\Users\Desktop\VS CODE\Project\17. win32com\data.xlsx")

excel.Quit()
