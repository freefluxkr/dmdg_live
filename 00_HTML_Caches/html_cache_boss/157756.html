5) win32com 통해 엑셀 다루기 - 엑셀 서식 지정

이번 파트에서는 win32com.client를 통해 엑셀 셀서식을 설정하는 방법을 알아보겠습니다. 셀서식 파트의 내용은 아래와 같은 순서도 다뤄보겠습니다.

1. Font Style

2. Font Color(글 색상)

3. Cell 서식 : 색상, 테두리, 정렬

4. Font, Cell 서식 지우기

앞 파트와 마찬가지로 아래 코드가 이미 작성되어 있다는 가정하에 아래 내용을 진행하도록 하겠습니다. 이전에도 많이 설명한 부분이지만, 새로운 Workbook 및 Worksheet 객체를 생성하는 과정입니다.

import win32com.client

excel = win32com.client.Dispatch("Excel.Application") #엑셀 프로그램 실행
excel.Visible = True #앞으로 실행과정을 보이게

wb = excel.Workbooks.Add() #엑셀 Workbook 파일 1개 새로 생성
ws = wb.Worksheets.Add() #엑셀 시트를 새로 생성


1. Font Style

Font Style은 글꼴, 글씨의 크기 등 말 그대로 글씨의 형태를 지정해주는 것을 말합니다. win32com.client를 사용해서 어떻게 Font Style을 수정할 수 있는지 알아보겠습니다.

먼저 아래와 같이 임의의 텍스트를 엑셀 셀에 입력해보았습니다.


<코드>

#다중범위 써보기1
ws.Range(ws.cells(1,1), ws.cells(1,3)).value = "win32com excel 서식(font style)"

#다중범위 써보기2
ws.Range("A2:B2").value = "win32com excel 서식(font 색상)"

#다중범위 써보기3
ws.Range("A3").value = "win32com excel 서식(Cell 색상)"

<결과>

위 이미지의 각 텍스트에 Font Style 설정 코드를 작성해보겠습니다.


<코드>

#셀서식1. font size 및 font 굵게, 글씨체

#"A1" 글씨체 변경
ws.cells(1,1).Font.name = "굴림"

#"B2"글씨 사이즈 변경
ws.cells(1,2).Font.Size = 14 

#"C3"글씨 스타일 변경(Bold, Italic, Underline)
ws.cells(1,3).Font.Bold = True #굵게
ws.cells(1,3).Font.italic = True #글씨 기울기
ws.cells(1,3).Font.Underline = True #밑줄

<결과>


위 코드에서는 cells(row, column) 을 사용했지만 Range( )로 범위를 설정해도 무관합니다. 셀 범위 선택 방법에 대해서는 "3-3-3) Cell 영역 선택하는 방법" 편을 참고해주세요.

참고로 "C3"의 글씨 스타일을 변경하는 코드(Bold, Italic, Underline)은 True로 설정하면 적용되며, False로 할 경우 적용이 취소됩니다. 코드를 작성하지 않은 경우 기본이 False 상태라고 생각하시면 됩니다


2. Font Color

이번에는 글씨의 색상을 지정하는 코드를 작성해보겠습니다.


<코드>

#셀서식2. font 색상 지정
ws.Range("A2").font.ColorIndex = 40
ws.Range("B2").font.ColorIndex = 50

<결과>


글씨 색상을 지정하는 방법은 Font.ColorIndex 라는 속성을 사용하는 것입니다. 위 코드에서 보시면 숫자 값(40, 50)을 설정한 것을 확인할 수 있습니다.

Microsoft에서는 엑셀의 Color를 설정하는 고유의 숫자를 설정해두었습니다. 이를 컬러 인덱스(ColorIndex)라고 하며, 1~56가지의 번호로 56가지 색상을 설정할 수 있습니다. 인덱스별 색상은 아래 이미지를 참고해봅시다.


3. Cell 서식 : 색상, 테두리, 정렬


1) Cell 색상

셀 서식-셀 색상은 셀의 배경색을 지정하는 방법입니다. 위에서 다뤘던 ColorIndex를 그대로 활용하며 .Interior.ColorInddex라는 속성을 활용합니다. 사용법은 아래 코드를 통해 이해해보겠습니다.

<코드>

#"A3" 셀 배경색 지정
ws.Range("A3").Interior.ColorIndex = 30

<결과>

2) Cell 테두리 지정

이번에는 셀의 테두리를 지정하는 방법에 대해 알아보겠습니다. 먼저 정해진 영역의 외곽 테두리만 지정하는 코드를 작성해보죠.

<코드>

#Weight : 선 굵기, LineStyle의 경우 1:실선, 2:짧은점선, 3:긴점선 
ws.Range("A1:C3").BorderAround(ColorIndex = 1,Weight = 2,LineStyle = 1)

<결과>

외곽 테두리만 지정하는 함수는 BorderAround( )라는 함수입니다. 괄호 안의 옵션 값은 테두리 색을 지정하는 ColorIndex, 두께를 지정하는 Weight, 선의 스타일을 설정하는 LineStyle입니다. 자세한 내용은 위 주석을 확인해주세요.

참고로, 이번 코드에는 Range("A1:C3")라고 표기하였지만 사용 영역에 다라 UsedRange, CurrentRegion 등 셀 영역을 설정하는 개체들을 사용할 수 있습니다. 관련 내용은 "3-3-3) 셀 영역 선택하기"에서 배웠던 것 기억나시죠? 혹시 내용이 궁금하신 분들은 해당 파트를 참고하시면 됩니다.

만약, 외곽 테두리가 아닌 선택 영역 안쪽까지 모두 테두리 지정하려면 아래 코드를 사용하시면 됩니다.


<코드>

#셀 안쪽까지 모두 테두리 지정
rng = ws.Range("A1:C3") #범위 설정
rng.Borders.LineStyle = 1 #선 스타일
rng.Borders.ColorIndex = 14 #선 색상
rng.Borders.Weight = 2 #선 굵기

<결과>


rng라는 변수에 선택 영역을 설정하여 Borders 라는 객체의 속성값(LineStyle, ColorIndex, Weight)을 ㅅ함으로써 테두리를 지정할 수 있습니다.


3) Cell 정렬

아래와 같이 임의의 양식을 작성해보았습니다. 이번 내용의 목표는 각 텍스트에 맞게 정렬 코드를 구현해보는 겁니다.

셀 정렬 코드를 배우기 전에 행,열크기를 먼저 조정해보도록 하겠습니다. 행,열 크기를 조정하는 이유는 정렬 된 내용이 더 잘보이게 하기 위함입니다. 선택 범위의 rowHeight와 ColumnWidth 속성을 이용하여 셀의 행,열 크기를 조절할 수 있습니다.

추가로 위에서 배운 테두리 코드도 적용해볼까요?


<코드>

#행, 열크기 조정
rng = ws.UsedRange # 사용 영역 선택
rng.rowHeight = 70  # 선택 영역 행 크기 설정
rng.ColumnWidth = 30  # 선택 영역 열 크기 설정

#테두리 설정
rng.Borders.LineStyle = 1 #선 스타일
rng.Borders.ColorIndex = 1 #선 색상 : Black
rng.Borders.Weight = 2 #선 굵기

<결과>


양식 설정은 끝났습니다. 이번에는 셀 정렬 코드를 배워보겠습니다. 셀 정렬 코드는 2가지 속성을 통해 설정할 수 있습니다. HorizotalAlignment, VerticalAlignment입니다. 영어 뜻대로 HorozontalAlignment는 수평 방향으로의 정렬, VerticalAlignment는 수직 방향으로의 정렬을 뜻합니다.

코드를 통해 배워볼까요?


<코드>

#B1
ws.Range("B1").VerticalAlignment = -4160  #위로 정렬
ws.Range("B1").HorizontalAlignment = -4108  #가운데 정렬(수평)

#B3
ws.Range("B3").VerticalAlignment = -4107  #아래로 정렬
ws.Range("B3").HorizontalAlignment = -4108  #가운데 정렬(수평)

#A2
ws.Range("A2").VerticalAlignment = -4108  #가운데 정렬(수직)
ws.Range("A2").HorizontalAlignment = -4131  #왼쪽으로 정렬

#C2
ws.Range("C2").VerticalAlignment = -4108  #가운데 정렬(수직)
ws.Range("C2").HorizontalAlignment = -4152  #오른쪽으로 정렬

#B2
ws.Range("B2").VerticalAlignment = -4108  #가운데 정렬(수직)
ws.Range("B2").HorizontalAlignment = -4108  #가운데 정렬(수평)

<결과>


각 설정 값들은 Microsoft에서 제공하는 공식 문서에서 각 값들이 의미하는 바를 찾아볼 수 있습니다. 아래 이미지를 참고해보도록 합시다.


-. VertialAlignment 옵션 값에 따른 정렬


-. HorizontalAlignment 옵션 값에 따른 정렬


4. Font, Cell 서식 지우기

3번까지는 폰트, 셀 서식을 설정하는 방법에 대해 공부해보았습니다. 이번에는 지금까지 설정한 폰트 및 셀 서식을 초기화하는 방법에 대해 배워보겠습니다. 바로 ClearFormats( )이라는 함수입니다. 추가로 비슷한 종류인 Clear( ), ClearContents( ) 함수까지 알아보죠.

먼저, 위에서 작성했던 이미지를 그대로 들고오겠습니다.

위에서 설정했던 폰트와 셀 서식을 아래 한줄로 초기화 할 수 있습니다.


<코드>

#폰트, 셀서식 초기화(ClearContents일 겨우 내용만 삭제, Clear는 내용,서식 모두 초기화)
ws.Range("A1:C3").ClearFormats()

<결과>


ClearFormats( )를 사용하면 선택한 영역의 서식들이 위 결과 이미지와 같이 모두 삭제됩니다. 행과 열의 크기가 바뀐 부분에 대해서는 적용되지 않습니다.

주석에서도 설명하였지만 Clear( )를 사용하면 서식 및 내용이 모두 지워집니다. ClearContents( )는 내용만 지우는 코드입니다. 내용만 지운다는 것은 서식은 그대로 남아있다는 점 참고해주세요.
