엑셀 Sheet의 Cell에 접근하는 내용에 대해서는 아래 5개 부분으로 나누어 설명 드리겠습니다.

1. Cell data 읽기

2. Cell data 쓰기

3. Cell data 삭제하기

4 .rows, .columns 속성 이해하기

5. 엑셀 함수 쓰기(max_row, max_column 속성 이해)

1. Cell의 Data 읽기

Cell의 Data를 읽어오는 방법을 학습하기 전에 먼저 3-1-1)에서 다뤘던 엑셀의 구성요소에 대해 간단하게 복습해보도록 합시다. 아래 이미지는 이전에 공부했던 내용을 요약한 것입니다.

위 이미지에서 숫자 4를 가리키는 표현법은 2가지입니다. Cell 속성을 사용하려면 행,열에 대한 위치값을 각각 알면 됩니다. 숫자 4를 기준으로 Cell(1,2)라고 표현할 수 있습니다. Cell( ) 내부의 숫자는 행 row=1(행), column=2(열)을 의미합니다. 만약, 엑셀의 고유 인덱스인 Range로 표기하려면 "B1"이라고 표기할 수 있습니다.

그럼 위에서 숫자 4를 파이썬으로 읽어오기 위해선 어떻게 코드를 작성해야 할까요? 아래 예시 코드를 보며 이해해보도록 합시다. 이전에 배웠던 Sheet 설정 객체 변수 ws를 통해 읽어올 값 위치에 접근할 수 있습니다.

엑셀 파일은 이전 파트에서 진행했던 'test.xlsx' 파일을 그대로 활용합니다. 해당 파일에는 (업,무,자,동,화) 5개 Sheet가 있었던 것을 인지하고 아래 내용을 진행하겠습니다. <코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.load_workbook(r"test.xlsx") #워크북 객체 생성(파일명 : test.xlsx)
ws = wb.active  #활성화 되어있는 시트 설정(시트명 : "업")

#방법 1 : Sheet의 Cell 속성 사용하기
data1 = ws.cell(row=1, column=2).value

#방법 2 : 엑셀 인덱스(Range) 사용하기
data2 = ws["B1"].value

#위 결과 출력해보기
print("cell(1,2) : ", data1)
print('Range("B1"):', data2)

<결과>

cell(1,2) :  4
Range("B1"): 4

숫자 4를 openpyxl 코드로 읽어오는 방법은 2가지입니다. 첫번째는, Cell 속성을 사용하는 것입니다. 코드에서 보시다시피 .cell 함수를 통해 row값과 column 값을 입력해주면 해당 위치의 값을 읽어올 수 있습니다.

두번째는, 엑셀 고유 인덱스를 통해 직접 접근하는 것입니다. ws["위치인덱스"]와 같이 입력해주면 해당 위치의 값을 읽어올 수 있습니다.

각 표현법의 뒤에 .value를 붙여줘야 실제값을 읽어올 수 있다는 점은 주의해야 합니다. .value를 붙이지 않으면 각 Cell 위치에 대한 정보값을 튜플로 읽어옵니다. 직접 .value를 빼고 출력시켜보면 확인하실 수 있습니다. 아래 코드 및 결과를 보겠습니다.

<코드>

#Value 빼고 출력해보기
data1 = ws.cell(row=1, column=2)
data2 = ws["B1"]
print(data1)
print(data2)

<결과>

<Cell '업'.B1> #data1 출력
<Cell '업'.B1> #data2 출력

.value를 삭제하고 출력한 결과 [Cell '업' .B1] 과 같은 형태로 저장되는 것을 확인할 수 있습니다. 해당 결과는 "Cell의 속성을 가지고 있고 '업'이라는 Sheet의 B1 위치의 값을 가리키고 있다"라는 뜻으로 이해하시면 됩니다. 그래서 결과를 보시면 알겠지만 위 2가지 코드의 결과는 동일합니다. (표현법이 다를 뿐 동일 위치이므로)

그럼 만약, 위 이미지 처럼 영역으로 된 부분의 data를 읽어오려면 어떻게 할까요? 아래 예시 코드를 통해 이해해보겠습니다.

먼저 rng라는 변수를 통해 범위를 설정하고 그대로 출력해보겠습니다.

<코드>

rng = ws["A1:B1"] #A1:B1 범위 저장
print("Range(a1:b1) : ", rng) #출력값은 튜플

<결과>

Range(a1:b1) :  ((<Cell '업'.A1>, <Cell '업'.B1>),)

결과에서 보시는대로 해당 영역의 위치 정보가 튜플로 저장됐습니다. 이번엔 조금 차이를 둬서 위 이미지의 데이터가 입력된 영역인 "A1:C3"으로 입력해보겠습니다.

<코드>

rng = ws["A1:C3"] #A1:C3 범위 저장(총 9개 Cell)
print(rng) #결과 출력(튜플)

<결과>

((<Cell '업'.A1>, <Cell '업'.B1>, <Cell '업'.C1>), (<Cell '업'.A2>, <Cell '업'.B2>, <Cell '업'.C2>), (<Cell '업'.A3>, <Cell '업'.B3>, <Cell '업'.C3>))

ws["A1:C3"]에 대한 위치 정보를 확인해보니 튜플 속의 튜플인 이차원 튜플로 각 위치 정보가 표기되어 저장됩니다. 위 결과를 보면 이해가 어려울 수 있으니 간단히 도식화 해보도록 하겠습니다.

위 표에서 색깔이 다른 부분이 각각 하나의 튜플 요소라고 생각하시면 됩니다. 따라서 Python 튜플을 인덱스로 접근하기 위해서는 위 표를 이해하시면 됩니다.(튜플, 리스트 등 자료형은 인덱스가 0부터입니다.)

따라서, 위 튜플에 저장 된 위치정보를 .value 를 통해 값을 출력하려면 이중 for문을 사용하셔야 합니다. 튜플이 2차원 배열이기 때문입니다. 이중 for문을 통해 출력해보는 코드를 아래처럼 작성해보겠습니다.

<코드>

rng = ws["A1:C3"] #A1:C3 범위 저장(총 9개 Cell)

for  rng_data  in  rng: #튜플의 첫번째 차원 : 색깔이 다른 영역 data
    for  cell_data  in  rng_data: #튜플의 두번째 차원을 위한 for문 : 1개의 Cell 요소

    print(cell_data.value) #각 Cell 요소의 값 출력

<결과>

2. Cell에 데이터 쓰기

지금까지 공부했던 "1. Cell의 데이터 읽기"에서 Cell의 각 위치에 접근하는 방법을 이해하셨다면 데이터를 쓰는 방법은 어렵지 않습니다. 이번엔 "test.xlsx" 파일의 "무" Sheet에 접근하여 Cell에 데이터를 쓰는 방법을 이해해보도록 합시다.

아래 코드를 작성해보고 결과 엑셀 파일을 확인해보겠습니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.load_workbook(r"test.xlsx") #Workbook 객체 생성
ws = wb["무"] #WorkSheet 객체 생성("무" Sheet)

#"B1" Cell에 입력하기
ws.cell(row=1, column=2).value = "입력테스트1"

#"C1" Cell에 입력하기
ws["C1"].value = "입력테스트2"

wb.save("result.xlsx") #엑셀 파일 저장(파일명 : result.xlsx)

<결과>

쓰는 방법은 읽는 방법과 크게 다르지 않습니다. ws 객체 변수의 Cell 속성이나 "C1"과 같은 고유 인덱스를 통해 원하는 위치에 값을 입력해주면 됩니다. 엑셀 데이터를 읽을 때와 마찬가지로 주의해야할 점은 .value 코드를 꼭 작성해주셔야 오류가 발생하지 않습니다.

이번엔 위 쓰기 내용을 조금 더 응용하여 임의의 숫자 리스트를 작성하고 일렬로 세워 입력하는 코드를 작성해보겠습니다.

<코드>

datalist = [2,4,8,16,32,64,128,256] #임의의 숫자 리스트 정의

i=1  # 행값을 바꾸기 위한 인덱스 정의

for  data  in  datalist:
    ws.cell(row = i, column=1).value = data  #A열(Column=1)에 행을 바꾸면서 입력
    i=i+1  #행값 증가

wb.save("result.xlsx")

<결과>


3. Cell data 삭제하기

Cell의 data를 삭제 하는 방법은 간단합니다. 대표적인 방법은 3가지를 소개하겠습니다.


1) cell.value 값을 공백으로 설정하기

저희는 "2. Cell에 data 쓰기" 파트에서 원하는 Cell에 data를 쓰는 방법을 배웠습니다. Data를 삭제하는 방법은 입력 값을 공백으로 두는 것입니다. 아래 예시를 확인해보겠습니다.

위 엑셀 파일에서 짝수 data만 공백으로 처리하는 코드를 작성해보겠습니다. 위에서 다뤘던 내용과 같이 "A1:C9" 영역을 튜플로 저장해서 조건문으로 처리해보겠습니다.

<코드>

import  openpyxl  as  op

#Workbook 객체 생성
wb = op.load_workbook("./Project/16. openpyxl 차트, 피벗/test data.xlsx")

#'test'라는 이름을 가진 Sheet를 객체로 생성
ws = wb['test']

#ws에서 데이터범위 설정
rng = ws["A1:C3"] #A1:C3 범위 저장(Cell 9개)

#튜플에 대한 for 문
for  row_data  in  rng:
    for  data  in  row_data:
        #해당 data가 2로 나눈 나머지가 0이면 공백처리
        if (data.value % 2) == 0:
            data.value = ""

#Workbook 객체 저장
wb.save("./Project/16. openpyxl 차트, 피벗/delete_result.xlsx")

<결과>

결과 이미지에서 보듯이 짝수만 삭제된 것을 확인할 수 있습니다. 코드내용은 위 "1. Cell Data 읽기"에서 다뤘던 내용이므로 주석을 보며 다시 이해해보도록 합시다.


2) delete_rows, delete_cols 사용하기

1)에서 다뤘던 내용은 내용을 삭제하는 방법이지만 어떻게 보면 공백 ""을 입력하는 과정으로 "2. Cell Data 쓰기"와 크게 다를 점이 없습니다.

Openpyxl에서는 delete_rows, delete_cols 함수를 제공합니다. 이 함수들은 원하는 행이나 열을 설정한 범위 기준으로 삭제해줍니다. 1)과 다른 점은 Cell data만 삭제하는 것이 아닌 행, 열을 제거한다는 것입니다.

아래 예시를 보며 이해해보겠습니다. 먼저 사용법은 아래와 같습니다. 

"Worksheet 객체명".delete_rows(첫행 값, 첫행부터 몇개까지?)
"Worksheet 객체명".delete_cols(첫열 값, 첫열부터 몇개까지?)

위 엑셀 파일을 활용하여 코드 테스트를 진행해보겠습니다. 먼저 행을 기준으로 삭제하는 방법입니다. 행을 기준으로 삭제할 때는 delete_rows 함수를 사용합니다.

주의해야 할 점은 괄호 안의 숫자 값입니다. delete_rows(1,2)의 의미는 1행부터 2행까지가 아니라 1행부터 시작해서 2개까지 라는 의미입니다.

<코드>

import openpyxl as op

#Workbook 객체 생성
wb = op.load_workbook("./Project/16. openpyxl 차트, 피벗/delete_test.xlsx")
#활성화 된 Sheet를 객체로 생성
ws = wb.active

#1행부터 2개행까지 행을 삭제한다.
ws.delete_rows(1,2)

#Workbook 객체 저장
wb.save("./Project/16. openpyxl 차트, 피벗/delete_result.xlsx")

<결과>

열을 기준으로 삭제하는 delete_cols도 사용법은 동일합니다. 마찬가지로 괄호 (2,1)의 의미는 2열부터 1개 열까지라는 의미입니다. 따라서 2열만 삭제됩니다.

<코드>

ws = wb.active

ws.delete_cols(2,1)

wb.save("./Project/16. openpyxl 차트, 피벗/delete_result.xlsx")

<결과>


3) 시트를 통째로 삭제하고 다시 생성하기

한 시트의 데이터를 모두 지우기 위해서는 1), 2)와 같이 공백값을 입력하거나 데이터가 있는 행,열을 모두 삭제하는 방법이 있습니다.

추가로 한가지 팁을 드리자면, 이번 방법과 같이 시트를 통째로 삭제하고 다시 생성하는 방법도 있습니다.(초기화)

.remove 함수로 시트를 삭제했고, .create_shet 함수로 시트를 똑같은 이름으로 다시 생성했습니다. 시트를 생성하거나 조작하는 방법은 "3-1-8) WorkSheet 조작하기" 파트에서도 다루니 참고하시면 됩니다.

<코드>

import openpyxl as op

#Workbook 객체 생성
wb = op.load_workbook("./Project/16. openpyxl 차트, 피벗/delete_test.xlsx")
#'test'라는 이름을 가진 Sheet를 객체로 생성
ws = wb['test']
#test 시트 삭제
wb.remove(ws)
#test 시트 재생성
wb.create_sheet('test')

wb.save("./Project/16. openpyxl 차트, 피벗/delete_result.xlsx")
