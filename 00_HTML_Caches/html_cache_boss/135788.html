3-1. Excel - OpenPyxl 소개

파이썬에서 엑셀 업무 자동화에 자주 쓰이는 openpyxl 라이브러리에 대해 알아봅시다. openpyxl은 엑셀의 데이터를 읽거나 쓰고 제어할 수 있는 대표적인 라이브러리입니다. 해당 챕터는 openpyxl의 모든 부분에 대해서 설명하진 않습니다. 업무 자동화에 자주 쓰이는 내용과 저자가 실제 자동화 프로그램에 활용하고 있는 기초적인 내용에 대해 학습합니다. 책에서 다루지 않는 내용에 대해서는 openpyxl 공식 홈페이지를 참고하시기 바랍니다.

Openpyxl 공식 페이지 : https://openpyxl.readthedocs.io/en/stable/tutorial.html
