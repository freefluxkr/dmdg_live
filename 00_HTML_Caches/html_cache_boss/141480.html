5) 엑셀 함수 쓰기 - max_row, max_column 속성의 이해

openpyxl을 통해 엑셀 함수를 사용할 수 있을까요? 해당 파트는 openpyxl을 통해 엑셀 함수를 적용하는 법을 공부합니다. 정확히는, 엑셀 함수를 Cell에 쓰는 방법입니다.

먼저 아래 가상의 예시를 만들어보았습니다. 지출내역을 정리한 엑셀 파일입니다.

1. Cell에 엑셀 함수 써보기

간단한 예시를 보여주기 위해 위 이미지 지출 내역의 총 합계를 구하고 엑셀에 표시해주는 코드를 작성해볼 것입니다. 사실 엑셀에서 SUM 함수를 사용하는게 가장 빠릅니다. 이 책의 목적은 openpyxl을 통해 업무 자동화에 활용하는 방법을 배우는 것이므로 파이썬 코드로 작성해보겠습니다.

엑셀을 아시는 분이라면 위 지출 합계를 구하기 위해선 "=SUM(C:C)"를 사용하면 된다는 것을 아실겁니다. 실제로 파이썬 코드로 엑셀 SUM 함수를 입력하면 적용되는지 확인해볼까요?

접근하는 엑셀파일명은 "test.xlsx", 위 시트는 활성화되어있는 상태입니다. 입력되는 Cell의 위치는 "E11"로 생각하고 코드를 작성해보겠습니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.load_workbook(r"test.xlsx") #워크북 객체 생성
ws = wb.active #시트 객체 생성

#엑셀 함수를 실제 Cell에 써보기
ws["E11"].value = "=SUM(C:C)"

wb.save("result.xlsx")

<결과>

결과 이미지에서 보시면 "E11"에 함수가 정상적으로 사용된 것을 확인할 수 있습니다.

2. 여러 줄에 함수 한번에 적용하기

"1. Cell에 엑셀 함수 써보기"에서 다뤘던 내용은 1개 Cell에 함수를 입력하는 방법입니다. 사실 엑셀을 사용하다 보면 여러 줄에 동시에 적용해야 하는 경우가 더 많습니다.

다음 예시에는 코드를 어떻게 작성하면 될지 확인해봅시다. 위 1번에서 다뤘던 예시를 조금 수정하여 지출 내역에서 단가(C열), 인원(D열)을 통해 총 가격을 구해보는 함수를 파이썬을 통해 적용해보겠습니다.

이전과 다른 점이라면 "E"열에 행마다 함수를 다르게 적용해야 한다는 점입니다. "줄 별로 계산식을 다 넣으면 되지 않을까요?" 라고 생각하실 수도 있지만, 이 책은 업무자동화를 다루고 있으므로 파이썬스럽게 for 반복문을 통해 코드를 작성할 것입니다. 지출내역부는 데이터가 계속 추가될 수 있는 점도 고려할겁니다.

코드를 작성하기 전에 먼저 WorkSheet(ws)의 속성 2가지를 추가로 알아보겠습니다. openpyxl에는 이전 파트에서 다뤘던 WorkSheet의 .rows, .columns 말고도 데이터가 입력 된 최대 행 값, 열 값을 정수로 반환하는속성도 존재합니다. 바로 .max_row와 .max_column입니다. 아래 코드를 보며 이해해보겠습니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import 

wb = op.load_workbook(r"test.xlsx")

ws = wb.active 

#해당 시트의 최대 행값, 최대 열값 구하기

col_max = ws.max_column
row_max = ws.max_row

#출력해보기
print("최대행값 : ", row_max)
print("최대열값 : ", col_max)

<결과>

최대행값 :  11
최대열값 :  5

결과에서 보시다시피, 최대 행값과 최대 열값을 정수로 반환합니다. 데이터를 새로 추가하면 최대 행값과 최대 열값은 자동으로 바뀌게 됩니다. 이번 코드는 이 row_max값을 활용해 작성할 것입니다.

이번에 계산해야 할 총 가격(단가 x 인원)은 엑셀 열로 따지면 C x D입니다. 즉, 두번째 행의 함수는 "=C2 x D2", 3번째 행의 함수는 "=C3 x D3"로 각행마다 열 번호가 바뀌면서 반복됩니다. 따라서 행의 시작값은 2, 행의 마지막 값은 row_max로 반복문이 진행될 것입니다.

아래 코드는 설명 드린 내용을 파이썬 코드로 구현한 것입니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.load_workbook(r"test.xlsx") #Workbook 객체 생성
ws = wb.active #활성화 된 시트 객체 생성 

row_max = ws.max_row  #최대 행값 저장

#for문 통해 2행~최대행까지 반복문
#range(a,b+1) : a부터 b까지 반복하는 range 구문
for  row  in  range(2, row_max+1):
    #함수 자동 작성
    ws["E"+str(row)].value = "=C"+str(row)+"*"+"D"+str(row)

wb.save(r"result.xlsx") #결과 엑셀파일 저장

<결과>

E 열에 행마다 함수가 적용되어 계산되어 결과 값을 확인할 수 있습니다. 한가지 주의해야할 점은, 위 반복문의 정수 row를 str(row)로 표기한 것입니다. 엑셀 함수를 적용하는 것은 각 Cell에 문자열을 입력하는 것이므로 row 그대로 입력하면 에러가 발생합니다. 정수 타입의 row를 str( ) 함수를 통해 문자열로 변경함으로써, 에러를 해결할 수 있습니다.

각 계산될 대상(C열,D열)을 리스트나 튜플로 데이터를 입력받아 파이썬에서 계산하여 값을 출력하는 방법도 있습니다. 이번 학습 내용은 "엑셀 함수로 적용이 더 쉽다면 위와 같이 openpyxl을 통해 함수를 쓰는 방법도 있다"는 방법을 알려 드리기 위해 쓴 파트입니다.

3. 함수 결과를 다시 읽어보기

위에서 적용한 함수 열 "E"열을 행 별로 읽어와서 리스트로 저장하는 코드를 작성해보겠습니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

#위 결과 파일을 기준으로 Workbook, WorkSheet 객체 생성
wb = op.load_workbook(r"result.xlsx")
ws = wb.active

#빈 리스트 생성
data = [] 

#ws.rows 속성 활용하여 for문 진행
for  row  in  ws.rows:
    data.append(row[4].value) #E열 데이터를 리스트에 추가

print(data) #최종 리스트 출력

<결과>

['총 가격(단가*인원)', '=C2*D2', '=C3*D3', '=C4*D4', '=C5*D5', '=C6*D6', '=C7*D7', '=C8*D8', '=C9*D9', '=C10*D10', '=C11*D11']

결과를 확인해보시면 총 가격(E열)에 대한 결과가 리스트로 저장된 것을 확인할 수 있습니다. 그런데 한가지 이상한 점이 보이시죠? 계산된 결과가 아니라 엑셀에 적용했던 수식이 그대로 저장되었습니다. 업무자동화에 활용하려면 수식으로 계산된 값을 읽어오는 방법이 필요할 것입니다.

이 부분은 코드 중 기존 파일을 Workbook 개체로 생성하는 .load_workbook( ) 함수의 내부 옵션값을 수정하면 됩니다. 내부 옵션값에는 data_only와 read_only라는 항목이 있습니다. 2개 옵션에 대해 아래 설명 및 예시를 보며 이해해봅시다.

data_only = True일 경우 수식이 계산된 값을 읽어옵니다. (기본 False이므로 설정하지 않으면 함수나 수식 그대로 읽어옵니다.)

read_only = True일 경우 읽기 전용으로 읽어오는 옵션입니다. 엑셀을 수정하지 않고 데이터만 읽어올 경우 read_only=True로 작성하는게 속도 측면에서 빠릅니다. (기본 False이므로 설정하지 않으면 읽기/쓰기 모두 가능합니다.)

그럼 수식으로 계산 된 결과값을 읽어오기 위해 data_only=True를 추가하여 코드를 작성해봤습니다.

<코드>

wb = op.load_workbook(r"result.xlsx", data_only=True)
ws = wb.active

data = [] #빈 리스트 생성

for  row  in  ws.rows:
    data.append(row[4].value)

print(data)

<결과>

['총 가격(단가*인원)', None, None, None, None, None, None, None, None, None, None]

이번엔 수식이 아닌 결과값이 없다는 표시의 None이 나오네요. 사용자에 따라 결과값을 바로 확인할 수 있는 분도 있고 위 경우 처럼 None이 출력되는 분도 계실겁니다. None 이 나오시는 분은 불러온 엑셀파일을 한번 실행시켜서 저장한 후, 다시 코드를 실행시켜보도록 하겠습니다.

<결과>

['총 가격(단가*인원)', 10000, 30000, 39000, 100000, 15000, 15000, 30000, 39000, 100000, 20000]

정상적으로 결과를 확인할 수 있습니다. 위와 같은 현상이 나오는 이유는 openpyxl 라이브러리의 특성 때문입니다. 저희는 "2. 여러 줄에 엑셀 함수 적용하기" 파트에서 함수를 적용 후 엑셀 파일을 .save( ) 함수를 통해 저장했었죠?

openpyxl에서는 "=C2D2"와 같은 수식을 문자열로 인식하여 엑셀 파일에 입력은 하지만 실제 위 수식을 계산하여 표시하진 않습니다. 계산의 영역은 파이썬이 아닌 실제 엑셀 프로그램의 영역이기 때문입니다. 그래서 파이썬 코드 상에서 .save( )를 하고 그대로 "result.xlsx' 결과 파일을 읽어오면 저희가 입력한 수식 문자열을 그대로 불러오는겁니다.

따라서, 엑셀 파일을 직접 실행하면 저희가 코드를 통해 입력했던 수식은 자동으로 계산이 되고, 그 때 저장이 되면 수식이 계산된 값을 인식하게 됩니다. 그런데 엑셀파일을 실행시키고 저장하는 부분을 직접하려면 굉장히 번거롭겠죠? 이 부분도 코드로 작성해보겠습니다. 엑셀을 직접 실행시키고 저장시키는 부분은 win32com 라이브러리를 사용하시면 됩니다. 아래 코드를 앞에 추가하시면 됩니다.*

<코드>

import  win32com.client #win32com.client 모듈 import

#excel 사용할 수 있게 설정
excel = win32com.client.Dispatch("Excel.Application")

#임시 Workbook 객체 생성 및 엑셀 열기
temp_wb = excel.Workbooks.Open(r"result.xlsx")

#저장
temp_wb.Save()

#excel 종료
excel.quit()

이 파트에서는 win32com에 대해서는 자세히 설명하지 않겠지만 win32com을 통해 엑셀을 직접 실행시키고 저장할 수 있습니다. win32com에 대해서는 3-4) 챕터에서 설명드리겠습니다.

아래는 이번 "5)엑셀 함수 쓰기" 파트를 정리한 전체 코드입니다. 본인 엑셀 파일에 맞게 수정하여 테스트해보시기 바랍니다.

<전체 코드>

import  openpyxl  as  op  #openpyxl 모듈 import
import  win32com.client



def  writeFunc():
    wb = op.load_workbook(r"test.xlsx") #Workbook 객체 생성
    ws = wb.active  #활성화 된 시트 객체 생성

    row_max = ws.max_row  #최대 행값 저장

    #for문 통해 2행~최대행까지 반복문
    #range(a,b+1) : a부터 b까지 반복하는 range 구문
    for  row  in  range(2, row_max+1):
    #함수 자동 작성
        ws["E"+str(row)].value = "=C"+str(row)+"*"+"D"+str(row)

    wb.save(r"result.xlsx") #결과 엑셀파일 저장


def  loadData():
    #엑셀 직접 실행시키고 저장 및 종료
    excel = win32com.client.Dispatch("Excel.Application")
    temp_wb = excel.Workbooks.Open(r"result.xlsx")
    temp_wb.Save()
    excel.quit()

    #openpyxl 통해 Workbook 객체 및 WorkSheet 객체 생성
    wb = op.load_workbook(r"result.xlsx", data_only=True)
    ws = wb.active

    #빈 리스트 생성
    data = []

    #ws.rows 속성 활용하여 for문 진행
    for  row  in  ws.rows:
        data.append(row[4].value) #E열 데이터를 리스트에 추가

    print(data) #최종 리스트 출력

if  __name__ == "__main__":
    writeFunc() #writeFunc 실행
    loadData() #loadData 실행
