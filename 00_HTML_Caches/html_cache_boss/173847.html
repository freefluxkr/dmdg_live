수료증 발급 자동화

외부 교육을 듣고 나면 제출용으로 수료증을 발급해주는 경우가 있습니다. 교육 참가자가 적다면 워드 양식을 켜서 한명씩 수정하면서 발급이 가능할테지만, 만약 교육 규모가 크고 자주 있다면 교육 담당자는 수료증을 발급하는 업무만 해도 많은 시간을 소모할 것입니다.

이번 연습하기 시간에는 이번 챕터에서 배운 지식과 지난 액셀 챕터에서 배운 내용을 토대로 ‘액셀 시트의 교육 참가자 명단을 참고해서 수료증을 자동으로 작성하고 저장’하는 것을 해보겠습니다.

우선 Word 양식을 불러와서 구조를 파악해봅시다. 보통은 각자의 회사에서 사용하는 양식이 이미 있는 경우가 대부분이기 때문에, 양식을 A부터 Z까지 코드로 구현하는 것은 생략하겠습니다.

저는 아래와 같은 양식을 만들어서 ‘교육 수료증.docx’라는 파일명으로 저장하였습니다.

step1. 가장 처음으로 해줄 작업은 양식의 구조를 파악하는 일입니다. 구조 파악을 위해 아래의 코드를 실행해보세요.

코드

from docx import Document

doc = Document('인덱싱 예제 문서.docx')

for i, paragraph in  enumerate(doc.paragraphs):

print(str(i)  +  ": "  + paragraph.text)

step2. 바꿔 줄 부분을 정하고, 다른 정보로 수정해보겠습니다. 저는 같은 차수의 교육을 들은 교육생들의 수료증을 발급해주는 상황을 가정하고 성명과 생년월일만 바꿔주어 보겠습니다.

코드

from docx import Document

doc = Document('교육 수료증.docx')

#스타일 적용하기 (일반 텍스트, 글꼴은 ‘맑은고딕체’)
from docx.oxml.ns import qn
style = doc.styles['Normal']
style.font.name =  '맑은 고딕'

style._element.rPr.rFonts.set(qn('w:eastAsia'), '맑은 고딕')

# 성명 수정
p = doc.paragraphs[3]
p.text = '성 명: 이지은'

# 생년월일 수정
p = doc.paragraphs[4]
p.text = '생년월일: 1993-05-16'

#저장
doc.save('교육 수료증_아이유.docx')

step3. Word 양식과 내용 변경 방법을 알아보았으니, 엑셀 리스트와 연동할 차례입니다. 수강생들의 리스트가 엑셀로 잘 정리되어 있다고 가정하고 진행해보겠습니다.

Word 파일에 바로 입력하기 전에 쉬운 이해를 돕기 위해서 명단이 포함된 엑셀 파일에서 성명과 생년월일을 순서대로 불러와서 print( )함수로 출력시켜 보겠습니다.

from openpyxl import load_workbook

wb = load_workbook("수강생 명단.xlsx")
ws = wb.active

for i in  range(ws.max_row):

    if i !=  0: # 가장 첫줄(성명, 생년월일) 제거

step4. 엑셀에서 원하는 데이터를 가져왔으니, 차례대로 수료증을 작성해봅시다.

코드

from docx import Document
from docx.oxml.ns import qn
from openpyxl import load_workbook

#스타일 적용하기 (일반 텍스트, 글꼴은 ‘맑은고딕체’)
style = doc.styles['Normal']
style.font.name =  '맑은 고딕'
style._element.rPr.rFonts.set(qn('w:eastAsia'), '맑은 고딕')

doc = Document('교육 수료증.docx')
wb = load_workbook("수강생 명단.xlsx")

ws = wb.active

for i in  range(ws.max_row):
    name = ws.cell(row=i+1,  column=1).value
    birth = ws.cell(row=i+1,  column=2).value

    if i !=  0:

        # 성명 수정
        p = doc.paragraphs[3]
        p.text =  '성 명: '  + name

        # 생년월일 수정
        p = doc.paragraphs[4]
        p.text =  '생년월일: '  +  str(birth)[:10]

    #저장
    doc.save('교육 수료증_'  + name +  '.docx')
