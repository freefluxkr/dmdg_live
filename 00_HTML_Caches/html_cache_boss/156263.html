4) win32com 통해 엑셀 다루기 - Sheet 제어

이번 파트는 win32com.cleint 모듈을 사용하여 엑셀 시트를 다루는법을 알아보겠습니다. 서론에서 win32com.client가 엑셀의 기능적인 측면에서 OpenPyxl보다 더 편리하다라고 언급한 적이 있습니다.

예를 들어, win32com.client로 엑셀 시트를 제어하면 여러 엑셀 파일간 시트 이동/복사가 가능해집니다. (OpenPyxl에서는 불가능한 작업입니다.)

아래 5가지 부분으로 나누어 설명해보도록 하겠습니다.

1 시트 생성 및 설정하기

2 시트 복사/이동하기

3. 시트 삭제하기

4. 시트 이름 변경하기

5. 시트 탭 속성 설정하기


1. 시트 생성 및 설정

"2) win32com 통해 엑셀 다루기 - Cell 데이터 읽기/쓰기" 파트에서도 다뤘지만 win32com.client를 통해 엑셀을 다룰 때는 아래 과정을 필수로 거쳐야 합니다.

win32com.client 모듈을 임포트하고 엑셀 프로그램을 변수(excel)로 바인딩하는 과정입니다. 변수는 꼭 "excel"로 지정하실 필요는 없습니다. 여러분이 편하게 사용할 수 있는 변수로 지정하시면 됩니다.

#win32com.client 모듈 임포트
import win32com.client

#Excel 프로그램 객체 생성
excel=win32com.client.Dispatch("Excel.Application")

#엑셀 실행과정이 보이게 설정
excel.Visible = True

앞으로의 과정은 위 코드가 앞에 작성되어 있다는 가정하에 설명하도록 하겠습니다.

먼저 시트를 생성하는 코드는 아래와 같습니다. 이전 편에서 설명드렸듯이 Workbook 객체를 변수로 설정하고 그 변수를 이용하여 WorkSheet 객체를 생성합니다.

#기존에 있는 "data1.xlsx"파일을 Workbook 객체로 설정
wb1 = excel.Workbooks.Open(r"C:\Users\Desktop\VS CODE\Project\17. win32com\data1.xlsx")

#data1.xlsx 파일에 새로운 Worksheet 생성 및 ws1으로 객체 설정
ws1 = wb1.Worksheets.Add()

위 과정은 "data1.xlsx"파일에 새로운 "Sheet1"이라는 시트를 생성하여 ws1이라는 변수로 설정합니다.(아래 이미지)

이해를 위해 한번더 똑같은 코드를 실행해보겠습니다. 이번에는 변수 ws2로 설정하였습니다.

#data1.xlsx 파일에 새로운 Worksheet 생성 및 ws2으로 객체 설정
ws2 = wb1.Worksheets.Add()

이번에는 "Sheet2"가 새로 생성되었죠? WorkSheets.Add( )라는 메서드는 워크시트를 "Sheet"+번호 형식으로 시트를 새로 생성합니다.

옆에 있는 "test" 시트는 기존 "data1.xlsx"에 만들어져 있던 시트입니다. 만약, 기존에 만들어져 있던 시트에 접근하려면 아래와 같이 코드를 작성합니다.

#현재 활성화되어 있는 시트를 객체로 설정(위 이미지 기준 Sheet2)
ws3 = wb1.ActiveSheet

#특정 시트명으로 접근(Sheet1으로 접근)
ws4 = wb1.Worksheets("sheet1")

시트를 변수로 설정하는 방법을 알고 있으면 사용자가 원하는 시트에 접근하여 데이터를 읽거나 쓸 수 있습니다.


2. 시트 복사 및 이동

서론에서도 설명하였지만 win32com.client 모듈을 통해 엑셀을 다룰 때 가장 큰 장점은 엑셀의 본래 기능적인 측면에서 프로그램을 제어할 수 있는 것입니다. 따라서, 엑셀에서 제공하는 시트 이동/복사 기능을 제공합니다. 같은 파일 뿐만 아니라 다른 파일 간 시트 이동/복사도 가능합니다.

이번에 저희가 학습해볼 내용은 파일간 시트/이동복사 기능을 구현하는 것입니다. (위 그림)

위 그림과 같이 "data1.xlsx" 파일의 "test" 시트를 "data2.xlsx" 파일에 복사하는 코드를 작성해보겠습니다.

먼저 테스트를 위해 2개 파일을 각각 Workbook 객체로 설정해봅시다.

#"data1.xlsx" 파일을 wb1로 설정
wb1 = excel.Workbooks.Open(r"C:\Users\Desktop\VS CODE\Project\17. win32com\data1.xlsx")

#"data2.xlsx" 파일을 wb2로 설정
wb2 = excel.Workbooks.Open(r"C:\Users\Desktop\VS CODE\Project\17. win32com\data2.xlsx")

위 이미지 상으로 설명하면 wb1 객체에 속해있는 "test" 시트를 wb2 객체로 복사하면 됩니다.

#wb1의 "test" 시트를 wb2의 "Sheet1" 앞으로 복사한다.
wb1.Worksheets("test").Copy(Before=wb2.Worksheets("Sheet1"))

위 코드대로 구현하면 아래와 같이 "data2.xlsx" 파일에 "test" 시트가 복사되게 됩니다.

위에서 코드를 보면 궁금하신 부분이 있을겁니다. Copy( ) 함수 내부에 있는 Before라는 옵션인데요. Before 설정값은 시트를 어떤 위치에 복사할지를 설정할 수 있습니다. 위 코드대로 하면 wb2의 "Sheet1" 객체 앞(before)로 복사한다고 이해하시면 됩니다.

만약, 위치를 "Sheet1" 객체 뒤(After)로 복사하고 싶으면 아래와 같이 코드를 작성합니다.

#wb1의 "test" 시트를 wb2의 "Sheet1" 뒤로 복사한다.
wb1.Worksheets("test").Copy(After=wb2.Worksheets("Sheet1"))

시트 이동은 Copy( )라는 메서드에서 Move( )라는 함수로 변경만 해주시면 됩니다. 프로그램 실행과정에서는 시트가 이동이 됐는데 엑셀파일을 다시 실행시켰을 때 반영이 안되어있다면, 코드 중에 엑셀 파일을 저장하는 부분이 없는 것이니 Save 코드를 작성해주시면 됩니다.(전편 참고)

참고로, win32com.client의 서론에서도 설명한 부분이지만 같은 Microsoft에서 개발 된 언어인 엑셀 VBA와 매우 유사한 형태를 띄고 있습니다. 자료를 참고하고 싶다면 Microsoft의 VBA Documentaion을 확인하시면 됩니다. 아래 내용은 Copy( ) 메서드의 옵션값(Before, After)를 설명하는 내용입니다.


3. 시트삭제

이번에는 시트를 생성해보고 그 시트를 다시 삭제하는 코드를 작성해보겠습니다.

먼저 WorokBook 및 WorkSheet 객체를 새로 생성해보겠습니다.

wb = excel.Workbooks.Add() #엑셀 Workbook 파일 1개 새로 생성

ws = wb.Worksheets.Add() #엑셀 시트를 새로 생성

위 결과 이미지를 보시면 Sheet1, Sheet2가 생성되어 있습니다. 엑셀은 기본적으로 WorkBook 1개를 생성했을 때, "Sheet1"을 가지게 됩니다. 따라서, Worksheets.Add( )를 하면 "Sheet2"가 새로 생성되는 점 참고해주세요.

위 이미지에서 "Sheet1"을 삭제하려고 합니다.

#"Sheet1"을 ws로 설정
ws = wb.Worksheets("Sheet1")
#ws 삭제
ws.Delete()

위 코드는 풀어쓰면 아래와 코드와 동일한 코드입니다.

#"Sheet1" 삭제하기
wb.Worksheets("Sheet1").Delete()


4. 시트 속성 설정(시트명, 시트탭 색)

시트명을 변경하려면 아래와 같이 코드를 작성합니다.

#"Sheet2"을 ws로 설정
ws = wb.Worksheets("Sheet2")
#ws 시트명 바꾸기
ws.Name = "시트 이름 바꾸기"

위 "시트 이름 바꾸기" 시트탭의 색상을 변경하려면 아래와 같이 코드를작성합니다.

ws.Tab.ColorIndex = 30

"Worksheet 객체".Tab.ColorIndex = "번호" 와 같은 형태로 작성하면 시트탭 색상을 변경할 수 있습니다.

Microsoft에서 제공하는 엑셀 ColorIndex는 1~56이며, 각 번호가 뜻하는 색상은 구글링을 하면 쉽게 찾아볼 수 있으니 참고하시면 됩니다. (Excel Color Index 검색)
