4) rows, columns 속성 이해하기

openpyxl의 Sheet 객체(WorkSheet)에는 .rows와 .columns라는 속성이 있습니다. 이 속성들을 설명하기 전에 이전 편에서 설명했던 숫자 배열 이미지 및 코드를 그대로 가져오겠습니다.

<코드>

rng = ws["A1:C3"] #A1:C3 범위 저장(총 9개 Cell)
print(rng) #결과 출력(튜플)

<결과>

((<Cell '업'.A1>, <Cell '업'.B1>, <Cell '업'.C1>), (<Cell '업'.A2>, <Cell '업'.B2>, <Cell '업'.C2>), (<Cell '업'.A3>, <Cell '업'.B3>, <Cell '업'.C3>))

위에서 엑셀 다중 영역을 설정하기 위해 ws["A1:C3"]을 통해 각 Cell의 위치 정보를 rng 라는 변수에 저장했었습니다. 그런데 만약, 아래와 같이 데이터를 추가로 입력했다고 가정해봅시다.

"D"열에 숫자 [10,11,12]를 추가로 입력하였습니다. 만약, 엑셀 Cell에 입력 된 모든 데이터를 읽어오는 코드를 작성하였다면 위에서 작성했던 코드는 영역 설정 부분을 수정해야 합니다. 이미지와 같이 "A1:C3"를 "A1:D3"로 변경해야 합니다. 또, 데이터가 추가로 입력되면 다시 영역을 수정해야 할 것입니다.

만약, 데이터가 새로 입력되어도 영역을 자동으로 설정해주는 코드가 있다면 업무 자동화에서 좀 더 유용하지 않을까요? 이런 문제를 해결해주는 것이 Sheet의 속성인 .rows와 .columns입니다.

아래 예시를 통해 두 속성을 이해해보도록 합시다.

먼저 위 이미지를 기준으로 WorkSheet 객체를 생성하고 .rows와 .columns를 출력해보도록 하겠습니다.

1. rows 출력하기

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.load_workbook("test.xlsx") #Workbook 객체 생성
ws = wb["업"] #"업"시트 객체 생성

print("#rows 출력")
for  row_rng  in  ws.rows:
    print(row_rng) #각 행에 대한 1차원 배열 출력(위치정보)

<결과>

#rows 출력
(<Cell '업'.A1>, <Cell '업'.B1>, <Cell '업'.C1>)
(<Cell '업'.A2>, <Cell '업'.B2>, <Cell '업'.C2>)
(<Cell '업'.A3>, <Cell '업'.B3>, <Cell '업'.C3>)

ws["A1:C3"]와 결과가 동일해보이지만 자세히 보시면 다릅니다. ws["A1:C3"]는 2차원 배열(튜플)이었고 이번 ws.rows는 각각의 1차원 배열이 출력되었습니다. 위 결과는 1차원 배열이 3번 출력 된 결과입니다. 각 1차원 배열은 행(row)의 위치 정보를 담고 있습니다.

2. columns 출력하기

<코드>

print("#columns 출력")
for  col_rng  in  ws.columns:
    print(col_rng)

<결과>

#columns 출력
(<Cell '업'.A1>, <Cell '업'.A2>, <Cell '업'.A3>)
(<Cell '업'.B1>, <Cell '업'.B2>, <Cell '업'.B3>)
(<Cell '업'.C1>, <Cell '업'.C2>, <Cell '업'.C3>)

ws.columns을 출력한 결과를 확인해봅시다. ws.rows와 다른 점은 각 1차원 배열(튜플)의 결과가 열의 정보를 담고있다는 겁니다. 위에서 다뤘던 .rows와 .columns의 차이를 도식화해보면 아래와 같습니다.

ws.rows 또는 ws.columns 은 파이썬 이터레이터(iterator)입니다. 이 책의 영역에서 벗어나 이터레이터에 대해 자세한 설명은 하지 않겠으나, 내부 값을 출력하기 위해선 반복문(for)를 사용해야 한다는 것을 기억해주시면 됩니다.

3. 데이터 추가 후, rows 출력해보기

그럼 위 엑셀 파일에서 "D"열에 [10,11,12,13]를 입력하고 1) ws.rows 코드를 적용하여 다시 출력해보도록 하겠습니다. 열별로 차이를 두기 위해 "D"열에는 4개 데이터를 입력하였습니다.

그리고 "1) rows 출력하기"의 코드를 그대로 적용해보겠습니다.

<결과>

#rows 출력
(<Cell '업'.A1>, <Cell '업'.B1>, <Cell '업'.C1>, <Cell '업'.D1>)
(<Cell '업'.A2>, <Cell '업'.B2>, <Cell '업'.C2>, <Cell '업'.D2>)
(<Cell '업'.A3>, <Cell '업'.B3>, <Cell '업'.C3>, <Cell '업'.D3>)
(<Cell '업'.A4>, <Cell '업'.B4>, <Cell '업'.C4>, <Cell '업'.D4>)

마지막 행이 자동으로 추가가 되었습니다. 예시처럼 .rows와 .columns 속성은 입력 된 데이터에 따라 자동으로 위치를 인식하여 결과를 반환하여 줍니다.

위 결과값을 .value 속성을 활용하여 실제값을 출력해봅시다.

<코드>

print("#rows 출력")
for  row_rng  in  ws.rows:
    for  cell  in  row_rng: #각 행에 대한 1차원 배열 for문
        print(cell.value)

<결과>

#rows 출력
1
4
7
10
2
5
8
11
3
6
9
12
None
None
None
13

결과에 None이 포함되어 있습니다. 위 엑셀 양식을 보시면 A4, B4,C4가 빈칸인 것을 확인할 수 있죠? D4에 데이터가 입력됨으로써 A4:C4 영역도 같이 저장되었기 때문에 그렇습니다. 만약 None을 빼고 출력하고 싶다면 If문을 사용하시면 됩니다.

아래 코드로 변경하여 실행시켜 결과를 확인해보시기 바랍니다.

<코드>

print("#rows 출력")
for  row_rng  in  ws.rows:

    for  cell  in  row_rng: #각 행에 대한 1차원 배열 for문
        if  cell.value != None: #None인경우 출력 제외
            print(cell.value)
