3) VBA에서 파이썬 코드 실행시키기

이번 파트에서는 VBA에서 파이썬 코드를 실행시키는 방법을 알아보겠습니다.

1. 파이썬 코드 작성하기

파이썬 코드를 VBA에서 동작시키기 전에 동작 시킬 파이썬 테스트 코드를 작성해보겠습니다. 아래 파이썬 코드 파일명은 "py1.py"입니다.

<코드>

import  xlwings

def  main():
    #xlwings 통해 Workbook 호출
    wb = xlwings.Book.caller()

    #Sheet 설정
    sheet = wb.sheets[0]

    #텍스트 입력
    sheet["A1"].value = "xlwings 테스트 코드 작성"
    sheet["A2"].value = "파이썬 업무 자동화"

if  __name__== "__main__":
    path = r"C:\Users\Desktop\VS CODE\Project\practice"
    #매크로 파일 설정
    xlwings.Book(path+"/"+"p1.xlsm").set_mock_caller()
    #main 함수 호출
    main()

VBA를 활용하여 실행시키기 전에 파이썬에서 코드를 제대로 작성했는지 py1.py 파일 내에서 main( ) 함수를 호출해봅시다. 결과는 아래와 같습니다. "A1"과 "A2" 셀 위치에 텍스트가 출력됩니다.

2. VBA에서 파이썬 코드 호출하기

이제 위 파이썬 코드를 VBA에서 호출해보도록 합시다. 엑셀 VBA를 사용하는 방법에 대해서는 "3-1) 엑셀 VBA(Visual Basic for Application) 소개"에서 다뤘으니 해당 내용은 생략하고 다음 과정부터 진행해보겠습니다. VBA 엑셀 파일의 파일명은 "py1.xlsm"입니다.

엑셀 VBA에서 파이썬 코드를 호출할 때는, 파이썬 코드 파일이 같은 경로에 있어야 합니다. 즉, 현재 "py1.py" 파일과 "py1.xlsm"파일은 같은 경로에 있는 상태입니다.

그 다음, Alt+F11 을 눌러 VBA 개발 도구 창을 열고 모듈을 생성한 후, 아래 코드를 작성해보도록 합시다. 아래 코드는 엑셀 VBA 코드입니다.

Sub test()
    RunPython "import py1;"
    RunPython "py1.main()"
End Sub
