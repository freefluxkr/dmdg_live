2) WorkBook, WorkSheet 객체 설정하기

이번 파트에서는 openpyxl을 통해 Workbook을 생성하고, Sheet 를 설정하는 방법에 대해 알아보겠습니다. openpyxl을 통해 엑셀 파일을 제어하려면 무조건 거쳐야 하는 과정입니다.


1. openpyxl 설치 및 import 하기

openpyxl을 설치하고 모듈을 import 하는 방법을 알아보겠습니다.

1) openpyxl 설치

openpyxl은 파이썬의 내장 모듈이 아니므로 별도 설치 과정을 거쳐야 합니다. 사용하고 있는 개발 환경에 따라 터미널 창에 아래 명령어를 입력하여 openpyxl 모듈을 설치하도록 합시다.

#python
pip install openpyxl

#Anaconda
conda install openpyxl

2) import 하기

import openpyxl as op

앞으로 사용하는 코드는 위와 같이 import 했다고 가정하고 설명합니다. openpyxl을 코드 상에서는 'op'로 줄여 표현할 것입니다.


2. Workbook 객체 생성하기

Workbook을 생성한다는 의미는 사용자가 접근해야 할 엑셀 파일을 설정하겠다는 의미입니다. Workbook을 생성하는 경우는 2가지 케이스가 있습니다. 새로운 엑셀 파일을 만들거나, 원래 있는 파일에 접근하는 경우입니다.

1) 새로운 엑셀 파일을 만들 경우

새로운 엑셀 파일을 만드는 경우는 어렵지 않습니다. 아래와 같이 코드를 입력하면 새로운 Workbook 객체를 파이썬에서 생성합니다. 아직 저장한 상태는 아니므로, 실제 파일은 없는 상태입니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.Workbook() #새로운 Workbook 객체 생성

print(wb) #객체를 출력해보기

<결과>

<openpyxl.workbook.workbook.Workbook object at 0x0000020CB5E0A0C8>

wb를 출력해보면 openpyxl의 Workbook object라는 내용을 확인할 수 있습니다. 설명을 위해 출력을 해본 것이므로, 위 결과값이 무엇을 의미하는지는 몰라도 무관합니다.

생성한 Workbook 객체를 실제 파일로 저장하기 위해선 .save( )라는 함수를 사용하면 됩니다. 아래 코드는 위에서 생성한 Workbook 객체인 'wb'를 'openpyxl_test.xlsx' 라는 파일명으로 저장합니다.

wb.save("openpyxl_test.xlsx")

저장 할 위치를 정해주고 싶다면 아래와 같이 절대 경로(or 상대경로)로 입력하면 됩니다.

wb.save(r"C:\Users\Desktop\VS CODE\openpyxl_test.xlsx")

경로 안에 있는 r 표시는 unicode 에러 발생시 사용합니다. 파이썬에서는 역 슬래쉬를 인식하지 못하여 디코더 에러가 발생합니다. 따라서 경로를 표현할 때 슬래쉬(/)를 사용하거나, 역 슬래쉬를 사용해야 할 경우 문자열 앞에 r을 표기하여 줍니다.

2) 기존에 만들어져 있는 파일로 객체를 생성하는 경우

이번에는 새로운 엑셀 파일을 생성하는 것이 아닌 기존에 만들어져 있는 엑셀파일을 Workbook 객체로 생성해보겠습니다. 실제 업무 자동화에서는 기존 엑셀 파일을 가공하는 경우가 많기 때문에 2)의 경우를 더 많이 사용하기도 합니다.

기존 엑셀 파일을 Workbook 객체로 생성하고 싶다면, .load_workbook( ) 함수를 사용하면 됩니다. 아래 경로에 있는 'test.xlsx'파일을 Workbook 객체로 생성해보겠습니다.

먼저 위 파일이 있는 path를 변수를 통해 지정해보겠습니다. path라는 변수명을 가진 문자열이며, 위 주석에서 설명한 부분이지만 unicode 에러를 방지하기 위해 문자열 앞에 "r"을 표기하였습니다.

path = r"C:\Users\Desktop\VS CODE\Project\practice\연습"
wb = op.load_workbook(path + "/test.xlsx")

그리고 객체가 제대로 생성되었는지 확인하기 위해 print 함수를 통해 wb를 다시 출력해보겠습니다.

<openpyxl.workbook.workbook.Workbook object at 0x00000233DBA2F108>

wb를 출력해보면 Workbook 객체가 제대로 생성된 것을 확인할 수 있습니다. "2) 원래 있는 파일로 객체 생성하기"과 "1) 새로운 엑셀파일 만드기"는 WorkBook 객체를 생성하는 방법이 다를 뿐, .save( ) 함수를 사용하는 방법은 동일합니다.


3. WorkSheet 설정하기

2번 과정까지는 Workbook 객체를 새로 생성하거나 이미 만들어진 엑셀 파일에 접근할 것인지에 대한 내용이었습니다.

다음은, 엑셀 파일 내부의 어떤 Sheet에 접근할 것인지 Sheet를 설정해야 합니다. 3-1-1) 엑셀의 구성요소 파트에서 엑셀 파일 1개에는 여러개 Sheet가 있을 수 있음을 설명했습니다.

Sheet를 설정하는 방법은 Sheet를 새로 생성하여 객체를 설정하거나 기존 만들어진 Sheet로 설정하는 방법이 있습니다.

1) Sheet 객체 생성1 - 새로운 Sheet 만들기

Workbook과 마찬가지로 openpyxl은 Sheet를 새로 생성하는 기능도 제공합니다. 단 Sheet를 생성할 때 주의해야할 점은 해당 엑셀 파일의 객체(Workbook) 변수를 통해 접근해야 한다는 점입니다. 아래 코드 예시를 보며 이해해봅시다.

<코드> 

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.Workbook() #새로운 워크북 객체 생성

ws = wb.create_sheet("new_sheet1") #wb 객체를 통해 새로운 시트 생성(시트명 : new_sheet1)

print(ws) #ws 객체 출력해보기

wb.save("test_result.xlsx") #해당 워크북(엑셀파일) 저장하기

<결과>

<Worksheet "new_sheet1">

위 코드에서 새로운 시트를 생성하기 위해 wb.create_sheet( ) 라는 함수를 사용했습니다. 괄호 안의 내용은 생성할 Sheet명입니다. 주의해야할 점에서 앞에서 설명드렸다시피 Workbook 객체를 통해 생성해야 하기 때문에, "wb"라는 객체 변수로 Sheet를 생성했습니다.

만약 기존에 만들어진 엑셀 파일에 새로운 Sheet를 생성한다면 wb=op.load_workbook( ) 함수를 통해 Workbook 객체를 생성하시면 됩니다. (위 내용 중2-2) 참고)

ws를 출력해보면 Worksheet "new_sheet1" 라는 결과를 확인할 수 있습니다. 실제 저장 된 엑셀 파일에서 Sheet가 생성되었는지 확인해보도록 하겠습니다.

저장 된 엑셀 파일을 열어보면 "new_sheet1" 이라는 시트가 생성되었습니다. 하지만, 위 코드에서 생성하지 않았던 "Sheet"라는 시트도 보이네요. 이 것은 엑셀에서 Workbook 객체를 생성하면 기본적으로 Sheet 1개를 생성하기 때문입니다.

2) Sheet 객체 생성2 - 기존 만들어져 있는 Sheet에 접근하기

새로운 Sheet를 생성하는 것이 아닌 기존 만들어져 있는 Sheet에 접근하려면 어떻게 할까요?? 설명을 드리기 위해 "test.xlsx" 라는 엑셀 파일에 아래 5개의 Sheet를 임의로 생성하였습니다.(업,무,자,동,화)

기존에 만들어져 있는 Sheet에 접근하기 위한 방법은 2가지가 있습니다. 순서대로 알아보겠습니다.

첫번째 방법은 "활성화되어있는 Sheet"에 접근하는 방법입니다. "활성화 되어있는 Sheet"란 엑셀 파일에서 현재 선택되어 있는 Sheet입니다. 위 이미지의 경우 "업" 시트가 되겠네요. 활성화되어있는 Sheet의 경우 .active란 코드로 Sheet를 설정할 수 있습니다.

ws = wb.active #활성화되어있는 시트 설정
print(ws)

위 코드의 결과를 보면 아래와 같습니다. 

<Worksheet "업">

두번째 방법은 시트명으로 접근하는 방법입니다. wb["시트명"]으로 Sheet를 설정할 수 있습니다.

ws = wb["무"] #무 Sheet로 설정하기
print(ws)

결과를 보면 아래와 같습니다.

<Worksheet "무">

위에서 설정한 Sheet에 대한 변수 ws를 통해 내부 Cell의 데이터를 읽거나 쓸 수 있습니다. 이 내용은 "3-1-3) Cell 데이터 읽기/쓰기" 파트에서 다룰 예정입니다.

3) Workbook 객체의 모든 Sheet명 출력

이번에는 엑셀 파일의 모든 Sheet를 출력해보겠습니다. .sheetnames( )라는 함수를 통해 엑셀 파일의 내부 Sheet 목록을 모두 출력할 수 있습니다. 내부 Sheet를 파이썬의 자료 형 중 리스트로 저장하기 때문에 for문과 같이 반복문을 통해 접근하는게 가능해집니다.

해당 함수는 엑셀 업무 자동화에서 자주 사용되는 부분이니 기억해두시면 좋습니다. 위 엑셀 파일 시트 5개(업,무,자,동,화)를 리스트로 저장하여 출력하는 코드를 작성해보겠습니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import
wb = op.load_workbook(r"C:\UsersDesktop\VS CODE\Project\practice\연습\test.xlsx")
ws_list = wb.sheetnames  #해당 Workbook의 시트 목록을 리스트로 저장
print(ws_list) #리스트 출력

<결과>

['업', '무', '자', '동', '화']

위 코드를 응용하여 for문을 작성하고 각 Sheet 객체를 생성하여 출력하는 코드를 작성해보겠습니다.

<코드>

import  openpyxl  as  op  #openpyxl 모듈 import

wb = op.load_workbook(r"C:\UsersDesktop\VS CODE\Project\practice\연습\test.xlsx")

ws_list = wb.sheetnames  #해당 Workbook의 시트 목록을 리스트로 저장

for  sht  in  ws_list:
    ws = wb[sht] #Sheet 객체 생성
    print(ws) #객체 출력

<결과>

<Worksheet "업">
<Worksheet "무">
<Worksheet "자">
<Worksheet "동">
<Worksheet "화">

for 문에 따라 리스트의 각 Sheet명을 이용하여 객체를 생성하여 출력해보았습니다. 위 코드 블럭은 엑셀 자동화에 자주 쓰이는 부분이니 기억해두도록 합시다.
