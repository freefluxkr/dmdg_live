7) win32com 통해 엑셀 다루기 - 파일 저장 옵션

이번 파트에서는 win32com.client를 통해 엑셀 파일을 저장하는 여러가지 방법에 대해 알아보겠습니다. 엑셀 업무자동화에서 중요한 부분 중 하나는 원하는 파일을 사용자가 원하는 형태로 저장하는 것입니다. 사용자에 따라 엑셀 파일을 필요한 시트만 저장하거나, pdf 파일 등 다른 형식의 파일로 저장해야하는 경우도 생깁니다. 아래 내용을 공부하시면 저장 방법에 대한 기초적인 내용을 아실 수 있습니다.

아래와 같은 3가지 함수를 배워보겠습니다.

1. Save( )

2. SaveAs( )

3. ExportAsFixedFormat( )


1. Save( )

Save 함수는 별다른 설정 옵션 없이 "통합문서"라는 이름으로 파일을 저장합니다. Save 함수를 사용해보기 전에 먼저 임의의 Workbook 객체를 생성하는 코드를 작성해보겠습니다.

import win32com.client

#excel App 열기(객체 생성)
excel = win32com.client.Dispatch("Excel.Application")

#엑셀 실행과정이 보이게
excel.Visible = True

#Workbook 객체 생성(새로 추가)
wb = excel.Workbooks.Add()

지금까지 win32com.client 모듈을 공부해오셨던 분이라면 많이 봐왔던 코드들이죠?? 위 코드를 실행하면 아래와 같이 엑셀 통합 문서와 함께 기본 시트 "Sheet1"을 생성하게 됩니다.

그럼 위 상태에서 문서를 저장하는 Save( ) 함수를 사용하는 코드를 한줄 추가해보겠습니다. Save( ) 함수를 사용할 때 대상이 되는 객체는 Workbook입니다. 따라서, 아래와 같이 작성합니다.

#Workbook(통합문서) 저장
wb.Save()

위 코드와 같이 작성하여 실행하면 내 PC-문서라는 폴더에 "통합문서"라는 이름으로 엑셀 파일이 저장되게 됩니다. 넘버링의 경우 그전 문서에 이어 순서대로 저장되게 됩니다.(통합문서1,2,3....)

그럼 만약 엑셀의 "다른 이름으로 저장하기"와 같은 기능을 사용하려면 어떻게 해야할까요? 파일명과 저장 경로를 직접 설정할 수 있게 하려면 아래 SaveAs( ) 함수를 사용해야 합니다.


2. SaveAs( )

위에서 언급했다시피 SaveAs( )는 엑셀의 "다른 이름으로 저장하기"와 같은 기능을 하는 함수입니다.

Save( )와 마찬가지로 대상이 되는 객체는 Workbook 입니다. 기본적인 사용법은 아래와 같습니다. SaveAs의 옵션은 여러가지가 있으나 대표적으로 쓰는 3가지만 표시해보았습니다. 

"Workbook 객체".SaveAs(파일명, 파일포맷, 비밀번호...)

직접 사용해보며 익혀볼까요? 아래와 같이 코드를 작성하여 실행시켜보겠습니다. 파일포맷, 비밀번호 등의 옵션은 생각하지 않고 경로와 파일명만 지정하였습니다.

#path 지정
path = r"C:\Users\Desktop\VS CODE\Project\17. win32com\결과"

#저장
wb.SaveAs(path+"/test1.xlsx)

<결과>

위에서 SaveAs( ) 함수를 사용했을 때, 파일 확장자(.xlsx)를 직접 지정했지만 함수의 옵션 값을 통해 파일 형식을 지정하는 것도 가능합니다.

대표적인 예로 .csv 확장자로 저장하는 코드를 작성해보겠습니다. 아래 코드처럼 파일포맷 자리에 6을 입력하면 .csv 파일로 저장하게 됩니다. 대신 파일명을 지정할 때, 확장자는 제외시켜주어야 합니다.

( 위에서 실행했던 코드는 test1.xlsx이었던 기억해보세요)

#path 지정
path = r"C:\Users\Desktop\VS CODE\Project\17. win32com\결과"

#.csv 확장자로 저장(file format=6)
wb.SaveAs(path+"/test1, 6)

<결과>

파일 포맷에 대한 정보는 Microsoft 공식가이드 문서를 찾아보시면 됩니다. 아래 자료에서 보듯이 숫자 6은 .csv 파일을 의미하는 숫자입니다.

3. ExportAsFixedFormat( )

위에서 배워왔던 저장 방법은 단순히, 엑셀 파일을 저장하는 방법이었습니다. 엑셀 업무자동화에서 가장 많이 쓰이는 부분 중 하나는 특정 엑셀 시트를 .pdf 파일과 같이 원하는 확장자로 추출하는 방법입니다.

이런 경우에는 win32com 에서 제공하는 ExportAsFixedFormat( )이라는 함수를 사용합니다.

먼저, 해당 함수의 사용법은 아래와 같습니다.

"WorkSheet 객체".ExportAsFixedFormat(Type, FileName, From, To)

함수의 대상이 되는 객체는 Worksheet 객체입니다. 함수 내부의 옵션값은 매우 많습니다. 하지만, 대표적으로 사용하는 옵션은 Type, FileName, From, To 정도입니다.

1) Type

Type은 추출할 형식을 선택합니다. 0을 입력할시 pdf 형식, 1을 입력할시 xps 형식으로 파일을 추출합니다. 해당 내용은 Microsoft 공식 문서에도 나와있습니다.

2) FileName

이 부분은 SaveAs 함수에서 배웠던 내용과 동일합니다. 경로 및 파일명을 지정할 수 있습니다.

3) From, To

From은 해당 엑셀 시트에서 저장할 시작 페이지를 의미합니다. To는 해당 엑셀 시트에서 저장할 마지막 페이지입니다.

이번엔 사용 예시를 들어보겠습니다.

<코드>

#모듈 임포트
import  win32com.client

#excel 객체 생성 및 실행과정 보이게
excel = win32com.client.Dispatch("Excel.Application")
excel.Visible = True

#신규 엑셀 문서 생성
wb = excel.Workbooks.Add()
#활성화 된 시트를 ws로 설정
ws = wb.ActiveSheet

# 1행 1열에 텍스트 입력
ws.cells(1,1).Value = "사장님 몰래 하는 파이썬 업무자동화"

<결과>

저희는 위 입력 된 엑셀 시트를 pdf 확장자로 추출해볼 것입니다. 아래와 같이 코드를 추가 입력해보겠습니다. 저장 경로는 앞에서 실행했던 코드들과 동일 경로입니다.

From, To의 경우 생략하면 설정 된 페이지 영역을 모두 저장합니다. 아래 예시는 이해를 위해 From과 To를 입력하였습니다. 생략하여도 결과는 동일합니다.

<코드>

#저장할 경로 설정
path = r"C:\Users\Desktop\VS CODE\Project\17. win32com\결과" 

#pdf 파일로 저장하기 (1 page)
ws.ExportAsFixedFormat(Type=0, Filename=path+"/test.pdf",From=1,To=1)

<결과>

pdf 파일을 실행시켜보면 엑셀 시트 내용이 그대로 저장 된 것을 확인하실 수 있습니다.

이번 파트 내용을 응용하시면 여러 엑셀파일을 모두 pdf 파일로 한번에 변환하거나 하는 등의 업무 자동화 프로그램을 작성할 수 있습니다. 관련 프로그램은 "Ch4. 업무자동화 프로젝트 사례"에서 다룹니다.
