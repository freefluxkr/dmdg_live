## 3. 핵심 약점 및 분석

### ⚠️ 약점 1: 넓고 얕은 AI 스택으로 인한 '기술 깊이의 분산' (삼성SDS 지적)
* **원인**: ML(토픽모델링), NLP(감성분석), CV(MediaPipe, OpenCV), LLM(LoRA 튜닝) 등 인공지능의 거의 모든 분야를 포트폴리오에 나열하여, 신입 지원자로서 한 분야의 깊이를 깊게 파지 못한 인상을 줌.
* **보완 목표**: "여러 모델을 실서비스 백엔드와 긴밀히 엮어내는 AI 연동 풀스택 역량"으로 스택의 방향성을 단일화하고 구조적 심도 입증.

### ⚠️ 약점 2: Cerebras API 활용 깊이 부족 (LG CNS 지적)
* **원인**: Cerebras를 활용해 정서 케어 RAG 챗봇을 설계했다고 기재했으나, 기획 관점의 프롬프트 작성에 머물러 있어 RAG 벡터 인덱싱 최적화나 실질적인 실시간 임베딩 파이프라인 구축 이력이 부족해 보임.
* **보완 목표**: 단순 API 호출을 넘어서는 AI 모델 엔지니어링 구현 내역 보완.

### ⚠️ 약점 3: 실시간 추천 엔진의 가용성 입증 부족 (신세계I&C 지적)
* **원인**: FastAPI와 PostgreSQL로 추천 시스템을 백엔드단에 배포했으나, 리테일 서비스에서 발생할 수 있는 동시 사용자 트래픽 처리나 실시간 립 추천 처리 속도를 위한 성능 개선(캐싱 등) 노력이 보이지 않음.
* **보완 목표**: 추천 응답성 확보를 위한 최적화 아키텍처 제시.

### ⚠️ 약점 4: 코드 신뢰도 검증(단위 테스트) 부재 (롯데이노베이트 지적)
* **원인**: GitHub Action을 통한 CI/CD 인프라와 깃 관리는 훌륭하지만, 빌드 단계에서 안정성을 보장할 실질적인 단위 테스트(Unit Test) 구축 흔적이 없음.
* **보완 목표**: PyTest 기반 단위 테스트 설계 이력을 추가하여 시스템 안정성 보증.

### ⚠️ 약점 5: 직무 아이덴티티의 경계 모호함 (CJ올리브네트웍스 지적)
* **원인**: 데이터 분석가(DA)와 백엔드/AI 서비스 개발자 사이의 역할 분담이 섞여 있어, 입사 후 어떤 스페셜티로 팀에 기여할지 뚜렷한 포커싱이 아쉬움.
* **보완 목표**: "인문학적 사용자 이해도를 갖춘 AI 서비스 풀스택 엔지니어"로 브랜드 정립.

## 4. 단계별 약점 극복 로드맵 (Action Plan)

### 📅 [Phase 1] 직무 아이덴티티 단일화 및 기여도 명세 (즉시 실행)
1. **타이틀 재정의**: 포트폴리오 첫 장과 이력서 헤드라인을 **"사용자 데이터와 AI 모델을 조율하는 AI 서비스 풀스택 개발자"**로 단일화하여 전문성 강조.
2. **형상관리 성과 시각화**: GitHub Release Manager로서 활약하며 구축한 **브랜치 전략(Git Flow) 다이어그램**을 포트폴리오 내 1페이지로 깔끔하게 삽입하여 협업 역량을 직관적으로 어필.

### 📅 [Phase 2] AI/RAG 및 백엔드 기술 깊이 고도화 (1개월 내)
1. **RAG 파이프라인 고도화**:
   * Cerebras API 사용 시 데이터 임베딩 모델의 튜닝 방법과 벡터 DB 검색 최적화(Top-k 매칭 및 가중치 조정) 과정을 상세 아키텍처로 추가 서술.
2. **실시간 캐싱 및 DB 인덱싱 도입**:
   * 립 추천 및 식당 추천 엔진의 응답 속도 향상을 위해 **Redis 기반 추천 캐싱 레이어** 장표 추가.
   * PostgreSQL 데이터베이스의 **복합 인덱스(Composite Index) 튜닝**을 통한 쿼리 속도 개선 이력 가미.

### 📅 [Phase 3] DevOps 인프라 및 코드 안정성 증명 (2개월 내)
1. **단위 테스트 및 CI/CD 연동**:
   * PyTest를 사용해 퍼스널컬러 KNN 모델 및 API 응답 로직의 단위 테스트를 작성한 이력 기술.
   * GitHub Actions의 CI 단계에서 이 테스트 코드가 자동으로 구동되어 빌드 안정성을 체크하도록 자동화 파이프라인 완성.
2. **IaC(Terraform) 맛보기**:
   * 로컬 Docker 환경 배포에서 한 단계 나아가, 인프라를 코드로 관리(IaC)하는 기본 Terraform 구성 경험을 서술하여 LG CNS 등 DX 지향 대기업 맞춤 어필.
