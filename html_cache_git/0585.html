12.4.4 저장소 연결

임시 객체를 이용하여 로컬 저장소의 커밋 연결 고리를 분리했습니다. 연결 고리가 분리된 커밋들은 각각 두 원격 저장소로 푸시되었습니다. 이번에는 분리된 두 저장소를 저장소 하나로 연결해 보겠습니다.

7단계. 분리된 두 원격 저장소 중에서 마지막에 작업한 커밋으로 원격 저장소를 복제합니다.

$ cd 실습폴더


$ git clone https://github.com/jinygit/git-replace2.git git-replace2 저장소 복제
