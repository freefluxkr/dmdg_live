2 사용자 정의 함수 odd_even()은 숫자 하나를 전달받아 홀수인지, 짝수인지를 판단합니다. 다음 중 odd_even() 함수에 관한 설명으로 옳지 않은 것을 고르세요.

def odd_even(num): 
    if num % 2 == 1: 
        result = '홀수' 
    else: 
        result = '짝수' 
    return result 

odd_even(num = 26)

① num은 함수 외부로부터 데이터를 전달받는 매개변수다.

② odd_even(num = 26)에서 26을 인자라고 한다.

③ 프로그램을 실행하면 result에는 '짝수'가 저장된다.

④ return으로 반환하는 값은 하나만 설정할 수 있다.

⑤ odd_even(num = 26)은 odd_even(26)으로 바꿔도 된다.
