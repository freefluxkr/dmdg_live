조금 더 일반적인 예를 살펴봅시다.

name = '유리'
height = 175.5
age = 21
hobby = 'programming'
print(name, height, age, hobby)
실행결과
유리 175.5 21 programming

이 코드는 각 변수에 이름, 키, 나이, 취미를 저장합니다. 그리고 마지막 출력 명령어에서 name, height, age, hobby 변수에 저장된 값을 출력합니다. 이때 각 변수를 콤마(,)로 연결했습니다. 콤마(,)는 2장에서 배웠듯이 여러 요소를 연결하는 역할을 하며, 문자나 숫자 외에 변수를 연결할 때도 사용합니다.

4개의 변수를 만들 때 컴퓨터 내부에서 일어나는 일은 다음과 같습니다.

▲ 그림 3-2 변수 만들기
