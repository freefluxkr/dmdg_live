1 제어구조의 종류

종류

진행 순서

순차구조

위에서 아래의 순서로 실행되는 구조

선택구조(조건문)

조건 충족 여부에 따라 실행할 명령어가 달라지는 구조

반복구조(반복문)

특정 명령어를 지정된 범위 또는 조건 내에서 반복하는 구조

 

2 반복문의 실행 원리

형식

의미

예시

 
for a in data:
    B

a가 data 구간 안에 있는 값일 동안

B를 실행하라

 
for a in [1, 2, 3, 4, 5]:
    print('안녕하세요')
 
while 조건:
    B

조건을 충족하는 동안

B를 실행하라

 
a = 1
while a <= 5:
    print('안녕하세요')
    a += 1
