4.2
조건을 충족하지 않을 때: else

4.2.1 그렇지 않으면 else

앞에서 작성한 알람 설정 프로그램에서 주중과 주말, 두 가지 조건을 동시에 충족하는 경우가 있을까요? 당연히 없습니다. 일주일은 주중과 주말로 나뉩니다. 그럼 ‘주중이면 아침 7시에 알람을 울리고, 그렇지 않으면 아침 10시에 알람을 울려라.’로 조건을 바꿔도 되지 않을까요? 파이썬에서는 조건이 2개일 때 앞서 배운 if에 ‘그렇지 않으면’이라는 의미의 else를 추가해 다음 형식으로 표현합니다.

형식

if A: # 조건
    B # 조건을 충족할 때 실행할 내용
else:
    C # 조건을 충족하지 않을 때 실행할 내용
