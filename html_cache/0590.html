12.1.1 folium 설치하고 지도 만들기

먼저 folium을 설치해 봅시다. folium은 파이썬에 내장된 라이브러리가 아니어서 따로 설치해야 합니다. 주피터 노트북에서는 !pip install folium으로 설치합니다. 코랩에서는 따로 설치할 필요 없습니다.

!pip install folium
실행결과
Collecting folium
  Downloading folium-0.12.1-py2.py3-none-any.whl (94 kB)
…
Successfully installed branca-0.4.2 folium-0.12.1

설치 내용이 나오다가 가장 마지막 줄에 ‘Successfully installed...’라는 메시지가 보이면 설치가 끝납니다(버전은 책과 다를 수 있습니다). 이제 folium 라이브러리를 자유롭게 사용할 수 있습니다.
