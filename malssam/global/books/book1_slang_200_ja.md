# マルッサム：韓国語新造語・ミーム年代記 200選

## Part 1. レトロ思い出：1990〜2000年代ポケベル・PC通信流行語 (27選)

### 001. 방가방가 (banggabangga) — ちーす / こんちゃ
- **意味と由来**: 90年代パソコン通信時代の伝説的挨拶「お会いできて嬉しいです」。
- **実戦K-状況劇**: A: ちーす！今日初参加です！ B: いらっしゃい！


### 002. 하이루 (hairu) — ハロー / うぃっす
- **意味と由来**: 英語のHiに可愛い語尾を付けた2000年代初頭のネット挨拶語。
- **実戦K-状況劇**: A: みんなハロー！ B: おっす、いらっしゃい！


### 003. 즐 (jeul) — 乙 / お断りします
- **意味と由来**: 元は「楽しく」だったが、転じて「お前には用ない、消えろ」という意味になった拒絶語。
- **実戦K-状況劇**: A: 1万ウォン貸してくれない？ B: 乙。絶対に貸さん。


### 004. OTL (OTL) — orz / ガックリ
- **意味と由来**: 頭(O)、手(T)、跪く足(L)でがっくりと地面に崩れ落ちる姿を描いた象形顔文字。
- **実戦K-状況劇**: 単位落とした… OTL


### 005. 뷁 (bwek) — ブエッ / なんじゃそりゃ
- **意味と由来**: 理不尽さやあきれ返る怒りを一音で表現した伝説のネットスラング。
- **実戦K-状況劇**: 週末出勤しろって？うわ、ブエッ…


### 006. 간지 (ganji) — イケてる / カンペキな着こなし
- **意味と由来**: 日本語の「感じ」が韓国で独自のファッショナブルなスラングに定着した例。
- **実戦K-状況劇**: 今日のコートの着こなし、超イケてるじゃん！


### 007. 지못미 (jimotmi) — 守ってあげられなくてごめん (ジモンミ)
- **意味と由来**: 黒歴史や恥ずかしい写真に対して同情と笑いを込めて使われた略語。
- **実戦K-状況劇**: 卒アルで目閉じて撮られちゃったの？うわぁ、ジモンミ…


### 008. 킹왕짱 (kingwangjjang) — キング・オブ・神 / 最強
- **意味と由来**: 英語King＋漢字王＋韓国語チャン(最高)の3段重ねによる至高の賛辞。
- **実戦K-状況劇**: この新型PC、マジでキング王チャン！超快適！


### 009. 안습 (anseup) — 涙目 / 目から汗が
- **意味と由来**: 「眼球に湿気が満ちる」の略で、あまりに不憫で涙が出そうな状況を表す流行語。
- **実戦K-状況劇**: 初デートで財布忘れたって？うわ、ガチで涙目案件だな…


### 010. 얼짱 (eoljjang) — オルチャン / 超美形
- **意味と由来**: 「顔(オルグル)が最高(チャン)」の略で、K-Beautyの起源とも言えるネット美男美女の称号。
- **実戦K-状況劇**: あの転校生、昔ネットで有名なオルチャンだったらしいよ！


### 011. 몸짱 (momjjang) — モムチャン / ナイスバディ
- **意味と由来**: 「体(モム)が最高(チャン)」の略で、鍛え上げられた美ボディを讃える言葉。
- **実戦K-状況劇**: 毎日ジム通ってモムチャンになったね！腹筋すごい！


### 012. 훈남 (hunnam) — 癒し系イケメン / フンナム
- **意味と由来**: 「心が温まる(フンフン)男」の略で、親しみやすくて爽やかな好青年を表す。
- **実戦K-状況劇**: あの先輩、優しくて笑顔が素敵な癒し系イケメンだよね。


### 013. 엄친아 (eomchina) — オムチナ (完璧な隣の息子)
- **意味と由来**: 「母の友人の息子」の略。勉強も外見も完璧で、親から常に比較対象にされる男。
- **実戦K-状況劇**: うちの母、いっつも完璧なオムチナと私を比べてくるのよ。


### 014. 된장녀 (doenjangnyeo) — テンジャン女 / 見栄っ張り女子
- **意味と由来**: 身の丈に合わない高級ブランドやスタバ消費を批判・風刺した2000年代の論争語。
- **実戦K-状況劇**: 2000年代半ば、韓国でテンジャン女論争がものすごく社会問題になったよね。


### 015. 담다디 (damdadi) — ダムダディ / 90年代青春アンセム
- **意味と由来**: 80年代末〜90年代の韓国X世代が熱狂した、自由奔放な若者の伝説的ヒット曲。
- **実戦K-状況劇**: 当時の学園祭といえば、みんなでタンバリン叩いてダムダディ踊ったもんだよ。


### 016. 8282 () — 8282 (早く早く / ポケベル暗号)
- **意味と由来**: 90年代ポケベル時代、数字の「パリパリ」が「早く早く(パリパリ)」と読める緊急暗号。
- **実戦K-状況劇**: ポケベルに8282入った！公衆電話探さなきゃ！


### 017. 0124 () — 0124 (永遠に愛してる / ポケベル愛の暗号)
- **意味と由来**: 語呂合わせで「永遠に(012) 愛してる(4)」を意味した90年代純愛ポケベル暗号。
- **実戦K-状況劇**: 公衆電話から彼女のポケベルに0124送ってドキドキ待ったよな。


### 018. 도토리 (dotori) — どんぐり (ドトリ / サイワールド通貨)
- **意味と由来**: 国民的SNSサイワールドでBGMやスキンを買うために使われた伝説の電子通貨。
- **実戦K-状況劇**: フリースタイルの『Y』をBGMに設定したいから、どんぐり5個送って！


### 019. 일촌평 (ilchonpyeong) — イルチョンピョン (親友のひとこと伝言板)
- **意味と由来**: 親友(イルチョン)限定でミニホのトップに刻むことができた伝説の1行メッセージ。
- **実戦K-状況劇**: 気になるあの子のイルチョンピョンに足跡残してドキドキしたなぁ。


### 020. 십라 (sipra) — クソッ / 伏字回避スラング
- **意味と由来**: 2000年代のネットゲームでチャットのNGワード規制をすり抜けるために生まれた罵倒語。
- **実戦K-状況劇**: ボスあとHP1%で鯖落ちした！クソッふざけんな！


### 021. 취존 (chwijon) — 趣味尊重 / 好みは人それぞれ
- **意味と由来**: 『他人の好みを尊重しよう』の略語。マニアックな趣味を否定せず認め合おうというネットマナー。
- **実戦K-状況劇**: 他人に迷惑かけてないんだから、趣味尊重してよね！


### 022. 모태솔로 (motaesolro) — 母胎ソロ (生まれてこの方交際ゼロ)
- **意味と由来**: 母のお腹から生まれて以来、一度も恋愛をしたことがない人をユーモラスに指す言葉。
- **実戦K-状況劇**: 生まれて23年間彼女がいたことのない母胎ソロです。


### 023. 금사빠 (geumsappa) — すぐ惚れる人 (惚れっぽい人 / クムサッパ)
- **意味と由来**: ちょっと優しくされただけで『私のこと好きかも！』とすぐ恋に落ちてしまうタイプの人。
- **実戦K-状況劇**: コーヒー渡されただけで運命感じちゃう、筋金入りの惚れっぽい性格だよ。


### 024. 아햏햏 (ahaethaet) — アヘヘッ (2000年代初頭の伝説的禅ネットスラング)
- **意味と由来**: 虚無、悟り、脱力感が混ざり合った、韓国初期インターネット掲示板を象徴する伝説の感嘆詞。
- **実戦K-状況劇**: 徹夜のレポート全部消えたけど不思議と心が穏やかだ…これぞアヘヘッの境地。


### 025. 싱하형 (singhahyeong) — シンハ兄貴 (ブルース・リー顔の元祖ネット番長)
- **意味と由来**: 『10秒以内に高架下に来い』という名台詞で2000年代初頭の韓国ネット界を支配した伝説のキャラクター。
- **実戦K-状況劇**: 兄貴はお怒りだ。10秒以内にガード下に来い、9秒も11秒も許さん！


### 026. 폐인 (pyein) — 廃人 (ネトゲ廃人 / ネチズン廃人)
- **意味と由来**: ネットカフェで徹夜でゲームや掲示板に没頭し、現実を忘れてネットの世界に住み着いたヘビーユーザー。
- **実戦K-状況劇**: 休日はカップ麺すすりながらネカフェで夜通しゲーム、完全に古の廃人コースだ。


### 027. 따봉 (ttabong) — タボン！ (最高！ / 親指グッジョブ)
- **意味と由来**: ポルトガル語のEstá bom由来。1990年代初頭のCMで韓国中に大ブームを巻き起こした『最高！』の合図。
- **実戦K-状況劇**: 今日のお母さんの手料理、本当にタボン（最高）だよ！


## Part 2. 国民的流行語：2010年代スマホ・カカオトーク時代 (31選)

### 001. 멘붕 (menbung) — メン崩 (メンタル崩壊) / パニック
- **意味と由来**: 「メンタル崩壊」の略で、あまりの衝撃に精神が崩壊しパニックになった状態。
- **実戦K-状況劇**: 保存せずにパワポ閉じちゃった…マジでメン崩。


### 002. 꿀잼 (kkuljaem) — 神オモ / めっちゃ面白い
- **意味と由来**: 「蜂蜜(クル)」のように甘くて「面白い(チェム)」という意味の国民的賛辞。
- **実戦K-状況劇**: 昨日の新作映画見た？最初から最後まで神オモだったよ！


### 003. 노잼 (nojaem) — くそつまらん / スベってる
- **意味と由来**: 英語のNoと面白い(チェム)が合体した「全く面白くない」というスラング。
- **実戦K-状況劇**: 部長がまたオヤジギャグ言ったの？くそつまらんな…


### 004. 심쿵 (simkung) — 胸キュン / 心臓止まるかと思った
- **意味と由来**: 「心臓がドクン」と跳ねるほどときめいたり可愛いものに出会った時の悶絶リアクション。
- **実戦K-状況劇**: 子猫が靴の上で寝ちゃった！可愛すぎて胸キュン死する…


### 005. 금수저 (geumsujeo) — 金のスプーン (クムスジョ) / 勝ち組御曹司
- **意味と由来**: 韓国の「スプーン階級論」で親の莫大な資産により何の苦労もせず富を得る最上位階層。
- **実戦K-状況劇**: 卒業してすぐ江南のマンションもらったの？さすが金のスプーン組だな。


### 006. 흙수저 (heuksujeo) — 土のスプーン (フクスジョ) / 親ガチャ大失敗
- **意味と由来**: 親の経済的支援がゼロで、自力で借金返済や生活苦に立ち向かわねばならない最下層の自虐語。
- **実戦K-状況劇**: 学費返すのにバイト掛け持ちだよ。土のスプーン生まれは辛いな…


### 007. 팩폭 (paekpok) — ファクト暴力 / ぐうの音も出ない正論
- **意味と由来**: 「ファクト(事実)暴力」の略。反論不能のド正論で相手の心を情け容赦なく粉砕する行為。
- **実戦K-状況劇**: そんなストレートにファクト暴力されたら立ち直れないわ…


### 008. 빼박캔트 (ppaebakkaenteu) — 言い逃れ不可能 / 逃げ場なし
- **意味と由来**: 「抜き差しならぬ」と英語の「Can't」を組み合わせた、言い訳が一切通用しない状態。
- **実戦K-状況劇**: 防犯カメラに全部映ってるよ。もう言い逃れ不可能だね。


### 009. 극혐 (geukhyeom) — 激キモ / ガチで無理
- **意味と由来**: 「極度に嫌悪」の略。マナーの悪さや不快な言動に対して強烈な嫌悪感を示す言葉。
- **実戦K-状況劇**: 電車で足広げて隣の人押しのける人、ガチで無理だわ。


### 010. 츤데레 (cheundere) — ツンデレ / 素直になれない優しさ
- **意味と由来**: 普段はツンツンしているが、本心は優しくデレる魅力的な二面性を表す言葉。
- **実戦K-状況劇**: 「道で拾った」って欲しかったスニーカーくれたの？完璧なツンデレじゃん笑


### 011. 케미 (kemi) — 相性抜群 / ケミストリー
- **意味と由来**: 英語のChemistry(化学反応)の略で、二人の息がぴったり合っている最高の相性。
- **実戦K-状況劇**: あの二人の掛け合い、ケミが良すぎて永遠に見てられる！


### 012. 답정너 (dapjeongneo) — 答えありきの質問 / 褒め言葉待ち
- **意味と由来**: 「答えは決まってるから、あんたは言われた通りに答えなさい」という誘導尋問をする人。

### 013. 낄끼빠빠 (kkilkkippappa) — 空気を読め / 引き際をわきまえろ
- **意味と由来**: 「混ざる時は混ざり、抜ける時は抜けろ」の略。場の空気を読んで出処進退を弁えろという教訓。
